Simulations enable you to automatically simulate sessions to test your agent before going live. They automate the execution of test scenarios and sessions to help ensure that your agent works correctly and handles expected scenarios reliably.

You can test different scenarios using various personas and understand how your agent performs across contexts—without waiting on real user data for detecting Agent breakdown points and efficiency issues.

Simulations help you:

* Validate agent behavior and responses before go-live.
* Benchmark results against desired outputs.
* Iterate on logic, tone, or context handling.
* Improve overall agent reliability and trustworthiness.

---

## How It Works

Simulations create realistic testing conditions by linking three key components: Personas, Test Scenarios, and Simulation Runs.

1. **Create Personas** — Define user profiles representing different end-user types with configurable traits such as demographics, tone, emotion, urgency, and intent patterns. 
2. **Define Test Scenarios** — Create or reuse test cases that represent typical or edge-case user queries, including the context and expected agent behavior for each situation. 
3. **Run Simulations** — Run simulations in one of the following ways:
    * **Manual** — Select Personas and Test Scenarios to generate simulated sessions and test realistic multi-turn conversations with the agent.
    * **Generate using AI** — Automatically generate and run simulations based on your inputs, without manually creating Personas or Test Scenarios.
4. **Use Simulated Data for Evaluation** — Simulated sessions are auto-imported into a Dataset to run evaluators or assess performance, tone, adherence, and tool accuracy.


### What Happens During a Simulation

During execution:

* The system combines each *Persona × Test Scenario* to generate multiple test queries.
* Each query includes the first user input and context/knowledge for follow-up interactions.
* Queries are passed to the agent to simulate realistic multi-turn conversations.
* Each conversation is recorded as an individual simulation session with transcripts, metadata, and execution details.

## Create a Simulation

Before creating simulations, you must first add an agentic app.

1. Go to your project and select **Evaluations > Simulations**.
2. Click **+ Add Simulation Apps**.
3. Select an agentic app from your workspace.

A folder is created for the selected app. All simulations, personas, and test scenarios for that app are stored in this folder.

<Note>
Currently, Agent Management Platform supports simulations only for Kore.ai’s Agent Platform Agentic Apps. Support for third-party agents will be available soon. 
</Note>

## Create Personas

Personas represent different types of users who interact with your agent. Each persona simulates distinct communication styles, goals, and behavior patterns. During simulation runs, Personas help test how your agent performs across different user contexts and tones.

Steps to create a persona:

1. Inside your simulation folder, click **Personas**> **Create Persona**.
2. Choose one of the following creation methods:
    * **Manual**
    * **Generate using AI**


### Manual Creation

Enter the following details:

* Persona name
* Description
* Language

Use the **Additional Information** field to define specific persona behaviors and interaction patterns. This controls how the persona interacts and responds during simulations.


### Generate using AI

Provide the following details:

* Persona role
* Persona context or description
* Number of personas to generate
* Model configuration

Click **Create Persona**. The created persona is listed on the Personas management page.

**Additional options**

* Use the column manager to add or remove columns displayed in the table.
* Edit, clone, or delete personas from the **Personas** page.
* If a Persona is deleted, any active simulations using it automatically switch to the default Unidentified Persona.

You can create multiple personas to represent different user types. Each persona can be used in one or more simulations. 

<Note>
Personas are reusable across multiple simulations within the same Agentic Evaluation project.
</Note>

## Create Test Scenarios

Test scenarios define the context, user intent, and expected outcome for a simulated interaction. Each scenario captures the situation, input details, and desired response to help evaluate how the agent performs under different conditions.

You can create Test Scenarios in one of the following ways:

* **Write test scenarios** — Manually define details such as the user query, context, and expected outcome.
* **Generate using AI** — Automatically generate multiple scenarios using AI based on your agent’s configured capabilities.


### Write Test Scenarios

To manually create a test scenario:

1. Go to **Evaluations > Simulations > Test Scenarios**.
2. Click **Write test scenario**.
3. Enter the following details:
    * **Agentic capability** — The specific skill or function being tested.
    * **Initial user query** — The user’s opening message or intent.
    * **Information provided to persona** — Context or background knowledge for the persona.
    * **End condition** — A plain-text condition that signals when the simulation should stop. The simulation also stops automatically if the agent ends the conversation early; if the end condition is not reached, it stops at Max turns.
    * **Max turns** — The maximum number of conversation turns allowed before the simulated conversation ends.
4. Click **Save**.

Provide any task-specific details—such as account numbers, external links, ticket IDs, or user IDs—so the simulation agent has enough context to complete realistic multi-turn conversations.


#### Use JSON Input

You can also define a test scenario directly using JSON in the **Create Test Scenario** screen.

**What it does**

* Defines the entire scenario in one structured input
* Bypasses manual form entry
* Syncs with the Form view automatically

**When to use**

* Bulk or repeated scenario creation
* External generation (LLMs, scripts)
* Precise control over fields


#### Required Fields

```json
{
  "name": "",
  "agenticCapability": "",
  "initialQuery": "",
  "informationToPersona": "",
  "endCondition": "",
  "maxTurns": 10
}
```

**Steps to use JSON:**

1. Open **Create Test Scenario > Manual Entry.**
2. Switch to **JSON view.**
3. Copy the JSON structure.
4. Paste it into an external tool (for example, GPT) and generate scenarios in the same format.
5. Paste the generated JSON back into the platform.
6. (Optional) Switch to **Form** view to review the scenario.
7. Click **Create Scenario**.

**Notes**

* JSON input must match the expected structure, or it will fail to load or run.
* All required fields must be present.
* Invalid JSON or missing fields prevent scenario creation.

To automatically generate test scenarios using AI:

1. On the **Test Scenarios** page, click **Generate using AI**.
2. Specify the following details:
    * **Environment** — Select the environment where the simulation will run. One agentic app can have multiple environments deployed.
    * **Agentic capabilities** — Capabilities to test (for example, *Transfer balance*).
    * **Test objective** — Define what you want to test, such as negative scenarios or multi-turn conversations.
    * **Number of scenarios per capability** — Maximum 15 scenarios.
    * **Model and model parameters** — Model configuration used for generation.
    * **Information provided to persona** — Background or knowledge context for the simulation.
3. Click **Generate**.

The system automatically generates multiple scenario variations for each capability, including both normal and edge-case interactions.

**Additional options:**

* Use the Column manager to add or remove columns displayed in the table.
* Edit, clone, or delete scenarios from the **Test Scenarios** page.


<Note>
* Manual and AI-generated scenarios can coexist within the same project.
* Test Scenarios are reusable across multiple simulations within the same Agentic Evaluation project.
</Note>

## Run Simulations

After creating Personas and Test Scenarios, run simulations to generate realistic interaction sessions. Simulations help automate testing and evaluate agent responses, measure consistency, track goal completion, and identify areas for improvement quickly.

You can run simulations in one of the following ways:

* Manual simulation
* Generate using AI


### Manual Simulation

To manually run a simulation:

1. Go to **Evaluations > Simulations > Create Simulation**.
2. Click **Create Simulation**.
3. Select **Manual simulation**.
4. Specify the following details:
    * Simulation name and description
    * Environment
    * One or more Personas and Test Scenarios
    * Model and model parameters such as Temperature, Max tokens, Top p, and Frequency penalty.
5. Click **Run Simulation**.

The system executes sessions for the selected scenarios. You can monitor progress in real time from the Simulation Runs panel.

### Generate Simulations using AI

Generate simulations without manually creating Personas or Test Scenarios.

1. Go to **Evaluations > Simulations > Create Simulation**.
2. Select **Auto-Generate using AI**.
3. Enter the required details.
4. Click **Generate sessions**.

The system automatically creates and runs simulated sessions.

After the generation completes, the sessions are available in the **Simulated Sessions** tab.

<Note>
Each simulation run creates a dataset using the simulation name followed by a unique ID, with the dataset type marked as ‘Simulated’. You can use these datasets for further evaluations, analysis, and insights.
</Note>

## View Simulated Results

After a simulation run completes, you can:

* View conversation transcripts between Personas and the agent
* Analyze how the agent handled each scenario
* Identify areas for improvement before production deployment

Simulation results are organized into three tabs:


### Overview

* The Overview tab provides a summary of the simulation.
* Shows simulation details (model, environment, creator)
* Analytics metrics: total runs, success rate, completed vs failed sessions 


### Simulated sessions

* The Simulated Sessions tab displays the list of all generated sessions.
* Each session includes Persona, Scenario, Status, Turns, Duration, and Outcome.
* Click a session to view the full conversation transcript
* **Status:**
    * **Passed** — Simulation completed successfully
    * **Failed** — Displays failure details (for example, tool failures)
    * **Running** — Simulation is still in progress


### Configuration

* The Configuration tab shows how the simulation was configured.
* Manual simulations display what was used in the run: Selected Personas, Selected Test Scenarios, Model settings (for example, temperature and tokens), Environment used.
* AI-generated simulations display the input you had provided: Agentic capabilities, Test objective, Persona role, Persona behavior or objective.

## Key Behavior

* Simulations automatically generate multi-turn conversations.
* Each session is independently executed and tracked.
* Results are structured for quick analysis and debugging.


<Note>
Simulated sessions are also automatically available in the **Runs** screen with full transcripts, traces, and policy results. This allows you to analyze simulated and real sessions in the same place.
</Note>
