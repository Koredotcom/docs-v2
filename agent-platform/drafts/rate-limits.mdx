The Config Overrides page allows superadmin or tenant admin to view the default limits for each plan and configure custom limit overrides for individual workspaces.

Config page in platform settings: https://example.com/config-overrides.

See this [list of region-specific URLs](/agent-platform/getting-started.mdx#platform-access-and-allowlist-of-ips).

## Change workspace-level rate limits

Superadmins can override the default limits for a specific workspace.

1. Log into the platform as a superadmin and go to the Config Overrides page.
1. In the **Tenant Config Inspector** UI, select the workspace for which you want to change the rate limits.
1. Review the workspace's current plan defaults.
1. Select **Edit Overrides**.
1. Edit the values that you want to override. Select **Save**.

The Resolved value for a limit reflects the value that applies to the selected workspace. When an override is configured, the resolved value can differ from the plan default.

<Note>In the **Tenant Config Inspector** UI, select **Clear All** to reset your rate limit customizations to the original default values.</Note>

## Remove workspace overrides

To remove the configured overrides for a workspace:

1. Select the workspace in **Tenant Config Inspector**.
1. Select **Clear All** and confirm the change.

The workspace then uses the applicable plan default values.
