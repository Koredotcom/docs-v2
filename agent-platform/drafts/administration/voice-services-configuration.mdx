Manage speech-to-text, text-to-speech, and telephony credentials.

Navigation: Settings > AI Configuration > Voice Services

Voice Services manages the credentials for speech-to-text (STT) and text-to-speech (TTS) providers that power voice-enabled agent interactions.

<Warning>Voice channels require both Deepgram (STT) and ElevenLabs (TTS) credentials. Voice preview and live voice sessions will fail until these are configured.</Warning>

**Supported Providers**

The following providers are available for configuration:

| Provider            | Description                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| Deepgram Speech     | Deepgram credentials for speech recognition and synthesis                   |
| Google Cloud Speech | Google Cloud speech credentials for recognition and synthesis               |
| AWS Speech          | AWS credentials for Amazon Transcribe and Polly                             |
| Microsoft Speech    | Azure / Microsoft Speech credentials for STT (speech-to-text) and TTS (text-to-speech) |
| Nuance Speech       | Nuance speech credentials for STT and TTS                                   |


Each provider shows its current configuration status. Providers that have not yet been configured display Not Configured.

**Configuring a Provider**

1. Go to Settings > AI Configuration > Voice Services.

2. Find the provider you want to configure.

3. Click Configure.

4. Enter the provider credentials in the configuration dialog.

5. Click Save.

The fields in the configuration dialog vary by provider. The following example shows the fields for Google Cloud Speech:

| Property            | Description                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| Display Name        | A label to identify this credential set (for example, *Google Cloud Speech Credentials*). |
| Service Account JSON| Paste the full Google service-account JSON used for Speech-to-Text.         |
| STT Model ID        | Optional. The Google STT model to use (for example, *chirp_3, chirp, latest_long, latest_short, telephony, telephony_short*). Default: **chirp_3**. |
