Arch is the AI Architect component of the Agent Platform that manages the model and credentials used for agent specification generation and chat-based orchestration.

- Navigation: Settings > AI Configuration
- Required role: Owner or Admin

The Arch page is organized into two tabs:

| **Tab**       | **Description**                                                                 |
|---------------|---------------------------------------------------------------------------------|
| Settings      | Configure the credential source, model selection, and generation parameters     |
| Audit Logs    | Review Arch session activity, costs, and errors                                 |

## Settings

### Current Source

The Current Source banner displays the active credential source and model Arch is currently using (for example, Model Hub · OpenAI · gpt-5.2).

### Credential Source

Choose how Arch authenticates with the LLM provider.

| Option | Description |
|---|---|
| Platform Credits | Use platform-provided API credits. Select which model to use below. |
| Direct API Key | Bring your own provider key and keep the model selection in Arch settings. |
| Model Hub | Use a model already configured with credentials in your Model Hub. |

<Note>Arch works best with models that support tool calling and have large context windows.</Note>

### Select Model

Select the model Arch uses from the dropdown. The selected model displays its provider, model ID, capability tags (for example, Tools, Balanced), and tier.

If the selected model hasn't been tested with Arch, a warning is shown: **"This model hasn't been tested with Arch. Consider using a recommended model."**

### Parameters

Fine-tune generation behavior for chat and spec generation.

| Parameter | Description | Default |
|---|---|---|
| Reasoning Effort | Controls how much reasoning the model applies before responding. Slide between none and high. | Low |
| Verbosity | Controls the length and detail of generated responses. Slide between low and high. | Medium |
| Max completion tokens | Maximum number of tokens Arch can generate per response. | 6,000 |

Click **Save Changes** to apply updates.


## Audit Logs

The Audit Logs tab shows Arch session activity for the selected time range, including cost, error count, and a browsable session list.

### Summary Metrics

Four metric cards are displayed at the top of the tab:

| Metric | Description |
|---|---|
| Sessions (24h) | Number of Arch sessions in the last 24 hours |
| Total Cost (24h) | Estimated cost of Arch sessions in the last 24 hours |
| Errors (24h) | Number of sessions that encountered errors in the last 24 hours |
| Listed Sessions | Total number of sessions shown in the current session list |

### Sessions List

The Sessions list displays all Arch sessions. Use the filter controls to narrow results:

| Filter | Description |
|---|---|
| Has Errors | Show only sessions that encountered errors |
| Today | Show only sessions from today |

Each session row shows the session ID, timestamp, number of turns, and current phase (for example, INTERVIEW).

Click a session to view the full execution flow in the detail panel on the right.
