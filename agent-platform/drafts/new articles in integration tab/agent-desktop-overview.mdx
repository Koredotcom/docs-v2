Agent desktop integrations hand over an Artemis conversation to a live agent working in a contact center or service desktop.

| Agent desktop                                                 |  Description |
|:--------------------------------------------------------------|:-------------|
| [Amazon Connect](/agent-platform/integrations/amazon-connect) | Escalate chat conversations to live agents in the Amazon Connect Contact Control Panel (CCP) through a contact flow. Voice calls aren't transferred. |
| [Kore SmartAssist](/agent-platform/integrations/ccai)         | Route escalated conversations to live agents in the AI for Service Contact Center app. Supports chat and email routing and voice call transfer. |
| [Genesys Cloud](/agent-platform/integrations/genesys-cloud)   | Route escalated conversations to a Genesys Cloud queue, where live agents pick them up in Genesys Cloud CX Agent Desktop. Supports Web Messaging and WebChat modes. |
| Genesys Open Messaging                                        | Connect your agent to Genesys Cloud Open Messaging conversations through a project-scoped, signed webhook. |
| [Salesforce](/agent-platform/integrations/salesforce)         | Route escalated conversations to a Salesforce queue, where live agents pick them up in the Service Console. Supports MIAW and BYOC authentication types. |
| ServiceNow                                                    | Escalate conversations to live agents working in ServiceNow. |
| [Five9](/agent-platform/integrations/five9)                   | Route escalated conversations to a Five9 Campaign, where live agents pick them up from their Five9 agent desktop. Checks for logged-in agents before transfer. |
