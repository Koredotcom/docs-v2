Setup procedure for creating an AI for Service Contact Center app, enabling Artemis Integration, and connecting Kore Smart Assist from the Artemis application.

| Item | Details |
|---|---|
| Document type | Configuration SOP |
| Primary users | AI for Service administrators, Artemis project administrators, implementation engineers |
| Systems covered | AI for Service Platform; Artemis Application; Kore Smart Assist integration |
| Target outcome | Published AI for Service Contact Center app connected to the correct Artemis project and webhook channel |

## Purpose and Scope

This document provides a clean configuration procedure for integrating an AI for Service Contact Center app with an Artemis project through the Artemis Integration and Kore Smart Assist connection.

Use this as an implementation checklist when setting up a new app, copying integration values, enabling the integration, and publishing the AI for Service app.

## Prerequisites

- AI for Service platform access with permission to create and publish Contact Center apps.
- Artemis application access with permission to open Agent Chat, Profile, Integrations, Deployments, and API Keys.
- An Artemis project selected for the integration.
- A secure token generator or password manager for creating secrets that meet the required complexity rules.

## Configuration Flow

1. Create a new AI for Service app and choose **Contact Center** during app setup.
2. Complete the AI for Service onboarding journey.
3. Open **Flows & Channels** and configure **Artemis Integration**.
4. Fetch tenant, project, webhook, and token values from the Artemis project.
5. Enable Artemis Integration and publish the AI for Service app.
6. In Artemis, open **Kore Smart Assist** and create the connection using values from the AI for Service Artemis Integration screen.

## AI for Service Platform Setup

### Create and onboard the app

1. Log in to the AI for Service platform.
2. Create a new app and choose **Contact Center** as the app type.
3. Complete the onboarding journey for the new app.
4. Go to **Flows & Channels**.
5. Select **Artemis Integration**.

### Complete Artemis Integration fields

| AI for Service Artemis Integration field | Where to fetch the value | Implementation notes |
|---|---|---|
| Artemis tenant ID | Artemis Agent Chat → initiate chat → Debug → Data **OR** Artemis Profile → Workspace ID | Use the tenant/workspace ID for the Artemis workspace being connected. |
| Artemis project ID | Artemis Agent Chat → initiate chat → Debug → Data | Use the project ID for the target Artemis project. |
| Artemis webhook URL | Artemis Project → Integrations → Kore Smart Assist → Connect → Webhook Channel Callback URL | Copy the callback URL exactly as shown. |
| Artemis access token | Bring your own key | Create a 32 to 512 character secret using at least 3 character classes: uppercase, lowercase, digit, symbol. |
| Artemis auth token | Artemis Project → Deployments → API Keys → Create a platform key | Create a platform key and copy the generated token into AI for Service. |

### Enable and publish

1. Review all Artemis Integration fields for the correct tenant, project, URL, and token values.
2. Enable Artemis Integration.
3. Publish the AI for Service app.
4. After publishing, keep the Artemis Integration screen open because Artemis will need the **CCAI host URL**, **CCAI auth token**, **Web token**, **CCAI stream ID**, and **Account ID**.

## Artemis Application Setup

Go to **Project → Integrations → Kore Smart Assist → Connect**.

| Artemis connection field | Source | Notes |
|---|---|---|
| Connection Name | Enter a unique connection name. | Use a name that identifies the environment and AI for Service app, such as `AI for Service-uat-contact-center`. |
| Base URL | AI for Service Artemis Integration → CCAI host URL | Example: `https://uat-platform.korebots.com/` |
| CCAI App Token (optional) | AI for Service Artemis Integration → CCAI auth token | Populate when required. |
| XOCC Webhook Channel Token | AI for Service Artemis Integration → Web token | Copy exactly from AI for Service. |
| Webhook Secret | Bring your own key | Use the same value as the Artemis access token entered in AI for Service Artemis Integration. |
| App ID | AI for Service Artemis Integration → CCAI stream ID | Copy exactly. |
| Account ID | AI for Service Artemis Integration → Account ID | Copy exactly. |

## Token and Secret Rules

| Requirement | Rule |
|---|---|
| Length | Use 32 to 512 characters. |
| Character mix | Include at least 3 of these 4 classes: uppercase letters, lowercase letters, digits, symbols. |
| Webhook Secret matching | Must match the Artemis access token configured in AI for Service. |
| Storage | Do not paste secrets into tickets, chat, emails, or this SOP. Store them in the approved vault. |
| Rotation | Rotate the paired AI for Service Artemis access token and Artemis Webhook Secret together. |

## Troubleshooting Quick Reference

| Symptom | Likely cause | Recommended action |
|---|---|---|
| 401 or 403 response | Token mismatch or expired API key | Re-copy the Artemis auth token and verify the webhook secret. |
| Webhook events are not received | Incorrect callback URL or channel token | Verify the callback URL and XOCC Webhook Channel Token. |
| Wrong tenant or project is connected | Values copied from another workspace or project | Fetch tenant ID and project ID again from Agent Chat → Debug → Data or confirm Workspace ID in Profile. |
| Connection name rejected | Connection name is not unique | Use a new unique name. |
| Integration works before publish but not after changes | Changes saved but not published | Publish the AI for Service app again. |

## Handoff Notes

When handing this setup to operations or support, share the AI for Service app name, Artemis project name, environment, connection name, and date configured. Share secrets only through the approved vault or secret-sharing process.
