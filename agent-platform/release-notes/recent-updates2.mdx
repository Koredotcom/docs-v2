<Update label="August 8, 2026" description="v1.4.2">
  
  <Badge>Patch Release</Badge>

This update includes new features and enhancements summarized below.

<p className="rn-title">Tools</p>

<p className="rn-subtitle">Secure secret handling for tools and workflows</p>

Tools can now return sensitive values — API keys, tokens, credentials — without exposing them to the LLM. These values are captured into an encrypted, session-scoped vault and kept invisible to the model and the conversation transcript. Use the new `{{_secret.X}}` syntax to restore a captured secret into a downstream tool's HTTP headers or request body.
<br />[Learn more →](/agent-platform/abl-reference/tools#reuse-secrets-across-tools-secretref)

<p className="rn-title">Voice</p>

<p className="rn-subtitle">Configure a PSTN transfer target number</p>

You can now configure a dedicated Public Switched Telephone Network (PSTN) transfer target number for agent-initiated call transfers, alongside the existing SIP transfer configuration. Outbound PSTN transfers now correctly present the provisioned caller ID. 
<br />[Learn more →](/agent-platform/administration/agent-behavior-settings#voice-gateway)

<p className="rn-title">Channels</p>

<p className="rn-subtitle">New API scope for closing sessions</p>

Integrators using the API channel can now issue a platform API key scoped specifically to closing sessions (close-session), instead of requiring a full administrative key to terminate a conversation programmatically.
<br />[Learn more →](/agent-platform/deployment#scopes)

<p className="rn-subtitle"> Microsoft Teams: verified identity and thought streaming</p>

Microsoft Teams is now supported as a verified-identity channel, with identity enrichment, auth-profile-based credential mapping, and a new channel setup experience in Studio. Teams conversations can also now stream the agent's thinking or progress updates in real time, with a new streaming toggle in the Teams channel configuration.
<br />[Learn more →](/agent-platform/channels/digital#configuration)

</Update>



<Update label="August 1, 2026" description="v1.4.1">

<Badge>Patch Release</Badge>

This update includes new features and enhancements summarized below.

<p className="rn-title">Workflows</p>

<p className="rn-subtitle">Set a default value for data entry fields in Workflows</p>

Workflow builders can now set the default value of fields in a Data Entry node using either static text or expressions. Expressions can reference data from workflow triggers or previous workflow steps. For example, a reviewer's form can be pre-filled with an AI-generated draft for approval or editing.
<br />[Learn more →](/agent-platform/workflows#data-entry-node)

<p className="rn-title">SDK</p>

<p className="rn-subtitle">Control attachment visibility in the Web SDK</p>

The Web SDK Theme Builder now has a toggle to show or hide the attachment icon in the chat widget's compose bar. This lets FAQ and informational AI agents offer a cleaner, text-only interface when file uploads aren't needed, while keeping attachments enabled by default elsewhere.

<p className="rn-title">Analytics</p>

<p className="rn-subtitle">Control SQL query operations for public analytics widgets</p>

Admins can now allow or restrict specific query operations for public-facing analytics dashboard widgets, from a new SQL Validation section in the Public Widget Data Policy settings. Supported restrictions include SQL comments, multiple SELECT statements, JOIN clauses, common table expressions (CTEs), set operations (UNION, INTERSECT, EXCEPT), and OR conditions.
<br />[Learn more →](/agent-platform/administration/security-observability-settings#sql-validation)

</Update>
