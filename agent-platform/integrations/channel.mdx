title: Channel integrations
sidebarTitle: Overview

Channels connect deployed agents to the surfaces where users interact, including your own apps, voice calls, messaging apps, webhooks, and other agent frameworks. A [channel](/agent-platform/channels#channels) always binds to a deployment in a specific environment. Configure deployments first, then add channels.

| Category | Channels |
|----------|----------|
| Messaging or digital | [Slack](/agent-platform/channels/slack), [LINE](/agent-platform/channels/line), [Microsoft Teams](/agent-platform/channels/ms-teams-copilot), [WhatsApp](/agent-platform/channels/whatsapp), [Messenger](/agent-platform/channels/messenger), [Twilio SMS](/agent-platform/channels/twilio), [Telegram](/agent-platform/channels/telegram), [Zendesk](/agent-platform/channels/zendesk), [Instagram](/agent-platform/channels/instagram), [Genesys](/agent-platform/channels/genesys), [Genesys Open Messaging](/agent-platform/channels/genesys-open-messaging), Email, [AI for Work](/agent-platform/channels/ai-for-work), [Kore Agent Assist](/agent-platform/channels/kore-agent-assist) |
| Voice | [Realtime LLM Voice](/agent-platform/channels/voice#set-up-realtime-llm-voice-channel), [Pipeline Voice](/agent-platform/channels/voice#set-up-pipeline-voice-channel), VXML IVR, [Genesys Audio Connector](/agent-platform/channels/genesys-audio-connector), AudioCodes |
| SDK | [Web SDK](/agent-platform/channels/web-sdk-channel), API, Mobile SDK |
| Webhook | [Webhooks (HTTP Async)](/agent-platform/channels/webhook) |
| Protocols | [AG-UI (CopilotKit)](/agent-platform/channels/ag-ui-copilotkit), [Agent-to-Agent (A2A)](/agent-platform/channels/agent-to-agent) |
