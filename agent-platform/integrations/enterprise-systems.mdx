Enterprise system integrations connect your workflows to business applications such as Slack, Gmail, Jira, and Salesforce. Use the [Integration node](/agent-platform/workflows#integration-node) in a workflow to run connector actions, such as sending a Slack message, creating a Jira issue, or requesting approval by email. Each integration exposes a set of authenticated actions that you configure as workflow steps.

| Category            | Integrations              |
|:--------------------|:--------------------------|
| Communication       | [Amazon SES](/agent-platform/integrations/amazon-ses), Amazon SNS, Discord, Gmail, Microsoft Exchange, Microsoft Outlook, Microsoft Teams, SendGrid, Slack, Twilio |
| Productivity        | Asana, ClickUp, Confluence, Google Calendar, Google Docs, [Jira](/agent-platform/integrations/jira-actions), Linear, Microsoft Excel, Microsoft Outlook Calendar, Microsoft Power BI, Microsoft SharePoint, Notion |
| Storage             | Airtable, Amazon DynamoDB, Amazon S3, Azure Blob Storage, Azure Cosmos DB, Databricks, Google Drive, Google Sheets, Microsoft OneDrive, MongoDB, Oracle Database, Postgres |
| CRM and sales       | HubSpot, Microsoft Dynamics 365, Pipedrive, Salesforce, Shopify, Stripe |
| Service management  | ServiceNow, Zendesk |
| AI and development  | Anthropic Claude, GitHub, OpenAI, Microsoft Foundry |
| Document processing | Amazon Textract, Azure Document Intelligence, Docling |
| Others              | Amazon SQS |
