Enterprise system integrations connect your workflows to business applications such as Slack, Gmail, Jira, and Salesforce. Use the [Integration node](/agent-platform/workflows#integration-node) in a workflow to run connector actions, such as sending a Slack message, creating a Jira issue, or requesting approval by email. Each integration exposes a set of authenticated actions that you configure as workflow steps.
