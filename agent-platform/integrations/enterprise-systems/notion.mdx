Use the Notion integration to let agents create, update, find, and archive database items, create and append to pages, and read or add comments through Action Tools.

| Authentication | Actions | Workflow triggers |
| --- | --- | --- |

## Supported actions

Actions are Notion operations that an agent runs as Action Tools during a conversation. You can also run them from an [Integration node](/agent-platform/workflows#integration-node) in a workflow.

| Group | Actions |
| --- | --- |
| Databases | [Create Database Item](#create-database-item), [Update Database Item](#update-database-item), [Find Database Item](#find-database-item), [Archive Database Item](#archive-database-item), [Restore Database Item](#restore-database-item), [Retrieve Database Structure](#retrieve-database-structure) |
| Pages | [Create Page](#create-page), [Append to Page](#append-to-page), [Get block content](#get-block-content), [Find Page](#find-page) |
| Comments | [Add Comment](#add-comment), [Get Page Comments](#get-page-comments) |
| Advanced | [Custom API Call](#custom-api-call) |

## Workflow triggers

Triggers are Notion events that start a workflow automatically. Select them as [app triggers](/agent-platform/workflows#app-triggers) when you configure a workflow.

| Trigger | Fires when |
| --- | --- |
| New Database Item | An item is added to a database. |
| Updated Database Item | An item in a database is updated. |
| New Comment | A comment is added to a specific page. |
| Updated Page | A page in the workspace is updated. |

## Prerequisites

- A Notion workspace where you can create integrations.
- The Notion pages and databases shared with the integration during authorization. The agent can access only what you share.

## Set up the integration

<Steps>
  <Step title="Create a Notion public integration">
    In [Notion integrations](https://www.notion.so/profile/integrations), create a **Public** integration, add the Artemis **Callback URL** as a redirect URI, and copy the **OAuth client ID** and **OAuth client secret**. See [Authorization](https://developers.notion.com/docs/authorization).
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Notion** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Notion** > **Continue**. Enter the **Client ID** and **Client Secret**, select **Create Profile**, and then select **Authorize**. In the Notion consent screen, select the pages to share. Artemis pre-fills the Notion endpoints and the `owner=user` parameter. Notion doesn't use scopes.

    **Usage Mode**: **Preconfigured** shares one authorization across users; **JIT** and **Preflight** ask each user to authorize, during or before the session. See [Auth profiles](/agent-platform/administration/integrations-settings#auth-profiles).
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Notion** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `redirect_uri` error during authorization | Add the exact **Callback URL** to the integration's redirect URIs. |
| Database or page lists are empty | Share the pages or databases with the integration. Authorize again and select them, or use **Connections** on the page in Notion. |
| `object_not_found` | The integration can't access the page or database. Share it with the integration. |
| Field values are rejected | Use **Retrieve Database Structure** to check field names and types. |
