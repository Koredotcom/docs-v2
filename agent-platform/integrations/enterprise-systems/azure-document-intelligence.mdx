Use the Azure Document Intelligence integration to let agents and workflows extract layout-aware content, such as text, tables, and structure, from documents.

| Authentication | Actions | Workflow triggers |
| --- | --- | --- |
| API Key | [1](#supported-actions) | None |

## Supported actions

Actions are Azure Document Intelligence operations that an agent runs as Action Tools during a conversation. You can also run them from an [Integration node](/agent-platform/workflows#integration-node) in a workflow.

| Action | Use it to |
| --- | --- |
| [Extract Document](#extract-document) | Extract content with a prebuilt model. |

## Prerequisites

- An Azure AI Document Intelligence resource, with its endpoint and key from **Keys and Endpoint** in the Azure portal.

## Set up the integration

<Steps>
  <Step title="Create the auth profile">
    In **Integrations**, select **Azure Document Intelligence** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Azure Document Intelligence** > **Continue**. Configure the fields, and select **Create Profile**.

    | Field | Value |
    | --- | --- |
    | **Endpoint** | Required. For example `https://<resource>.cognitiveservices.azure.com`, with no trailing slash. |
    | **API Version** | Leave empty to use the current GA version (`2024-11-30`). Set it only if your resource needs an older version. |
    | **API Key** | Resource key. Artemis sends it in the `Ocp-Apim-Subscription-Key` header. |
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Azure Document Intelligence** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Action reference

<AccordionGroup>
  <Accordion title="Extract Document" id="extract-document">
    | Parameter | Type | Description |
    | --- | --- | --- |
    | `fileUrl` | string | Public HTTP(S) URL of the document. The response can be up to 10 MB. |
    | `model` | enum | Prebuilt model. Default: `Layout` (text, tables, and structure). |
    | `pages` | string | Optional page range, for example `1-5` or `1,3,7`. |
    | `timeout` | number | Maximum seconds, from 5 to 1800. Default: 120. |
  </Accordion>
</AccordionGroup>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `401 Access denied` | Check the key and that it belongs to the **Endpoint** resource. |
| `404` on every request | Remove any trailing slash or path from **Endpoint**. |
| `InvalidRequest` for the API version | Clear **API Version**, or set the version your resource supports. |
| The document can't be downloaded | Use a public URL that returns the file directly. |
