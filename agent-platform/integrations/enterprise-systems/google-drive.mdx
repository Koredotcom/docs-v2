Use the Google Drive integration to create, find, read, upload, move, and delete files and folders, export documents as PDFs, and manage sharing permissions through Action Tools. It also provides triggers for new files and folders.

| Authentication | Actions | Triggers |
| --- | --- | --- |
| OAuth 2.0 | ([16](/agent-platform/integrations/enterprise-systems/google-drive#supported-actions)) | ([2](/agent-platform/integrations/enterprise-systems/google-drive#triggers)) |

## Supported actions

| Action | Use it to |
| --- | --- |
| [Create new folder](#create-new-folder) | Create a folder in Google Drive. |
| [Create new file](#create-new-file) | Create a text file from text. |
| [Read File Content](#read-file-content) | Read the contents of a file. |
| [Get File Information](#get-file-information) | Retrieve file or folder information by ID. |
| [List files](#list-files) | List files in a Drive folder. |
| [Search](#search) | Search a Drive folder for files or subfolders. |
| [Duplicate File](#duplicate-file) | Copy a file and return the new file ID. |
| [Save Document as PDF](#save-document-as-pdf) | Save a Google document as a PDF in Drive. |
| [Update permissions](#update-permissions) | Add or update a user's permission on a file or folder. |
| [Delete permissions](#delete-permissions) | Remove a user's permission from a file or folder. |
| [Set public access](#set-public-access) | Set public access for a file or folder. |
| [Move File](#move-file) | Move a file to another folder. |
| [Delete file](#delete-file) | Permanently delete a file from Drive. |
| [Trash file](#trash-file) | Move a file to the trash. |
| [Custom API Call](#custom-api-call) | Call a Google Drive API endpoint. |
| [Upload File](#upload-file) | Upload a file to Drive. |

## Triggers

| Trigger | Fires when |
| --- | --- |
| New File | A file is uploaded. Optionally select a parent folder, include Team Drives, and include file content in the trigger output. Including file content takes longer and may cause issues with large files. |
| New Folder | A folder is created or uploaded. Optionally select a parent folder and include Team Drives. |

## Prerequisites

- A Google account with access to the Drive files and folders used by your tools.
- Permission to authorize the Google Drive OAuth access requested in Studio. The connector requests the Google Drive scope `https://www.googleapis.com/auth/drive`.

## Set up the integration

<Steps>
  <Step title="Connect Google Drive">
    In **Integrations**, select **Google Drive** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Google Drive** > **Continue**. Complete the OAuth 2.0 profile setup and authorize the Google account that has access to the files and folders your tools will use.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Google Drive** > **Continue**. Select the **Action** and **Auth Profile**, configure the inputs, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

</AccordionGroup>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| OAuth authorization fails | Confirm that you authorized the Google account with access to the required Drive items and approved the requested Drive permissions. |
| An action can't find a file or folder | Verify the ID and confirm the authorized account can access that item. |
| Permission changes fail | Confirm that the account can manage sharing for the specified file or folder. |
| A file isn't returned by a trigger | Check the selected parent folder and whether Team Drive folders are included. |
| File content is missing from the New File trigger | Enable **Include File Content**. Large files may take longer to fetch. |
