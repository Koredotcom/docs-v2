Use the Amazon S3 integration to upload, read, list, move, and delete files, generate signed URLs, and decrypt PGP-encrypted files through Action Tools. It also provides a trigger for new or updated files.

| Authentication | Actions | Triggers |
| --- | --- | --- |
| AWS IAM | ([7](/agent-platform/integrations/enterprise-systems/amazon-s3-integrations#supported-actions)) | ([1](/agent-platform/integrations/enterprise-systems/amazon-s3-integrations#triggers)) |

## Supported actions

| Action | Use it to |
| --- | --- |
| [Upload File](#upload-file) | Upload a file to S3. |
| [Read File](#read-file) | Read an S3 file for use in later steps. |
| [Generate Signed URL](#generate-signed-url) | Generate a signed URL for an S3 object. |
| [Move File](#move-file) | Move a file to another folder. |
| [Delete File](#delete-file) | Delete an S3 object. |
| [List Files](#list-files) | List files in an S3 bucket folder or prefix. |
| [Decrypt PGP File](#decrypt-pgp-file) | Decrypt an S3 file using a private key stored in AWS Secrets Manager. |

## Triggers

| Trigger | Fires when |
| --- | --- |
| New or Updated File | A file is added or updated in the selected bucket or folder. The selected location must contain no more than 10,000 files. **Markdown** and **Folder Path** are optional settings. |

## Prerequisites

- An AWS account and IAM credentials with access to the S3 bucket and operations used by your actions.
- For **Decrypt PGP File**, a private key stored in AWS Secrets Manager and permission to access the secret.

## Set up the integration

<Steps>
  <Step title="Prepare AWS IAM credentials">
    Prepare AWS IAM credentials and the Region for the S3 bucket. Ensure the IAM principal has permission to perform the S3 operations used by your actions. For **Decrypt PGP File**, it also needs permission to retrieve the private key from AWS Secrets Manager. See [Using identity-based policies for Amazon S3](https://docs.aws.amazon.com/AmazonS3/latest/userguide/security_iam_service-with-iam.html).
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Amazon S3** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Amazon S3** > **Continue**. Configure the AWS IAM credentials and select **Create Profile**.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Amazon S3** > **Continue**. Select the **Action** and **Auth Profile**, configure the inputs, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Action reference

The required inputs below are listed in the connector catalog.

    Required inputs: `fileKey` and `folderKey`.
  </Accordion>
  <Accordion title="Delete File" id="delete-file">

  </Accordion>
  <Accordion title="List Files" id="list-files">
    No required inputs are listed in the connector catalog.
  </Accordion>
  <Accordion title="Decrypt PGP File" id="decrypt-pgp-file">

  </Accordion>
</AccordionGroup>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| An S3 action returns an access error | Confirm the IAM principal has the required S3 permissions for the bucket and operation. |
| **Read File**, **Move File**, or **Delete File** can't find an object | Verify the S3 object key or folder path. |
| **Decrypt PGP File** fails | Verify `secretArn` identifies the private key secret and that the IAM principal can access it. |
| The trigger doesn't detect a file | Confirm the selected bucket or folder contains no more than 10,000 files. |
