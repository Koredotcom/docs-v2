Use the Zendesk integration to create and manage support tickets, organizations, and users through Action Tools. It also provides triggers for ticket, organization, and user events.

## Triggers

| Trigger | Fires when |
| --- | --- |
| New ticket in view | A new ticket is created in the selected view. |
| New Ticket | A ticket is created, optionally filtered by organization. Requires a Zendesk Trigger with **Notify active webhook**. |
| Updated Ticket | An existing ticket is updated. Requires a Zendesk Trigger with **Notify active webhook**. |
| Tag Added to Ticket | A ticket update adds the selected tag, or any tag if no tag is specified. Requires a Zendesk Trigger with **Notify active webhook**. |
| New Organization | An organization is created. Uses a Zendesk event webhook; no Zendesk Trigger is needed. |
| New User | A user is created, optionally filtered by role. Uses a Zendesk event webhook; no Zendesk Trigger is needed. |
| New Suspended Ticket | A ticket is suspended. Suspended tickets are automatically deleted after 14 days. Requires a Zendesk Trigger with **Notify active webhook**. |
| New Action on Ticket | The specified ticket is updated. Requires a Zendesk Trigger with **Notify active webhook**. |

## Prerequisites

- A Zendesk account and its subdomain.
- A Zendesk agent email and API token, or an OAuth 2.0 access token.
- For triggers that require **Notify active webhook**, a Zendesk Trigger configured to send the event to the webhook endpoint used by the integration.

## Set up the integration

<Steps>
  <Step title="Connect Zendesk">
    In **Integrations**, select **Zendesk** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Zendesk** > **Continue**. Configure the profile with your Zendesk subdomain and either OAuth 2.0 credentials or an API token. For an API token, provide the email address of the Zendesk agent it belongs to; leave the email empty for OAuth 2.0. Save the profile.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Zendesk** > **Continue**. Select the **Action** and **Auth Profile**, configure the inputs, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Authentication fails | Check the Zendesk subdomain and token. For an API token, provide the matching Zendesk agent email; leave it empty for OAuth 2.0. |
| An action can't find a record | Verify the record ID and confirm that the authorized account can access it. |
| A webhook trigger doesn't fire | Confirm that the Zendesk Trigger is active, uses **Notify active webhook**, and targets the integration's webhook endpoint. |
| A ticket trigger returns no events | Check the selected view, organization filter, tag, or ticket ID. Suspended tickets are automatically deleted after 14 days. |
