## Supported actions

Actions are Google Docs operations that an agent runs as Action Tools during a conversation. You can also run them from an [Integration node](/agent-platform/workflows#integration-node) in a workflow.

| Action | Use it to |
| --- | --- |
| [Create Document](#create-document) | Create a document. |
| [Read Document](#read-document) | Read a document's content. |
| [Find Document](#find-document) | Find a document by name, and optionally create it. |
| [Append text to google docs](#append-text-to-google-docs) | Append text to the end of a document. |
| [Edit template file](#edit-template-file) | Fill a template document's placeholders with values. |
| [Custom API Call](#custom-api-call) | Call any API endpoint the other actions don't cover. |

## Prerequisites

- A Google Cloud project with the **Google Docs API** and **Google Drive API** enabled, and an OAuth consent screen.

## Set up the integration

<Steps>
  <Step title="Create a Google OAuth client">
    Create an OAuth client ID of type **Web application**, add the Artemis **Callback URL** to **Authorized redirect URIs**, and copy the **Client ID** and **Client Secret**. See [Using OAuth 2.0 to access Google APIs](https://developers.google.com/identity/protocols/oauth2).
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Google Docs** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Google Docs** > **Continue**. Enter the **Client ID** and **Client Secret**, select **Create Profile**, and then select **Authorize**. Artemis pre-fills the Google endpoints. {/* TODO: list pre-filled scopes */}

    **Usage Mode**: **Preconfigured** shares one authorization across users; **JIT** and **Preflight** ask each user to authorize, during or before the session. See [Auth profiles](/agent-platform/administration/integrations-settings#auth-profiles).
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Google Docs** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `redirect_uri_mismatch` | Add the exact **Callback URL** to the OAuth client's **Authorized redirect URIs**. |
| `403 Insufficient Permission` | Confirm the profile's scopes cover the action, and then authorize again. |
| Placeholders aren't replaced | Match **placeholder_format** to the template, and enter key names in `values` without brackets. |
| Document not found | Share the document with the authorized account, or check the document ID in its URL. |
