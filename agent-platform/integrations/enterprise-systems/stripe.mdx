Use the Stripe integration to manage customers, invoices, subscriptions, products, prices, payments, refunds, and payment links through Action Tools. It also provides triggers for payment, customer, subscription, invoice, refund, dispute, and checkout events.

## Triggers

| Trigger | Fires when |
| --- | --- |
| New Payment | A payment is made. |
| New Customer | A customer is created. |
| Payment Failed | A payment fails. |
| New Subscription | A subscription is created. |
| New Charge | A charge is successfully completed. |
| New Invoice | An invoice is created, optionally filtered by status, customer, or subscription. |
| Invoice Payment Failed | A payment against an invoice fails, optionally filtered by customer. |
| Canceled Subscription | A subscription is canceled, optionally filtered by customer. |
| New Refund | A charge is refunded, optionally filtered by charge or Payment Intent. |
| New Dispute | A customer disputes a charge, optionally filtered by charge or Payment Intent. |
| New Payment Link | A payment link is created. |
| Updated Subscription | A subscription changes, optionally filtered by status or customer. |
| Checkout Session Completed | A Stripe Checkout Session is successfully completed, optionally filtered by customer. |

## Prerequisites

- A Stripe account with access to the customers, products, payments, and other resources your tools will use.
- A Stripe secret API key, or a Stripe account and OAuth app for OAuth 2.0 authorization.
- The account or API key must have the permissions required for the selected actions and triggers.

## Set up the integration

<Steps>
  <Step title="Create a Stripe auth profile">
    In **Tools**, select **New Tool** > **Action** > **Stripe** > **Continue**, then select **Manage profiles**. In **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Stripe** > **Continue**. Choose **OAuth 2.0** or **API Key**. For OAuth 2.0, enter the client ID and secret and add the callback URL shown in Studio to your Stripe OAuth app. For API Key, enter the Stripe secret key. Save the profile and authorize it when using OAuth 2.0.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Stripe** > **Continue**. Select the **Action** and **Auth Profile**, configure the inputs, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Authentication fails | Check the Stripe API key or OAuth client credentials and confirm the profile has access to the account and operations used by the tool. |
| An action can't find a customer, invoice, or subscription | Verify the Stripe object ID and confirm the authorized account can access it. |
| An action is missing required permissions | Check the API key permissions or OAuth authorization for the selected Stripe operation. |
| A trigger doesn't return expected events | Check the event type and optional status, customer, subscription, charge, or Payment Intent filters. |
