## Prerequisites

- A Shopify store and a user with permission to install or authorize an app and access the resources your tools need.
- A Shopify app configured for the chosen authentication method, with API access scopes appropriate for the actions and triggers you plan to use.
- The store's Shopify subdomain. Studio asks for the subdomain used in `<subdomain>.myshopify.com`.

## Set up the integration

<Steps>
  <Step title="Create a Shopify auth profile">
    In **Tools**, select **New Tool** > **Action** > **Shopify** > **Continue**, then select **Manage profiles**. In **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Shopify** > **Continue**. Choose **OAuth 2.0**, **OAuth 2.0 Client Credentials**, or **API Key**. Enter the Shopify store subdomain and the credentials for that method. For OAuth 2.0, add the callback URL shown in Studio to the Shopify app and authorize the profile. For Client Credentials, choose **Client Secret** or **JWT assertion** and provide the matching settings. For API Key, use the Shopify Admin API access token.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Shopify** > **Continue**. Select the **Action** and **Auth Profile**, configure the inputs, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Authentication fails | Check the store subdomain and credentials. Confirm the Shopify app has the required API scopes and that the auth profile uses the matching OAuth 2.0, Client Credentials, or API Key method. |
| An action can't find or update a resource | Verify the Shopify resource ID and confirm the app or token has access to that resource and operation. |
| A product query returns no results | Check the title, vendor, product type, and status filters. Increase the result limit if needed; the maximum is 250. |
| A GraphQL query fails | Check the query syntax and declare each variable in the GraphQL operation. Use the generated variable inputs or provide additional values in `variables`. |
| A trigger doesn't return events | Confirm the selected auth profile belongs to the expected store and that the app has access to the relevant event data. |
