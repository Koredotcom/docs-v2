## Prerequisites

- A Pipedrive account with access to the records and features your tools will use.
- Permission to authorize the Pipedrive OAuth access requested in the integration profile. The connector requests these scopes: `base`, `admin`, `contacts:full`, `users:read`, `deals:full`, `activities:full`, `leads:full`, `products:full`, `webhooks:full`.

## Set up the integration

<Steps>
  <Step title="Connect Pipedrive">
    In **Integrations**, select **Pipedrive** > **Connect**. Create an **Integration Profile** for Pipedrive, complete the OAuth 2.0 setup, and authorize the Pipedrive account your tools will use.
  </Step>
  <Step title="Create an action tool">
    In **Tools**, select **New Tool** > **Action** > **Pipedrive** > **Continue**. Select the action and auth profile, configure its inputs, and create the tool. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| OAuth authorization fails | Confirm the Pipedrive OAuth profile is configured and authorize the account that has access to the records used by your tools. |
| A record, owner, label, or pipeline option is missing | Check that it exists in the connected Pipedrive account and that the authorized user can access it. |
| A trigger doesn't fire | Check the selected filter, deal status, watched field, or pipeline stage settings. Matching-filter triggers fire when an item newly matches the selected filter. |
| An action fails to find or update a record | Verify the record ID and required fields for the selected Pipedrive object. |
