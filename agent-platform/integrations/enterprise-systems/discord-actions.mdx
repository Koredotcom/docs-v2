Use the Discord integration to let agents post messages, request approvals, and manage guild channels, roles, and members through Action Tools.

| Authentication | Actions | Triggers |
| --- | --- | --- |
| OAuth 2.0, API Key | 16 | 2 ([use in workflows](/agent-platform/workflows#app-triggers)) |

## Supported actions

| Action | Use it to |
| --- | --- |
| [Send Message with Bot](#send-message-with-bot) | Post a message, with optional attachments, to a channel or thread as your bot. |
| [Send Message Webhook](#send-message-webhook) | Post a message through a channel webhook. |
| [Request Approval in a Channel](#request-approval-in-a-channel) | Post an approval request and wait for a response. |
| [Find channel](#find-channel) | Find a channel by name. |
| [Create channel](#create-channel) | Create a channel in a guild. |
| [Rename channel](#rename-channel) | Rename a channel. |
| [Delete channel](#delete-channel) | Delete a channel. |
| [List guild members](#list-guild-members) | List or search the members of a guild. |
| [Add role to member](#add-role-to-member) | Assign a role to a member. |
| [Remove role from member](#remove-role-from-member) | Remove a role from a member. |
| [Create guild role](#create-guild-role) | Create a role in a guild. |
| [Delete guild role](#delete-guild-role) | Delete a role from a guild. |
| [Remove member from guild](#remove-member-from-guild) | Remove (kick) a member from a guild. |
| [Ban guild member](#ban-guild-member) | Ban a member from a guild. |
| [Remove ban from user](#remove-ban-from-user) | Lift a ban on a user. |
| [Custom API Call](#custom-api-call) | Call any Discord API endpoint the other actions don't cover. |

## Triggers

| Trigger | Fires when |
| --- | --- |
| New message | A message is sent in a channel. |
| New Member | A new member joins a guild. |

## Prerequisites

- A Discord application with a bot user in the [Developer Portal](https://discord.com/developers/applications), invited to your guild with the permissions your actions need.
- The bot role ranked above any role the agent manages.

## Set up the integration

<Steps>
  <Step title="Prepare the Discord app">
    Copy the **Client ID** and **Client Secret** from **OAuth2** (for OAuth 2.0), or the bot **Token** from **Bot** (for API Key).
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Discord** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Discord** > **Continue**. Configure the fields, select **Create Profile**, and for OAuth 2.0 select **Authorize**.

    <Tabs>
      <Tab title="OAuth 2.0">
        Artemis pre-fills the Discord authorization, token, and refresh URLs. Enter **Scopes** (for example `bot guilds`), **Client ID**, and **Client Secret**, and add the read-only **Callback URL** under **OAuth2** > **Redirects** in the Developer Portal.

        **Usage Mode**: **Preconfigured** shares one authorization across users; **JIT** and **Preflight** ask each user to authorize, during or before the session. See [Auth profiles](/agent-platform/administration/integrations-settings#auth-profiles).
      </Tab>
      <Tab title="API Key">
        Set **Header Name** to `Authorization` (default `X-API-Key`), **Prefix** to `Bot ` (with a trailing space), and **API Key** to the bot token.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Discord** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Authorization fails or doesn't complete | Verify that the **Callback URL** in the profile exactly matches a redirect in the Discord Developer Portal. |
| Channel, guild, or role lists are empty | Confirm the bot is a member of the guild and can view the channels. |
| `401 Unauthorized` with an **API Key** profile | Confirm **Header Name** is `Authorization` and **Prefix** is `Bot `, and that the bot token is current. |
| `50013 Missing Permissions` | Grant the bot the required permission, and move the bot role above the roles it manages. |
| Webhook messages fail | Confirm the webhook still exists in the channel settings and the URL is complete. |
