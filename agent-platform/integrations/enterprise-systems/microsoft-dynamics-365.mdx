Use the Microsoft Dynamics 365 Business Central integration to create, retrieve, update, delete, and search records, and to call Business Central API endpoints through Action Tools. It also provides a trigger for new or updated records.

| Authentication | Actions | Triggers |
| --- | --- | --- |
| Client Credentials | ([6](#supported-actions)) | ([1](#triggers)) |

## Supported actions

| Action | Use it to |
| --- | --- |
| [Create Record](#create-record) | Creates a new record. |
| [Delete Record](#delete-record) | Deletes an existing record. |
| [Get Record](#get-record) | Retrieves the details of a record by it's ID. |
| [Update Record](#update-record) | Updates an existing record. |
| [Search Records](#search-records) | Retrieves a list of records. |
| [Custom API Call](#custom-api-call) | Make a custom API call to a specific endpoint |

## Triggers

| Trigger | Fires when |
| --- | --- |
| [New or Updated Record](#new-or-updated-record) | A record is added or modified in a selected company and record type. |

## Prerequisites

- A Microsoft Dynamics 365 Business Central environment with access to the companies and records your tools will use.
- An Entra ID application and Client Credentials profile with permission to access the Business Central API.

## Set up the integration

<Steps>
  <Step title="Connect Business Central">
    In **Integrations**, select **Microsoft Dynamics 365 Business Central** > **Connect**. Create a **Client Creds** integration profile with your Entra ID application details and authorize access to the Business Central environment.
  </Step>
  <Step title="Create an action tool">
    In **Tools**, select **New Tool** > **Action** > **Microsoft Dynamics 365 Business Central** > **Continue**. Select the action and auth profile, configure its inputs, and create the tool. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Authentication fails | Verify the Entra ID application details and confirm the Client Credentials profile has access to Business Central. |
| A company or record type is unavailable | Confirm the selected environment and company, then check that the connected application can access that company and record type. |
| An action cannot find or update a record | Verify the company, record type, record ID, and field names for the selected record. |
| A custom API call fails | Check the endpoint, HTTP method, headers, query parameters, and request body against the Business Central API. |
