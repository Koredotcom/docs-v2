Use the Airtable integration to create, find, update, and delete records, manage bases and tables, upload attachments, and add comments through Action Tools.

| Authentication | Actions | Triggers |
| --- | --- | --- |
| API Key | ([15](/agent-platform/integrations/enterprise-systems/airtable#supported-actions)) | ([2](/agent-platform/integrations/enterprise-systems/airtable#triggers)) |

## Supported actions

| Action | Use it to | Required inputs |
| --- | --- | --- |
| Create Airtable Record | Add a record to a table. | `base`, `tableId`, `fields` |
| Find Airtable Record | Find a record by field and value. | `base`, `tableId`, `searchField`, `searchValue` |
| Update Airtable Record | Update fields in a record. | `base`, `tableId`, `recordId`, `fields` |
| Clean Record | Clear fields in a record. Empty values clear the corresponding fields. | `base`, `tableId`, `recordId`, `fields` |
| Delete Airtable Record | Delete a record. | `base`, `tableId`, `recordId` |
| Upload File to Column | Upload a file to an attachment column. | `base`, `tableId`, `attachment_column`, `recordId`, `file`, `file_content_type` |
| Add Comment to Record | Add a comment to a record. | `base`, `tableId`, `recordId`, `text` |
| Create Base | Create a base with a table structure. | `workspaceId`, `name`, `tables` |
| Create Table | Create a table in a base. | `base`, `name`, `fields` |
| Find Base | Find a base by name or keyword. | `baseName` |
| Find Table by ID | Get a table's details and schema by ID. | `base`, `tableId` |
| Get Record by ID | Retrieve a record by its ID. | `base`, `tableId`, `recordId` |
| Find Table | Find a table by name. | `base`, `tableName` |
| Get Base Schema | Retrieve a base's tables and fields. | `base` |
| Custom API Call | Call an Airtable API endpoint. | `url`, `method`, `headers`, `queryParams` |

## Triggers

| Trigger | Fires when | Configuration |
| --- | --- | --- |
| New Record | A record is added to a table. | **Base** and **Table** are required; **View** is optional. |
| New or Updated Record | A record is created or updated in a table. | **Base**, **Table**, and **Trigger field** are required; **View** is optional. Use a Last Modified Time field to detect updates. |

## Prerequisites

- An Airtable API credential with access to the bases and operations used by your action tools.

## Set up the integration

<Steps>
  <Step title="Create the auth profile">
    In **Integrations**, select **Airtable** > **Manage**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Airtable** > **Continue**. Select **API Key**, enter your Airtable credential, and create the profile.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Airtable** > **Continue**. Select the **Action** and **Auth Profile**, configure the required inputs, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| A base or table is unavailable | Confirm that the Airtable credential can access it. |
| **New or Updated Record** does not detect changes | Select a suitable **Trigger field**. Airtable uses a Last Modified Time field to watch for record changes. |
| File upload fails | Confirm that the selected column is an attachment field. |
| **Find Airtable Record** fails | Provide the base, table, search field, and search value. |
