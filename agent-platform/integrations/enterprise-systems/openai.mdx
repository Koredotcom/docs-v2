## Supported actions

Actions are OpenAI operations that an agent runs as Action Tools during a conversation. You can also run them from an [Integration node](/agent-platform/workflows#integration-node) in a workflow.

| Group | Actions |
| --- | --- |
| Text and vision | [Ask ChatGPT](#ask-chatgpt), [Ask Assistant](#ask-assistant), [Vision Prompt](#vision-prompt), [Extract Structured Data from Text](#extract-structured-data-from-text) |
| Images and audio | [Generate Image](#generate-image), [Text-to-Speech](#text-to-speech), [Transcribe Audio](#transcribe-audio), [Translate Audio](#translate-audio) |
| Advanced | [Custom API Call](#custom-api-call) |

## Prerequisites

- An [OpenAI API key](https://platform.openai.com/api-keys) with access to the models you plan to use.

## Set up the integration

<Steps>
  <Step title="Create the auth profile">
    In **Integrations**, select **OpenAI** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **OpenAI** > **Continue**. Paste the key into **API Key**, keep **Header Name** (`authorization`) and **Prefix** (`Bearer `), and select **Create Profile**.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **OpenAI** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `401 invalid_api_key` | Check the API key and its project. |
| `404 model_not_found` | Select a model your key can access. |
| `429` errors | Check your rate limits and billing in the OpenAI dashboard. |
| Image isn't analyzed | Use a public HTTPS URL that returns the image directly. |
