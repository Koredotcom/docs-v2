Use the Amazon DynamoDB integration to list and describe tables, read and write items, query and scan data, and delete items through Action Tools.

| Authentication | Actions |
| --- | --- |
| AWS IAM | ([8](/agent-platform/integrations/enterprise-systems/amazon-dynamodb-integrations#supported-actions)) |

## Supported actions

| Action | Use it to |
| --- | --- |
| [List Tables](#list-tables) | List DynamoDB table names. |
| [Describe Table](#describe-table) | Retrieve table metadata. |
| [Get Item](#get-item) | Read an item by its primary key. |
| [Put Item](#put-item) | Create or replace an item. |
| [Update Item](#update-item) | Update an item with an update expression. |
| [Delete Item](#delete-item) | Delete an item by its primary key. |
| [Query Items](#query-items) | Query by partition key and optional sort-key expression. |
| [Scan Items](#scan-items) | Scan a table. Prefer Query Items for production workloads. |

## Prerequisites

- An AWS Region and IAM credentials with `dynamodb:ListTables` permission for profile validation and the DynamoDB permissions required by the actions you plan to use.
- For temporary credentials, the session token associated with the access key and secret access key.

## Set up the integration

<Steps>
  <Step title="Prepare AWS IAM credentials">
    Ensure the IAM principal has `dynamodb:ListTables` permission and the permissions required for the selected actions. Note the AWS Region and obtain the **Access Key ID** and **Secret Access Key**. Include the **Session Token** when using temporary credentials. See [Using identity-based policies for DynamoDB](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/security_iam_service-with-iam.html).
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Amazon DynamoDB** > **Manage**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Amazon DynamoDB** > **Continue**. Enter the **Access Key ID**, **Secret Access Key**, and **Region**; add the **Session Token** if required, then create the profile.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Amazon DynamoDB** > **Continue**. Select the **Action** and **Auth Profile**, configure the inputs, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Profile validation fails | Verify the access key, secret, and Region, and confirm the principal can call `dynamodb:ListTables`. |
| An action returns `AccessDeniedException` | Grant the IAM principal the DynamoDB permissions required for that action and table. |
| **Query Items** returns no expected items | Check the partition-key condition and any sort-key or filter expressions. |
| **Scan Items** is slow | Use **Query Items** when the request can be expressed with a partition key. |
