Use the Microsoft Teams integration to let agents post and read messages, create channels and chats, find members, and request approvals through Microsoft Graph. To let users talk to an agent inside Teams, deploy the agent to the Teams channel instead.

| Authentication | Actions | Triggers |
| --- | --- | --- |
| OAuth 2.0 App (User Delegated), Azure AD (Service Principal) | 14 | 4 ([use in workflows](/agent-platform/workflows#app-triggers)) |

## Supported actions

| Action | Use it to |
| --- | --- |
| [Send Channel Message](#send-channel-message) | Post a message to a channel, with optional @mentions. |
| [Reply to Channel Message](#reply-to-channel-message) | Reply to a channel message thread. |
| [Send Chat Message](#send-chat-message) | Post a message in an existing chat. |
| [Create Chat & Send Message](#create-chat-and-send-message) | Start a chat with members and send the first message. |
| [Get Channel Message](#get-channel-message) | Read a channel message or one of its replies. |
| [Get Chat Message](#get-chat-message) | Read a chat message. |
| [Delete Chat Message](#delete-chat-message) | Soft-delete a chat message the connected account sent. |
| [Create Channel](#create-channel) | Create a standard channel in a team. |
| [Create Private Channel](#create-private-channel) | Create a private channel in a team. |
| [Find Channel](#find-channel) | Find channels by name. |
| [Find Team Member](#find-team-member) | Find a team member by email or display name. |
| [Request Approval in Channel](#request-approval-in-channel) | Post an approval request to a channel and wait for a response. |
| [Request Approval from a User](#request-approval-from-a-user) | Send an approval request in a chat and wait for a response. |
| [Custom API Call](#custom-api-call) | Call any Microsoft Graph endpoint the other actions don't cover. |

## Triggers

| Trigger | Fires when |
| --- | --- |
| New Channel Message | A message is posted in a channel. |
| New Channel | A channel is created in a team. |
| New Chat | A chat is created. |
| New Chat Message | A message is received in a chat. |

<Warning>Microsoft Graph doesn't allow app-only message sending. Use **OAuth 2.0 App (User Delegated)** for message and approval actions; use **Azure AD (Service Principal)** only for reading and managing teams and channels.</Warning>

## Set up the integration

<Steps>
  <Step title="Register an Entra ID app">
    Register an app in [Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-register-app), create a client secret, and copy the **Application (client) ID**, **Directory (tenant) ID**, and secret value. Add the scopes listed in the next step as Microsoft Graph permissions (**Delegated** or **Application**), grant admin consent, and for delegated access add the Artemis **Callback URL** as a **Web** redirect URI.
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Microsoft Teams** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Microsoft Teams** > **Continue**. Select an **Auth Type**, configure the fields, and select **Create Profile**. For delegated access, select **Authorize**.

    <Tabs>
      <Tab title="OAuth 2.0 App (User Delegated)">
        Artemis pre-fills the `common` Microsoft identity platform endpoints and these scopes: `openid`, `email`, `profile`, `offline_access`, `User.Read`, `User.ReadBasic.All`, `Team.ReadBasic.All`, `TeamMember.Read.All`, `Channel.Create`, `Channel.ReadBasic.All`, `ChannelMessage.Send`, `ChannelMessage.Read.All`, `Chat.ReadWrite`, `Presence.Read.All`. Enter **Client ID** and **Client Secret**.

        **Usage Mode**: **Preconfigured** shares one authorization across users; **JIT** and **Preflight** ask each user to authorize, during or before the session. See [Auth profiles](/agent-platform/administration/integrations-settings#auth-profiles).
      </Tab>
      <Tab title="Azure AD (Service Principal)">
        Enter **Azure Tenant ID**, **Scopes** (`https://graph.microsoft.com/.default`), **Client ID**, and **Client Secret**. Keep **Resource** as `https://graph.microsoft.com`.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Microsoft Teams** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `AADSTS50011` redirect URI mismatch | Add the exact **Callback URL** as a **Web** redirect URI in the app registration. |
| `AADSTS65001` consent required | Grant admin consent for the API permissions, and then authorize again. |
| Message actions fail with an app-only profile | Graph blocks app-only message sending. Use an **OAuth 2.0 App (User Delegated)** profile. |
| Team or channel dropdowns are empty | Confirm the connected account is a member of the team, and the profile includes `Team.ReadBasic.All` and `Channel.ReadBasic.All`. |
| Mentions appear as plain text | Use `@username` for a member of the team, and confirm the member exists with **Find Team Member**. |
| **Delete Chat Message** fails | You can delete only messages that the connected account sent. |
