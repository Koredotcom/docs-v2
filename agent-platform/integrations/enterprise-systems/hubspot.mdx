## Prerequisites

- A HubSpot account with access to the CRM objects, lists, workflows, files, or content used by your tools.
- Permission to authorize the HubSpot OAuth access requested by the integration profile.

## Set up the integration

<Steps>
  <Step title="Connect HubSpot">
    In **Integrations**, select **HubSpot** > **Connect**. Create an **Integration Profile** for HubSpot, complete the OAuth 2.0 setup, and authorize the account your tools will use. Use the scopes and redirect URI shown in the profile setup.
  </Step>
  <Step title="Create an action tool">
    In **Tools**, select **New Tool** > **Action** > **HubSpot** > **Continue**. Select the action and auth profile, configure its inputs, and create the tool. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

| A CRM action or trigger can't find a record or property | Verify the record ID, object type, and the authorized account's access. For property-change triggers, select a property available for that object. |
| A list, workflow, form, or pipeline is missing | Confirm it exists in the authorized HubSpot account and that the profile grants the access required by the integration. |
| A tool can't upload or retrieve a file | Check the file inputs and confirm the HubSpot account and profile can access File Manager. |
