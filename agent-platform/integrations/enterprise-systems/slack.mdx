## Workflow triggers

Triggers are Slack events that start a workflow automatically. Select them as [app triggers](/agent-platform/workflows#app-triggers) when you configure a workflow.

| Trigger | Fires when |
| --- | --- |
| New Public Message Posted Anywhere | A message is posted to any public channel. |
| New Message Posted to Channel | A message is posted to a channel you choose. |
| New Direct Message | A message is posted in a direct message. |
| New Mention in Channel | A user name is mentioned in a channel. |
| New Mention in Direct Message | A user name is mentioned in a direct message. |
| New Reaction | A reaction is added to a message. |
| Channel created | A channel is created. |
| New Command in Channel | A command is sent to the bot in a channel, for example `@bot command arg1 arg2`. |
| New Command in Direct Message | A command is sent to the bot in a direct message. |
| New User | A user is created or first joins the workspace. |
| New Saved Message | You save a message. |
| New Team Custom Emoji | A custom emoji is added to the workspace. |
| New Modal Interaction | A user interacts with a modal. |

## Set up the integration

<Steps>
  <Step title="Configure the Slack app">
    [Create a Slack app](https://api.slack.com/apps). On **OAuth & Permissions**, add the Artemis **Callback URL** to **Redirect URLs** and the scopes listed in the next step. Copy the **Client ID** and **Client Secret** from **Basic Information**. Invite the app to every channel the agent uses (`/invite @<app name>`).
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Slack** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Slack** > **Continue**. Enter the **Client ID** and **Client Secret**, select **Create Profile**, and then select **Authorize**. Artemis pre-fills the Slack endpoints and scopes.

    **Usage Mode**: **Preconfigured** shares one authorization across users; **JIT** and **Preflight** ask each user to authorize, during or before the session. See [Auth profiles](/agent-platform/administration/integrations-settings#auth-profiles).

    <Accordion title="Pre-filled scopes">
      `channels:read`, `channels:manage`, `channels:history`, `channels:write.invites`, `chat:write`, `chat:write.customize`, `groups:read`, `groups:write`, `groups:history`, `groups:write.invites`, `im:read`, `im:write`, `im:history`, `mpim:read`, `mpim:write`, `mpim:history`, `reactions:read`, `reactions:write`, `users:read`, `users:read.email`, `users.profile:read`, `usergroups:read`, `files:read`, `files:write`, `links:read`, `links:write`, `emoji:read`
    </Accordion>
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Slack** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `bad_redirect_uri` during authorization | Add the exact **Callback URL** to **Redirect URLs** in the Slack app. |
| `not_in_channel` or `channel_not_found` | Invite the app to the channel with `/invite @<app name>`. |
| `missing_scope` | Add the scope to the Slack app, reinstall the app, and then authorize the profile again. |
| `message_not_found` | Confirm the `ts` value and the channel. Timestamps are unique only within a channel. |
| Messages show raw Markdown | Run the text through **Markdown to Slack format** before sending. |
| Channel or user dropdowns are empty | Confirm the profile is **Active** and includes `channels:read`, `groups:read`, and `users:read`. |
