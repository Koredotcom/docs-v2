Use the Twilio integration to let agents send SMS, place text-to-speech calls, look up numbers, and retrieve messages and recordings through Action Tools.

| Authentication | Actions | Triggers |
| --- | --- | --- |
| Basic Auth | 6 | 5 ([use in workflows](/agent-platform/workflows#app-triggers)) |

## Supported actions

| Action | Use it to |
| --- | --- |
| [Send SMS](#send-sms) | Send an SMS message from a Twilio number. |
| [Call Phone](#call-phone) | Call a number and speak a message with text-to-speech. |
| [Phone Number Lookup](#phone-number-lookup) | Get information about a phone number. |
| [Get Message](#get-message) | Get the details of a message. |
| [Download Recording Media](#download-recording-media) | Download the audio file of a call recording. |
| [Custom API Call](#custom-api-call) | Call any Twilio API endpoint the other actions don't cover. |

## Triggers

| Trigger | Fires when |
| --- | --- |
| New Incoming SMS | An SMS message is received. |
| New Phone Number | You add a phone number to your account. |
| New Recording | A call recording is completed and available. |
| New Transcription | A call recording transcription is completed. |
| New Call | A call completes, incoming or outgoing. |

## Prerequisites

- A Twilio number that is SMS-capable or voice-capable. Trial accounts can message only verified numbers.

## Set up the integration

<Steps>
  <Step title="Create the auth profile">
    In **Integrations**, select **Twilio** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Twilio** > **Continue**. Enter the **Account SID** as **Username** and the **Auth Token** as **Password** (both on the [Twilio Console](https://console.twilio.com/) dashboard), and select **Create Profile**.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Twilio** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Set `from` as a default. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

Enter all phone numbers in E.164 format, for example `+15558675310`.

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `20003 Authenticate` | Confirm that **Username** is the Account SID and **Password** is its current auth token. |
| `21608` unverified number | Trial accounts can send only to verified numbers. Verify the number or upgrade the account. |
| `21211` invalid `To` number | Enter the number in E.164 format. |
| `21606` invalid `From` number | Select a Twilio number that is SMS-capable or voice-capable for the action. |
| The `from` dropdown is empty | Confirm the account has an active phone number and the profile is **Active**. |
| Messages to some countries fail | Enable the destination in **Messaging** > **Settings** > **Geo permissions** in the Twilio Console. |
