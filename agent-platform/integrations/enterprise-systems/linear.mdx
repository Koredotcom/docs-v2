## Supported actions

Actions are Linear operations that an agent runs as Action Tools during a conversation. You can also run them from an [Integration node](/agent-platform/workflows#integration-node) in a workflow.

| Action | Use it to |
| --- | --- |
| [Create Issue](#create-issue) | Create an issue in a team. |
| [Update Issue](#update-issue) | Update an issue. |
| [Create Comment](#create-comment) | Comment on an issue. |
| [Create Project](#create-project) | Create a project. |
| [Update Project](#update-project) | Update a project. |
| [Raw GraphQL query](#raw-graphql-query) | Run any Linear GraphQL query or mutation. |

## Set up the integration

<Steps>
  <Step title="Get Linear credentials">
    For **API Key**, create a personal API key in Linear under **Settings** > **Security & access**. For **OAuth 2.0**, create an OAuth application in Linear, add the Artemis **Callback URL** as a redirect URI, and copy the **Client ID** and **Client Secret**. See [Linear API](https://linear.app/developers).
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Linear** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Linear** > **Continue**. Select **OAuth 2.0** or **API Key**, enter the credentials, and select **Create Profile**. For OAuth 2.0, select **Authorize**. {/* TODO: confirm pre-filled endpoints, scopes, and API Key header and prefix */}

    **Usage Mode**: **Preconfigured** shares one authorization across users; **JIT** and **Preflight** ask each user to authorize, during or before the session. See [Auth profiles](/agent-platform/administration/integrations-settings#auth-profiles).
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Linear** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Team, status, or assignee lists are empty | Confirm the authorized account is a member of the team. |
| `Authentication required` | Check the API key, or authorize the OAuth profile again. |
| GraphQL errors from **Raw GraphQL query** | Validate the query in the [Linear API explorer](https://studio.apollographql.com/public/Linear-API/variant/current/home). |
