Use the Docling integration to let agents and workflows extract Markdown, tables, images, and page text from documents. Docling needs no credentials.

| Authentication | Actions | Workflow triggers |
| --- | --- | --- |
| None | [1](#supported-actions) | None |

## Supported actions

Actions are Docling operations that an agent runs as Action Tools during a conversation. You can also run them from an [Integration node](/agent-platform/workflows#integration-node) in a workflow.

| Action | Use it to |
| --- | --- |
| [Extract Document](#extract-document) | Extract structured content from a public document URL. |

## Set up the integration

<Steps>
  <Step title="Create the auth profile">
    In **Integrations**, select **Docling** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Docling** > **Continue**. Enter a **Profile Name**, and select **Create Profile**. The **Auth Type** is `none`.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Docling** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Action reference

<AccordionGroup>
  <Accordion title="Extract Document" id="extract-document">
    | Parameter | Type | Description |
    | --- | --- | --- |
    | `fileUrl` | string | Public HTTP(S) URL of the document. |
    | `extractImages` | boolean | Includes images. Default: `True`. |
    | `extractTables` | boolean | Includes tables. Default: `True`. |
    | `ocrEnabled` | boolean | Runs OCR on scanned pages. Default: `True`. |
    | `language` | string | ISO 639-1 language hint, for example `en`. |
    | `ocrLanguages` | array | OCR language hints. RapidOCR supports English and Chinese aliases. |
    | `timeout` | number | Maximum seconds, from 5 to 1800. Default: 60. |
  </Accordion>
</AccordionGroup>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| The document can't be downloaded | Use a public URL that returns the file directly. |
| Scanned text is missing | Keep `ocrEnabled` on, and set `ocrLanguages` for the document language. |
| Extraction times out | Increase `timeout`, or split large documents. |
