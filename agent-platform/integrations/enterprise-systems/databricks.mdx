Use the Databricks integration to manage jobs and runs, execute SQL statements in a SQL warehouse, and call other Databricks REST API endpoints through Action Tools. It also provides a job notification webhook trigger.

| Authentication | Actions | Triggers |
| --- | --- | --- |
| OAuth 2.0 Client Credentials | ([12](/agent-platform/integrations/enterprise-systems/databricks#supported-actions)) | ([1](/agent-platform/integrations/enterprise-systems/databricks#triggers)) |

## Supported actions

| Action | Use it to |
| --- | --- |
| [List Jobs](#list-jobs) | List jobs, optionally filtered by name. |
| [Get Job](#get-job) | Retrieve a job by its ID. |
| [Run Job Now](#run-job-now) | Start a job run with optional parameters. |
| [List Runs](#list-runs) | List job runs with optional filters. |
| [Get Run](#get-run) | Retrieve a run by its ID. |
| [Cancel Run](#cancel-run) | Cancel a job run. |
| [Get Run Output](#get-run-output) | Retrieve a run's output. |
| [List SQL Warehouses](#list-sql-warehouses) | List SQL warehouses available to the authenticated principal. |
| [Execute SQL Statement](#execute-sql-statement) | Execute a SQL statement in a warehouse. |
| [Get SQL Statement](#get-sql-statement) | Retrieve statement execution details. |
| [Cancel SQL Statement](#cancel-sql-statement) | Cancel a running SQL statement. |
| [Custom API Call](#custom-api-call) | Send a request to a Databricks REST API endpoint. |

## Triggers

| Trigger | Fires when |
| --- | --- |
| Job Notification Webhook | A selected event occurs for the configured Databricks job: start, success, failure, duration warning threshold exceeded, or streaming backlog threshold exceeded. The trigger attaches a webhook notification destination to the job. It can create a destination or reuse one whose URL already points to the workflow's trigger webhook. When disabled, the trigger removes its job attachment and deletes the destination only if it created it. |

## Prerequisites

- A Databricks workspace and a service principal or OAuth client credentials with permission for the jobs, SQL, and API operations you plan to use.
- A SQL warehouse for **List SQL Warehouses** and SQL statement actions.
- For **Job Notification Webhook**, a job that the authenticated principal can edit. If reusing a notification destination, its URL must already be the workflow trigger's webhook URL.

## Set up the integration

<Steps>
  <Step title="Prepare Databricks OAuth credentials">
    Prepare the OAuth client ID and client secret, workspace URL, and required scopes for the Databricks APIs your tools will call. The token URL is prefilled as `${connectionConfig.workspaceHost}/oidc/v1/token`; verify it resolves to the workspace token endpoint. See [Databricks OAuth machine-to-machine authentication](https://docs.databricks.com/en/dev-tools/auth/oauth-m2m.html).
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Databricks** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Databricks** > **Continue**. Select **OAuth 2.0 Client Credentials**, enter the profile details, workspace **Host**, token URL, scopes, **Client ID**, and **Client Secret**, then select **Create Profile**. The Host is the Databricks workspace URL without a trailing slash. Studio also provides an optional refresh token URL field.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Databricks** > **Continue**. Select the **Action** and **Auth Profile**, configure the inputs, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| OAuth authorization or token exchange fails | Verify the workspace Host, client ID and secret, token URL, scopes, and service principal permissions. |
| A job or run action returns an access error | Confirm that the authenticated principal can view, run, or cancel the specified job or run. |
| SQL execution fails | Verify the warehouse ID, warehouse availability, SQL permissions, statement syntax, and parameter format. |
| SQL results are incomplete | Check the row and byte limits and the selected disposition and format. |
| The job notification trigger can't be enabled | Verify that the principal can edit the job. For a reused destination, confirm its configured URL is the trigger webhook URL. |
| The trigger stops receiving notifications | Confirm the selected events and that the Databricks job still has the notification destination attached. |
