Use the Jira integration to let agents create, update, search, assign, and comment on issues in Jira Cloud or Jira Data Center through Action Tools.

## Supported actions

Actions are Jira operations that an agent runs as Action Tools during a conversation. You can also run them from an [Integration node](/agent-platform/workflows#integration-node) in a workflow.

| Group | Actions |
| --- | --- |
| Issues | [Create Issue](#create-issue), [Update Issue](#update-issue), [Get Issue](#get-issue), [Search Issues](#search-issues), [Assign Issue](#assign-issue), [Link Issues](#link-issues), [Add Watcher to Issue](#add-watcher-to-issue) |
| Comments | [Add Issue Comment](#add-issue-comment), [Update Issue Comment](#update-issue-comment), [List Issue Comments](#list-issue-comments), [Delete Issue Comment](#delete-issue-comment) |
| Attachments | [Add Attachment to Issue](#add-attachment-to-issue), [Get Issue Attachment](#get-issue-attachment) |
| Users and utilities | [Find User](#find-user), [Markdown to Jira format](#markdown-to-jira-format), [Custom API Call](#custom-api-call) |

## Workflow triggers

Triggers are Jira events that start a workflow automatically. Select them as [app triggers](/agent-platform/workflows#app-triggers) when you configure a workflow.

| Trigger | Fires when |
| --- | --- |
| New Issue | An issue is created. |
| Updated Issue | An issue is updated. |
| Updated Issue Status | An issue's status changes. |

## Set up the integration

<Steps>
  <Step title="Prepare Jira credentials">
    - **Cloud**: In the [Atlassian Developer Console](https://developer.atlassian.com/console/myapps/), create an **OAuth 2.0 (3LO)** app, add the Jira API scopes listed in the next step, add the Artemis **Callback URL** as the callback URL, and copy the **Client ID** and **Secret**. See [OAuth 2.0 (3LO) apps](https://developer.atlassian.com/cloud/jira/platform/oauth-2-3lo-apps/).
    - **Data Center 10.3**: Create a personal access token, use a service account's username and password, or create an incoming OAuth 2.0 application link in Jira with the Artemis **Callback URL**.
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Jira** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Jira** > **Continue**. Select the **Version**, configure the fields, and select **Create Profile**. For OAuth, select **Authorize**.

    <Tabs>
      <Tab title="Cloud">
        **Auth Type** is **OAuth 2.0**. Artemis pre-fills the Atlassian endpoints, the `audience=api.atlassian.com` and `prompt=consent` parameters, and the scopes `read:jira-work`, `write:jira-work`, `read:jira-user`, and `offline_access`. Enter the **Client ID** and **Client Secret**.

        **Usage Mode**: **Preconfigured** shares one authorization across users; **JIT** and **Preflight** ask each user to authorize, during or before the session. See [Auth profiles](/agent-platform/administration/integrations-settings#auth-profiles).
      </Tab>
      <Tab title="Data Center 10.3">
        Enter **Base URL** (for example `https://jira.example.com`), and then select an **Auth Type**:

        | Auth Type | Fields |
        | --- | --- |
        | **Bearer Token** | **Token** (personal access token). Keep **Authorization Prefix** as `Bearer`. |
        | **Basic Auth** | **Username** and **Password**. |
        | **OAuth 2.0 App (User Delegated)** | **Client ID** and **Client Secret**. Artemis builds the endpoints from **Base URL** (`/rest/oauth2/latest/authorize` and `/token`) and pre-fills the `READ` and `WRITE` scopes. |
      </Tab>
    </Tabs>
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Jira** > **Continue**. Select the **Version** that matches your profile, the **Action**, and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Authorization fails or doesn't complete | Verify that the callback URL in the Atlassian app or Jira application link exactly matches the Artemis **Callback URL**. |
| `401 Unauthorized` | For Cloud, authorize the profile again. For Data Center, check the token or password and the **Base URL**. |
| `403 Forbidden` or missing fields | Confirm the app has the required scopes and the account has the Jira project permission for the action. |
| Project, issue, or user lists are empty | Confirm the authorized account can browse the project. |
| Rich text appears as raw markup | Run the text through **Markdown to Jira format**, and pass it in `adfFields` or with `isADF` turned on. |
| **Search Issues** returns an error | Test the JQL in Jira's issue search first. |
