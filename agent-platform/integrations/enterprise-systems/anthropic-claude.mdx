Use the Anthropic Claude integration to let agents and workflows call Claude models to answer prompts and extract structured data from text, images, or PDFs.

| Authentication | Actions | Workflow triggers |
| --- | --- | --- |
| API Key | [3](#supported-actions) | None |

## Supported actions

Actions are Anthropic Claude operations that an agent runs as Action Tools during a conversation. You can also run them from an [Integration node](/agent-platform/workflows#integration-node) in a workflow.

| Action | Use it to |
| --- | --- |
| [Ask Claude](#ask-claude) | Send a prompt to a Claude model. |
| [Extract Structured Data](#extract-structured-data) | Extract fields from text, an image, or a PDF. |
| [Custom API Call](#custom-api-call) | Call any API endpoint the other actions don't cover. |

## Prerequisites

- An [Anthropic API key](https://console.anthropic.com/settings/keys).

## Set up the integration

<Steps>
  <Step title="Create the auth profile">
    In **Integrations**, select **Anthropic Claude** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Anthropic Claude** > **Continue**. Paste the key into **API Key**, keep the pre-filled `x-api-key` header and the `anthropic-version` header (`2023-06-01`), and select **Create Profile**.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Anthropic Claude** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Action reference

<AccordionGroup>
  <Accordion title="Ask Claude" id="ask-claude">
    | Parameter | Type | Description |
    | --- | --- | --- |
    | `model` | enum | Model. Default: `Claude 4 Sonnet`. |
    | `systemPrompt` | string | System prompt. |
    | `prompt` | string | Question or instruction. |
    | `image` | string | Public HTTPS URL of an image or PDF to include as context. |
    | `roles` | object | Prior conversation messages by role. |
    | `temperature` | number | Randomness. Lower values give more focused output. |
    | `maxTokens` | number | Maximum tokens to generate. |
    | `thinkingMode` | boolean | Turns on extended thinking. Default: `False`. |
    | `thinkingModeParams` | object | Extended thinking settings. |
  </Accordion>
  <Accordion title="Extract Structured Data" id="extract-structured-data">
    | Parameter | Type | Description |
    | --- | --- | --- |
    | `model` | enum | Model. Default: `Claude 4 Sonnet`. |
    | `text` | string | Text to extract from. |
    | `image` | string | Public HTTPS URL of an image or PDF. |
    | `prompt` | string | Guidance for the extraction. |
    | `mode` | enum | Schema type. Default: `Simple`. |
    | `schema` | object | Fields to extract. |
  </Accordion>
  <Accordion title="Custom API Call" id="custom-api-call">
    | Parameter | Type | Description |
    | --- | --- | --- |
    | `url` | object | Endpoint URL. |
    | `method` | enum | HTTP method. |
    | `headers` | object | Additional request headers. Artemis injects the authorization header. |
    | `queryParams` | object | Query parameters. |
    | `body_type` | enum | Body type. Default: `None`. |
    | `body` | object | Request body. |
    | `response_is_binary` | boolean | Turn on for binary responses. Default: `False`. |
    | `failsafe` | boolean | Returns no error when the call fails. |
    | `timeout` | number | Timeout, in seconds. |
    | `followRedirects` | boolean | Follows HTTP redirects. Default: `False`. |
  </Accordion>
</AccordionGroup>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `401 authentication_error` | Check the API key, and confirm it isn't revoked. |
| `429 rate_limit_error` | Reduce request volume, or raise your Anthropic usage tier. |
| Image or PDF is ignored | Use a public HTTPS URL that returns the file directly. |
