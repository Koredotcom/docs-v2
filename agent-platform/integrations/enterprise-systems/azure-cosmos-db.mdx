Use the Azure Cosmos DB integration for NoSQL to query databases and create, read, update, patch, or delete items through Action Tools.

| Authentication | Actions |
| --- | --- |
| Cosmos DB account key or resource token | ([9](/agent-platform/integrations/enterprise-systems/azure-cosmos-db#supported-actions)) |

## Supported actions

| Action | Use it to |
| --- | --- |
| [List Databases](#list-databases) | List database IDs. |
| [List Containers](#list-containers) | List container IDs in a database. |
| [Query Items](#query-items) | Run a SQL query against a container. |
| [Read Item](#read-item) | Read an item by ID and partition key. |
| [Create Item](#create-item) | Create an item. |
| [Upsert Item](#upsert-item) | Create or replace an item. |
| [Replace Item](#replace-item) | Replace an item by ID and partition key. |
| [Patch Item](#patch-item) | Apply patch operations to an item. |
| [Delete Item](#delete-item) | Delete an item by ID and partition key. |

## Prerequisites

- An Azure Cosmos DB for NoSQL account and its endpoint.
- An account key or resource token with access to the databases, containers, and operations used by the tools.

## Set up the integration

<Steps>
  <Step title="Prepare the Cosmos DB connection">
    Have the account endpoint and account key or resource token ready. If you want actions to use profile defaults, also identify the database, container, and partition key.
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Azure Cosmos DB** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Azure Cosmos DB** > **Continue**. Configure the endpoint and key. Select **Account Key** or **Resource Token** for the token type; **Account Key** is the default. You can also set default database, container, and partition key values. For a resource token, you can optionally enter its expiry as an ISO timestamp for operator visibility. Select **Create Profile**.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Azure Cosmos DB** > **Continue**. Select the action and auth profile, configure its inputs, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Action reference

Database and container action inputs are optional when you set them in the auth profile. **Read Item**, **Replace Item**, **Patch Item**, and **Delete Item** also need a partition key from the action or profile. **Create Item** and **Upsert Item** use the partition-key field in the item.

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Connection fails | Verify the account endpoint, key, and token type. For a resource token, check that it is still valid. |
| A read, replace, patch, or delete reports a missing partition key | Supply it on the action or in the auth profile. Include the container partition-key field in items you create or upsert. |
| A query or patch fails | Check the Cosmos DB SQL, query parameter array, or patch operation array. |
| An action result exceeds the output limit | Reduce the number of returned items or fields. Connector responses larger than 2 MB are rejected. |
