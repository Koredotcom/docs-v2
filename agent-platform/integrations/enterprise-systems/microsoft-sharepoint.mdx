## Set up the integration

<Steps>
  <Step title="Register an Entra ID app">
    Register an app in [Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-register-app), create a client secret, and copy the **Application (client) ID** and **Directory (tenant) ID**. Add Microsoft Graph permissions (for example `Sites.ReadWrite.All` and `Files.ReadWrite.All`, plus `offline_access` for delegated access) as **Delegated** or **Application** permissions, grant admin consent, and for delegated access add the Artemis **Callback URL** as a **Web** redirect URI.
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Microsoft SharePoint** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Microsoft SharePoint** > **Continue**. Select an **Auth Type**, configure the fields, and select **Create Profile**. For delegated access, select **Authorize**.

    <Tabs>
      <Tab title="OAuth 2.0 App (User Delegated)">
        Enter the Microsoft identity platform endpoints if Artemis doesn't pre-fill them (`https://login.microsoftonline.com/<tenant>/oauth2/v2.0/authorize` and `.../token`), the delegated **Scopes**, **Client ID**, and **Client Secret**. {/* TODO: confirm which endpoints and scopes are pre-filled */}

        **Usage Mode**: **Preconfigured** shares one authorization across users; **JIT** and **Preflight** ask each user to authorize, during or before the session. See [Auth profiles](/agent-platform/administration/integrations-settings#auth-profiles).
      </Tab>
      <Tab title="Azure AD (Service Principal)">
        Enter **Azure Tenant ID**, **Scopes** (`https://graph.microsoft.com/.default`), **Client ID**, and **Client Secret**. Keep **Resource** as `https://graph.microsoft.com`.
      </Tab>
      <Tab title="OAuth 2.0 Client Credentials">
        Keep **Authorize Using** as **Client Secret** and the pre-filled **Token URL** and **Scopes**. Enter **Client ID** and **Client Secret**.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Microsoft SharePoint** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `AADSTS50011` redirect URI mismatch | Add the exact **Callback URL** as a **Web** redirect URI in the app registration. |
| `AADSTS65001` consent required | Grant admin consent for the API permissions, and then authorize again. |
| `403 Forbidden` | Add the missing Microsoft Graph permission for the action, and grant consent. |
| Site or library lists are empty | Confirm the account or app can access the site. For app-only access, grant `Sites.ReadWrite.All` or `Sites.Selected` with a site grant. |
| Copy or upload fails with a conflict | Change **conflictBehavior**, or set a new name. |
