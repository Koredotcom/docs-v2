| Task Created | A task is created. |

| Task Deleted | A task is deleted. |
| Task Priority Updated | A task's priority changes. |

| Task Due Date Updated | A task's due date changes. |
| Task Tag Updated | A task's tag changes. |
| Task Moved | A task moves to another list. |
| Task Comment Posted | A comment is posted on a task. |
| Task Comment Updated | A task comment is updated. |
| Task Time Estimate Updated | A task's time estimate changes. |
| Task Time Tracked Updated | A task's tracked time changes. |

## Prerequisites

- A ClickUp account with access to the workspaces, spaces, and lists that agents use.
- An OAuth app in ClickUp. See [Authentication](https://developer.clickup.com/docs/authentication).

## Set up the integration

<Steps>
  <Step title="Create a ClickUp OAuth app">
    In ClickUp, create an OAuth app. Add the **Callback URL** from the Artemis profile form as the redirect URL, and copy the **Client ID** and **Client Secret**.
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **ClickUp** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **ClickUp** > **Continue**.

    | Field | Value |
    | --- | --- |
    | **Profile Name** | A name for the profile, for example `ClickUp - Production` |
    | **Usage Mode** | **Preconfigured** (default), **JIT (Just-in-Time)**, or **Preflight**. With **Preconfigured**, an admin provides credentials at setup, and users don't authorize. See [Auth profiles](/agent-platform/administration/integrations-settings#auth-profiles). |
    | **Authorization URL**, **Token URL**, **Refresh URL** | Pre-filled with the ClickUp endpoints. Keep the defaults. |
    | **Scopes** | Leave empty. ClickUp doesn't use scopes. |
    | **Callback URL** | Read only. Add it to your ClickUp app's redirect URL. |
    | **Client ID**, **Client Secret** | From your ClickUp app. |

    Select **Create Profile**, and complete the ClickUp sign-in and consent when prompted. Select every workspace that agents need.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, open the **Actions** tab and select **Create Tool**. Enter a **Tool Name** and **Description**, and select **Select Integration** > **ClickUp** > **Continue**. Select the **Action** and **Auth Profile**, set parameter defaults (leave a value empty for the agent to supply at runtime), choose an output mode, and select **Create Tool**. Then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| Authorization fails with a redirect error | Confirm the ClickUp app's redirect URL matches the **Callback URL** from the profile form. |
| The profile status stays **Awaiting authorization** | Complete the ClickUp sign-in and consent in the same browser session. |
| A workspace is missing from the `workspace_id` list | Reauthorize the profile and select the workspace on the ClickUp consent screen. |
| Task creation fails on a list with required custom fields | Set `check_required_custom_fields` to `True`, and supply values in `custom_fields`. |
| `Get Task by Name` returns no result | Confirm the name matches exactly and that the task is in the selected list. |
| A trigger doesn't start the workflow | Confirm the auth profile is authorized and that the event occurs in a workspace the profile can access. |
