Use the Google Sheets integration to create spreadsheets and worksheets, add and update rows, find and export data, format rows, and manage worksheets through Action Tools. It also provides triggers for new or updated rows, new rows, spreadsheets, and worksheets.

## Triggers

| Trigger | Fires when |
| --- | --- |
| New or Updated Row | A row is added or modified in the selected spreadsheet and worksheet. Optionally limit the trigger to changes in a selected column. Google may delay the trigger by up to 3 minutes. |
| New Row Added | A row is added to the bottom of the selected worksheet. Google may delay the trigger by up to 3 minutes. |
| New Spreadsheet | A spreadsheet is created. |
| New Worksheet | A worksheet is created in the selected spreadsheet. |

## Prerequisites

- A Google account with access to the spreadsheets, worksheets, and Shared Drives used by your tools.
- A Google Cloud project with the Google Sheets API and Google Drive API enabled, and an OAuth client for Studio.

## Set up the integration

<Steps>
  <Step title="Prepare Google OAuth credentials">
    Create an OAuth client in Google Cloud and add the callback URL displayed in the Studio auth profile as an authorized redirect URI. Enable the Google Sheets API and Google Drive API for the Google Cloud project.
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Google Sheets** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Google Sheets** > **Continue**. Use **OAuth 2.0** and the **Preconfigured** usage mode. Studio prepopulates the authorization URL (`https://accounts.google.com/o/oauth2/v2/auth`), token and refresh URLs (`https://oauth2.googleapis.com/token`), and authorization parameters (`response_type=code`, `access_type=offline`, and `prompt=consent`). The requested scopes are `https://www.googleapis.com/auth/spreadsheets`, `https://www.googleapis.com/auth/drive.readonly`, and `https://www.googleapis.com/auth/drive`; PKCE is off by default. Enter the OAuth client ID and secret, copy the callback URL into the OAuth client configuration, and select **Create Profile**.
  </Step>
  <Step title="Create the action tool">
    In **Tools**, select **New Tool** > **Action** > **Google Sheets** > **Continue**. Select the **Action** and **Auth Profile**, configure the inputs, and choose whether to return the complete connector response or define custom output parameters. Select **Create Tool**, then [assign the tool to an agent](/agent-platform/tools/actions#assign-an-action-to-an-agent).
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| OAuth authorization fails | Verify the OAuth client ID and secret, callback URL, enabled APIs, and requested scopes. |
| A spreadsheet or worksheet is missing from a dropdown | Confirm the authorized Google account can access it. Enable **Include Shared Drives** if the item is in a Shared Drive. |
| Rows are mapped to the wrong columns | Check whether the worksheet has headers and set `first_row_headers`, `is_first_row_headers`, and `headerRow` accordingly. |
| A row trigger is delayed | Google may take up to 3 minutes to notify Studio. Check the selected spreadsheet, worksheet, and `trigger_column`. |
| An export is returned as a file instead of text | Enable **Return as Text** (`returnAsText`). |
| A custom API request fails | Verify the Google Sheets API URL, HTTP method, query parameters, and request body. Studio injects authorization headers from the selected profile. |
