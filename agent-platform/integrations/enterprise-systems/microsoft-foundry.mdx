Use the Microsoft Foundry integration to connect Artemis to Azure AI Foundry with a service principal, so you can discover and add Foundry model deployments. The integration uses the Azure management plane only.

| Authentication | Actions | Workflow triggers |
| --- | --- | --- |
| Service Principal (Azure AD) | None | None |

<Note>Microsoft Foundry has no actions or triggers. You use its auth profile when you add models from Azure AI Foundry.</Note>

## Prerequisites

- An Azure AI Foundry account (Cognitive Services account of kind **AIServices**) with model deployments.
- A service principal with read access to the subscription or resource group that contains the account, for example the **Reader** role.

## Set up the integration

<Steps>
  <Step title="Create a service principal">
    Register an app in [Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-register-app), create a client secret, and copy the **Directory (tenant) ID**, **Application (client) ID**, and secret value. Assign it a role on the Foundry account's subscription or resource group.
  </Step>
  <Step title="Create the auth profile">
    In **Integrations**, select **Microsoft Foundry** > **Connect**. On **Project Auth Profiles**, select **New Profile** > **Integration Profile** > **Microsoft Foundry** > **Continue**. Configure the fields, and select **Create Profile**.

    | Field | Value |
    | --- | --- |
    | **Tenant (Directory) ID** | Directory (tenant) ID. |
    | **Subscription ID** | Azure subscription that contains the Foundry account. |
    | **Application (Client) ID**, **Client Secret** | From the service principal. |
    | **Resource Group**, **Foundry Account**, **Foundry Project** | Optional default scope. Set all three to skip the scope step when you add models. Leave them empty to choose each time. |
  </Step>
</Steps>

## Troubleshoot common issues

| Issue | Resolution |
| --- | --- |
| `AADSTS7000215` invalid client secret | Use the secret **Value**, not its ID, and confirm it hasn't expired. |
| Resource group or account lists are empty | Assign the service principal a role on the subscription or resource group, and check **Subscription ID**. |
| No deployments appear | Confirm the account is of kind **AIServices** and has model deployments in the selected project. |
