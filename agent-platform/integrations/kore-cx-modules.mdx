Kore.ai CX modules are Kore.ai products that work with Artemis agents. Use these integrations to connect Artemis to contact center, campaign, quality, and agent-assist products from Kore.ai.

| Integration | Description |
|:------------|:------------|
| [Contact Center AI (CCAI)](/agent-platform/integrations/ccai) | Connect an Artemis project to the AI for Service Contact Center app for two-way communication with contact center agents. |
| [CCAI voice transfer](/agent-platform/integrations/ccai-voice-transfer) | Transfer a voice call from an Artemis voice agent to a human agent in CCAI over SIP. |
| [CCAI outbound campaign](/agent-platform/integrations/campaign) | Place outbound campaign calls through Artemis and trigger a deployed agent for each call. |
| [Read Campaign contact data](/agent-platform/integrations/read-campaign-contact-data) | Use the customer and campaign fields from a CCAI campaign in an outbound voice session. |
| [Quality AI](/agent-platform/integrations/quality-ai) | Run AI-based evaluations through Artemis with the By AI Agent metric. |
| [Agent AI](/agent-platform/integrations/agent-ai) | Generate next best action suggestions in the Agent AI widget. |
| [Kore Agent Assist](/agent-platform/channels/kore-agent-assist) | Give contact center agents real-time guidance from a deployed agent. This page is also listed under [Channels](/agent-platform/channels). |
