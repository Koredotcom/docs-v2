Contact center integrations hand over an Artemis conversation to a live agent working in a contact center or service desktop. When your agent escalates, the conversation reaches a human agent in the system you connect.

| Integration | Description |
|:------------|:------------|
| [Amazon Connect](/agent-platform/integrations/amazon-connect) | Escalate to a live agent in Amazon Connect through a chat contact. |
| [Kore SmartAssist](/agent-platform/integrations/ccai) | Connect an Artemis project to the AI for Service Contact Center app for two-way communication with contact center agents. |
| [Genesys Cloud](/agent-platform/integrations/genesys-cloud) | Connect an Artemis project to the Genesys Cloud CX Agent Desktop. |
| Genesys Open Messaging | Escalate to a Genesys agent over Open Messaging. |
| [Salesforce](/agent-platform/integrations/salesforce) | Connect an Artemis project to the Salesforce Service Cloud Agent Desktop. |
| ServiceNow | Connect an Artemis project to ServiceNow Agent System. |
| [Five9](/agent-platform/integrations/five9) | Connect an Artemis project to Five9 Virtual Contact Center. |
