Use the [Integration node](/agent-platform/workflows#integration-node) in a workflow to execute connector actions, such as sending a Slack message, creating a Jira issue, or requesting approval by email, during workflow execution. Each integration exposes a set of authenticated actions that you configure as workflow steps.

| Communication       | Amazon SES, Amazon SNS, Discord, Gmail, Microsoft Exchange, Microsoft Outlook, Microsoft Teams, SendGrid, Slack, Twilio |
| Productivity        | Asana, ClickUp, Confluence, Google Calendar, Google Docs, [Jira](/agent-platform/integrations/jira-actions), Linear, Microsoft Excel, Microsoft Outlook Calendar, Microsoft Power BI, Microsoft SharePoint, Notion |
