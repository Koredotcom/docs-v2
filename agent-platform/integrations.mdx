Integrations connect your Artemis agents to external systems—CRMs, communication channels, cloud services, and contact‑center desktops—so they can access data, trigger actions, and operate across your enterprise ecosystem. Each integration is a configured connection that exposes authenticated actions and triggers your agents can use during conversations and workflows, enabling them to do real work beyond the platform.

The Artemis platform provides nine categories of integrations:

## Agent Desktop

| Integration              | Description                                                                 |
|---------------------------|-----------------------------------------------------------------------------|
| Kore SmartAssist          | Connect Artemis with Kore.ai SmartAssist agent desktop for agent handoff.  |
| Genesys Cloud             | Integrate with Genesys Cloud CX (WebChat/Web Messaging) for live escalation.|
| Genesys Open Messaging    | Escalate ABL digital-channel conversations to Genesys agents via Open Messaging.|
| Five9                     | Connect to Five9 Virtual Contact Center agent desktop for live collaboration.|
