Artemis connects your agents to external systems so they can retrieve data, take action, hand off conversations to live agents, and reach users across your enterprise ecosystem. Each integration is a configured, authenticated connection to a third-party system that your agents and workflows use.

The platform organizes integrations in the following categories:

- [**Actions and triggers integrations**](#actions-and-triggers-integrations) execute connector actions inside workflows.
- [**Knowledge base connector integrations**](#knowledge-base-connector-integrations) bring content from external systems into a knowledge base.
- [**Agent desktop integrations**](#agent-desktop-integrations) hand off conversations to a live agent desktop.
- [**Channel integrations**](#channel-integrations) deploy agents to messaging, voice, and other user-facing surfaces.
- [**Kore.ai CX modules**](#koreai-cx-modules) connect Artemis projects to Contact Center AI, Campaign, Quality AI, and Agent AI.

## Actions and triggers integrations

Use the [Integration node](/agent-platform/workflows#integration-node) in a workflow to execute connector actions, such as sending a Slack message, creating a Jira issue, or requesting approval by email, during workflow execution. Each integration exposes a set of authenticated actions that you configure as workflow steps.

Actions and triggers integrations connect a workflow to third-party applications, such as communication, productivity, storage, CRM, and service management tools. Each integration is an authenticated connection that exposes actions, which are operations a workflow runs in that application. Use these integrations to automate steps that span your enterprise systems, such as notifying a team, updating a record, or storing a file, as part of a workflow run.

For details, see [actions and triggers integrations](/agent-platform/integrations/actions-and-triggers-overview).

## Knowledge base connector integrations

[Connectors](/agent-platform/knowledge#connectors) bring content from third-party systems into a knowledge base so agents can retrieve it during conversations. Setting up a connector requires authentication credentials, content and filter selection, field mapping to the knowledge base schema, and access permission configuration.

Knowledge base connector integrations ingest content from third-party repositories, such as cloud storage, documentation, project management, CRM, and support systems. Use them to make the content your organization already maintains available to agents, instead of copying it into the platform by hand.

For details, see [Knowledge Base connectors overview](/agent-platform/connectors/knowledge-base-overview).

## Agent desktop integrations

Agent desktop integrations hand over an Artemis conversation to a live agent working in a contact center or service desktop.

Agent desktop integrations connect Artemis to the contact center and service desktop platforms where your live agents work. Use them to escalate conversations that need human handling to those agents, so your team continues to work in the tools it uses.

For details, see [Agent desktop integrations](/agent-platform/integrations/agent-desktop-overview).

## Channel integrations

Channels connect deployed agents to the surfaces where users interact, including your own apps, voice calls, messaging apps, webhooks, and other agent frameworks. A [channel](/agent-platform/channels#channels) always binds to a deployment in a specific environment. Configure deployments first, then add channels.

Channel integrations expose a deployed agent to users through messaging, voice, SDK, webhook, and open protocol surfaces. Use them to reach users on the surfaces they prefer. Artemis provides channel adapters that handle the protocol-specific details, so a single agent definition works across every channel without modification.

For details, see [Channels](/agent-platform/channels).

## Kore.ai CX modules

Kore.ai CX modules connect to Artemis projects so that each module can use your deployed agents. Each module has its own setup guide.

| Module                                                 | Description                                                                                                          |
|:-------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------|
| [Contact Center AI](/agent-platform/integrations/ccai) | Connect an Artemis project to the AI for Service Contact Center app to route escalated conversations to live agents. |
| [Campaign](/agent-platform/integrations/campaign)      | Place outbound voice campaign calls from AI for Service and trigger a deployed Artemis agent for each call.          |
| [Quality AI](/agent-platform/integrations/quality-ai)  | Run AI-based evaluations of interactions through an Artemis agent using the By AI Agent metric.                      |
| [Agent AI](/agent-platform/integrations/agent-ai)      | Generate next best action (NBA) suggestions in the Agent AI widget using an Artemis agent.                           |
