Tools extend agents' capabilities by enabling them to retrieve data, execute logic, interact with external systems, and invoke workflows at runtime.

The platform supports the following tool types:

| Tool type | Description |
|-----------|-------------|
| [Workflow Tools](#workflow-tools) | Build reusable workflow-based tools using the visual workflow builder. |
| [HTTP Tools](#http-tools) | Connect to external APIs and services through HTTP requests. |
| [Code Tools](#code-tools) | Execute custom JavaScript or Python logic. |
| [Knowledge Base Tools](#knowledge-base-tools) | Retrieve information from connected enterprise knowledge sources. |
| [MCP Tools](#mcp-tools) | Connect to Model Context Protocol (MCP) servers and use their exposed tools. |
| [Actions](#actions) | Integrate with supported third-party applications and use their predefined actions as tools within agents and workflows. |
| [WSDL Repository](#wsdl-repository) | Upload and manage WSDL assets for SOAP services and create reusable SOAP-based HTTP tools from discovered operations. |   

![Tools](/agent-platform/images/tools.png)

Use the Tools page to:

* Create and manage tools
* Register workflows as tools
* Import and export tool definitions

For detailed configuration steps, see the documentation for each tool type.

## Workflow tools

Workflow tools allow agents to invoke reusable workflows during runtime.

A workflow can be registered as a tool and attached to one or more agents. Registered workflow tools expose workflow inputs as tool parameters that agents can invoke during interactions.

Workflow tools support:

* Multi-step execution logic
* Human approval and data-entry flows
* Conditional branching
* Integration actions
* Reusable business processes

For details about registering workflows as tools and attaching them to agents, see:

* [Register workflows as tools](/agent-platform/workflows#register-workflow-as-a-tool)
* [Attach workflow tools to agents](/agent-platform/workflows#attach-workflow-tools-to-agents)

## HTTP tools

HTTP tools let agents call external APIs to fetch data or trigger actions. The agent provides the required parameters, and the platform handles authentication, request construction, and response mapping. 

For details, see [HTTP Tools](/agent-platform/tools/http).

---


## Code tools

Code Tools let you define custom logic using JavaScript or Python that agents can invoke as part of a workflow. They bridge the gap between LLM reasoning and deterministic, programmatic operations, enabling your agents to reliably transform data, call APIs, or run business logic. 

For details, see [Code Tools](/agent-platform/tools/code).

---

## Knowledge base tools

The Knowledge Base tool enables agents to retrieve relevant information from enterprise knowledge sources during conversations. It connects the agent to one or more configured knowledge bases and allows it to search indexed content such as documents, web pages, and data from external systems. 

For detail, see [Knowledge Base and Knowledge Tools](/agent-platform/knowledge).

---

## MCP tools

MCP (Model Context Protocol) tools connect an agent to an external MCP-compatible server that exposes tools and capabilities, enabling agents to dynamically discover, access, and orchestrate tools across systems.

For details, see [MCP Tools](/agent-platform/tools/mcp).

## Actions

Actions allow agents to interact with supported third-party applications by invoking predefined operations, such as creating records, sending notifications, or updating data, without requiring custom API development.

For details, see [Actions](/agent-platform/tools/actions).

## WSDL repository

The WSDL Repository allows you to upload and manage WSDL assets for SOAP-based services. Uploaded WSDLs are parsed to discover available operations, which can then be used to create reusable SOAP-based HTTP tools.

For details, see [WSDL Repository](/agent-platform/tools/wsdl-repo).
