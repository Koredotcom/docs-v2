Inbuilt tools are tools that the Artemis runtime provides. They cover voice transfers, IVR and DTMF, human-agent handoff, and attachment handling. You do not build an HTTP endpoint or add a Tool Library entry for them.

## Use an inbuilt tool

Declare the tool in the `TOOLS:` section of your agent, with its input fields and return type. Then call it from a flow (`CALL:`) or let a reasoning agent choose it.

```yaml
TOOLS:
  send_dtmf(digits: string, reason?: string) -> object

FLOW:
  press_one:
    CALL:
      send_dtmf(digits: "1")
    THEN: COMPLETE
```

Keep these rules in mind:

- **Declare the tool.** A `CALL:` to an inbuilt tool that is not declared in `TOOLS:` fails validation, and a reasoning agent only sees the tools you declare.
- **Names are reserved.** If a project tool has the same name as an inbuilt tool, the project tool is ignored and the platform implementation runs.
- **The platform owns sensitive values.** For example, `call_transfer` never accepts a destination from the model. See each tool's page.

## Available tools

| Tool | Purpose | Available in | Page |
|---|---|---|---|
| `call_transfer` | Transfers a voice call to a SIP endpoint or PSTN number. | Voice agents | [call_transfer](/agent-platform/inbuilt-tools/call-transfer) |
| `transfer_to_agent` | Transfers the conversation to a human agent through an agent desktop provider. | All agents. On voice, only on supported gateways. | [transfer_to_agent](/agent-platform/inbuilt-tools/transfer-to-agent) |
| `check_hours` | Checks whether the contact center is within business hours. | Agents using SmartAssist agent transfer | [check_hours](/agent-platform/inbuilt-tools/check-hours) |
| `check_availability` | Checks whether a human agent is available. | Agents using SmartAssist agent transfer | [check_availability](/agent-platform/inbuilt-tools/check-availability) |
| `set_queue` | Validates a routing queue. | Agents using SmartAssist agent transfer | [set_queue](/agent-platform/inbuilt-tools/set-queue) |
| `ivr_menu` | Plays a menu and collects one keypad press. | Voice agents | [ivr_menu](/agent-platform/inbuilt-tools/ivr-menu) |
| `ivr_digit_input` | Collects multi-digit keypad input. | Voice agents | [ivr_digit_input](/agent-platform/inbuilt-tools/ivr-digit-input) |
| `send_dtmf` | Sends keypad tones into the active call. | Voice agents | [send_dtmf](/agent-platform/inbuilt-tools/send-dtmf) |
| `deflect_to_chat` | Moves a voice conversation to a chat channel. | Voice agents | [deflect_to_chat](/agent-platform/inbuilt-tools/deflect-to-chat) |
| `get_attachment_url` | Returns a public URL for a file uploaded in the conversation. | All agents | [get_attachment_url](/agent-platform/inbuilt-tools/get-attachment-url) |
| `route_attachment` | Sends an uploaded file to a configured external system. | All agents | [route_attachment](/agent-platform/inbuilt-tools/route-attachment) |

For DTMF concepts and secure collection, see [DTMF support in Artemis voice agents](/agent-platform/dtmf-support).
