The **Analytics Explorer** page monitors event volume, LLM performance, token consumption, and cost in near real time. It offers granular time controls down to 30-minute windows, so you can investigate production incidents, track the impact of model changes, or audit LLM spend during peak traffic.

**Navigation**: **Project** -> **Insights** -> **Analytics Explorer**

**Time range controls**: Analytics supports the most granular time ranges in the Insights section: **30m**, **1h**, **3h**, **6h**, **12h**, **24h**, **2d**, **7d**, **30d**, or a **Custom** range where you set exact start and end timestamps. Use the finer windows to correlate agent errors or latency spikes with specific deployment events.

## Overview

Six metric cards summarize the selected period at a glance.

| Metric        | Description                                                                                                                              |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Sessions**  | Total sessions in the selected period. A session is a single end-to-end interaction between a user and the agent system.                |
| **Messages**  | Total messages across all sessions, including both user messages and agent responses.                                                  |
| **LLM Calls** | Total LLM API calls agents made during the period. Includes calls to all configured models, for example routing, generation, and evaluation. |
| **Errors**    | Total errors during agent execution, including LLM failures, timeout errors, and tool invocation errors.                               |
| **Tokens**    | Total LLM tokens, both input and output, across all calls.                                                                             |
| **Cost**      | Estimated cost based on token usage and per-model pricing. Use it to track spend against budgets or compare cost-efficiency across model configurations. |

## Views

Analytics organizes its detail into four views. Select a tab to switch between them.

<Tabs>
  <Tab title="LLM Performance">
    Model-level metrics, including per-call latency distributions, average tokens per call, error rates by model, and throughput. Use this view to benchmark model performance and identify candidates for optimization or replacement.
  </Tab>
  <Tab title="Sessions Explorer">
    Browse and filter individual sessions with full conversation details, trace counts, token usage, and duration. Each session row expands into a detailed view with turn-by-turn replay, token breakdown, and model information.
  </Tab>
  <Tab title="Traces Explorer">
    Search and inspect individual trace events across sessions. Filter by event type, agent name, or error status to isolate specific execution paths for debugging.
  </Tab>
  <Tab title="Query">
    Run custom analytics queries against project event data through a query interface. Use it for ad-hoc investigations that don't fit the pre-built views.
  </Tab>
</Tabs>

## Session Detail View

Open a session from the **Sessions Explorer**, or from the **Trace Viewer** under **Evaluate**, to display the full session detail page. It contains the following sections.

| Section                  | Details                                                                                                                                              |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Session header**       | Session ID, agent name, trace status badge (for example, `history / partial`), total traces, total tokens, and session cost, shown in a summary bar at the top. |
| **Conversation pane**    | Full turn-by-turn dialog replay of user messages and agent responses. Each agent turn shows the responding agent's name and response latency. Multi-agent sessions show hand-offs between agents. |
| **Session Overview tab** | Agent name, session ID, message count, trace event count, connection state (Connected or Disconnected), and timestamps (Started, Finished).         |
| **Token Breakdown**      | Tokens In, Tokens Out, Total Tokens, LLM Calls count, and total Cost, in a grid of metric cards.                                                    |
| **Models Used**          | Each LLM model the session invoked, with its model identifier and version string.                                                                   |
| **Trace tabs**           | Tabbed navigation across Overview, Traces, Errors, Data, Conversation, Performance, and IR (Intermediate Representation), plus a Traces download option. |
| **Timeout Diagnostics**  | Browser idle timeout and Access Token TTL values for the session, useful for diagnosing disconnections.                                             |
