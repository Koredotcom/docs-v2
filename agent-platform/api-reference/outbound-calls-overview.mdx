---
title: Introduction to outbound dialing API
sidebarTitle: Overview
---

These APIs let an agent make voice calls to customers and manage incoming voice calls. The API supports a proactive customer-engagement requirement: 

- An external event or an app triggers a call.
- The voice agent conducts the conversation for answered calls.
- The calling app can monitor and act on the call.

A few specific use cases are:

- Remind user for an upcoming appointment.
- Verify user-placed orders.
- Send delivery notification or seek confirmation.
- Call as a follow-up of a user's contact request.

**Prerequisite** to use this API is an outbound-capable KoreVG [voice channel](/agent-platform/channels#voice-channels).

Pre-configured channels manage the telephony operations, infrastructure, and provider details. It makes the API simple to use by focusing on outcomes such as answered, busy, not answered, or failed calls. After a call is answered, it is handled over to an Artemis agent as a normal agent conversation. It uses idempotency to prevent unnecessary repeat calls.
