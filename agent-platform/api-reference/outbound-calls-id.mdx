---
title: Look up a call by ID
openapi: "/agent-platform/api-specs/outbound-calls.yaml get /api/v1/project/{projectSlug}/{env}/outbound-calls/{outboundCallId}"
---

Looks up an outbound call by its ID in the call record. The response includes the call's `phase`, `outcome`, `failureReason`, `initiationState`, `sessionId`, `statusHistory`, and timestamps. The destination and `providerCallSid` are always masked. The `sessionId` is set once the call connects and correlates to the session created for the conversation. The request needs the `outbound_calls.read` scope.

A call ID that does not exist, or that belongs to a different project, returns `404`. The API conceals calls from other projects instead of returning `403`. To follow a call as it progresses, poll this endpoint or use [Events of outbound calls](/agent-platform/api-reference/outbound-calls-events).
