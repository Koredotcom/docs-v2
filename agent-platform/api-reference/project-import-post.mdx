Use this endpoint to start an asynchronous import of project content into an existing project. The server runs the same preview and dependency validation as Studio before it changes anything. Blocking validation errors stop staging and activation. If activation fails partway, the import rolls back. The response returns an `operationId` and a `statusUrl`. Poll [Get project import status](/agent-platform/api-reference/project-import-get) until the import is `completed`. The request needs the `project_io.write` scope.

Send the content in `files`, a map of relative archive paths to UTF-8 file contents. By default, the import detects layers from the content, merges matching records, and deletes nothing. Use `layers` and `excludedLayers` to choose layers. Use `conflictStrategy` (`replace`, `skip`, or `merge`) to resolve conflicts. Use `deleteUnmatched` to remove target content that the import does not contain. Starting an import while another import runs returns `409`. Send an `Idempotency-Key` header so a retry is safe.
