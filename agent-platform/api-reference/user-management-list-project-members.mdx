---
title: List project members
openapi: "/agent-platform/api-specs/user-management.yaml get /api/public/v1/projects/{projectId}/members"
---

You can list the members of a project using this endpoint. This request needs the `project.members.read` scope. You must provide a workspace key or a project key bound to this project.

The results are paginated with a cursor. Pass `nextCursor` from the response as `cursor` in the next request. Each item includes the workspace `memberId`, the member's project role, and the `revision`.
