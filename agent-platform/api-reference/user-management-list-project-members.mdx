title: List project members
description: List the members of a project with their roles, using cursor pagination.

---

<Badge icon="arrow-left" color="gray">[Back to the User Management APIs overview](/agent-platform/api-reference/user-management-overview)</Badge>

You can list the members of a project using this endpoint. This request needs the `project.members.read` scope. You must provide a workspace key or a project key bound to this project.

The results are paginated with a cursor. Pass `nextCursor` from the response as `cursor` in the next request. Each item includes the workspace `memberId`, the member's project role, and the `revision`. Use `limit` to set the page size from 1 to 200. The default is 50.
