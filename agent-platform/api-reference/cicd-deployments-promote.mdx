---
title: Promote deployment
openapi: "/agent-platform/api-specs/project-deploy-promote.yaml post /api/cicd/v1/projects/{projectId}/deployments/{deploymentId}/promote"
---

Use this endpoint to promote an active deployment's release to a higher environment. The call moves the same immutable release to the `targetEnvironment` and checks that environment's qualification gate again. The source deployment must be `active`. The request needs the `cicd.promote` scope and authority on the target environment.

Promotion creates a new deployment and runs asynchronously. Use the returned `deploymentId` with [Get deployment](/agent-platform/api-reference/cicd-deployments-get) to track progress. To bypass the gate, set `bypassQualificationGate` to `true` and send a `bypassReason`. The bypass needs the `cicd.gate.bypass` scope. Promotion works for projects that you import with the Import API, because the release comes from a project snapshot.
