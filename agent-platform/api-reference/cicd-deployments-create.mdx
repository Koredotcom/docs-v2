---
title: Create deployment
openapi: "/agent-platform/api-specs/project-deploy-promote.yaml post /api/cicd/v1/projects/{projectId}/deployments"
---

Use this endpoint to deploy a `ready` release to an environment: `dev`, `staging`, or `production`. Send the `releaseId` and the target `environment`. The request needs the `cicd.deploy` scope and authority on the target environment. Call [Get caller identity](/agent-platform/api-reference/cicd-whoami) to check your authority.

The deployment runs asynchronously. A deploy worker enforces the qualification gate. Poll `statusUrl` or `jobStatusUrl` to track progress. To bypass the gate, set `bypassQualificationGate` to `true` and send a `bypassReason`. The bypass needs the `cicd.gate.bypass` scope. The API returns a `409` error if the release is not `ready` or the gate fails.
