Use this endpoint to exchange a platform API key for a short-lived Bearer JWT. It uses the OAuth2 client-credentials grant. Send `grant_type` as `client_credentials`, the client ID (`plt-…`), and the client secret (`abl_…`) in the request body. The endpoint needs no authentication header.

Send the returned token in the `Authorization: Bearer <token>` header on every other CI/CD API call. The token expires after 900 seconds by default. Use the optional `scope` and `projectIds` fields to narrow the key's grants. You can't widen them. The `scope` field is an array of strings, and the response returns the granted scopes as one space-delimited string. This endpoint allows 20 requests per minute. Invalid credentials return `401`.
