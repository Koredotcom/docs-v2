---
title: Exchange Platform key for JWT token
openapi: "/agent-platform/api-specs/project-deploy-promote.yaml post /api/cicd/v1/oauth/token"
---

Use this endpoint to exchange a platform API key for a short-lived Bearer JWT. It uses the OAuth2 client-credentials grant. Send the client ID (`plt-…`) and the client secret (`abl_…`) in the request body. The endpoint needs no authentication header.

Send the returned token in the `Authorization: Bearer <token>` header on every other CI/CD API call. The token expires after 900 seconds by default. Use the optional `scope` and `projectIds` fields to narrow the key's grants. You can't widen them. This endpoint allows 20 requests per minute.
