---
title: List workspace projects
openapi: "/agent-platform/api-specs/user-management.yaml get /api/public/v1/workspaces/{workspaceId}/projects"
---

Use this endpoint to list the projects in a workspace, with their member counts. You can find the project IDs that help you manage project membership. Provide a workspace key to the endpoint to get these details.

You can filter the list by `status` and `name`. The values of status are `active` or `archived` and the default is `active`. For pagination, use `limit` and `cursor` on the results. The request needs the `project.members.read` scope.
