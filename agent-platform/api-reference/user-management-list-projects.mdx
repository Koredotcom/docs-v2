title: List workspace projects
openapi: "/agent-platform/api-specs/user-management.yaml get /api/public/v1/workspaces/{workspaceId}/projects"
---

<Badge icon="arrow-left" color="gray">[Back to the User Management APIs overview](/agent-platform/api-reference/user-management-overview)</Badge>

Use this endpoint to list the projects in a workspace, with their member counts. You can find the project IDs that help you manage project membership. Provide a workspace key to the endpoint to get these details. Each project in the response includes `projectId`, `name`, `slug`, `status`, `memberCount`, and timestamps.

You can filter the list by `status` and `name`. The values of status are `active` or `archived` and the default is `active`. For pagination, use `limit` (1 to 200, default 50) and `cursor` on the results. The request needs the `project.members.read` scope.
