---
title: Update a project member role
openapi: "/agent-platform/api-specs/user-management.yaml patch /api/public/v1/projects/{projectId}/members/{memberId}"
---

Use this endpoint to change a member's project role. Send the new `roleId` in the request body. You can't change the project owner. The API returns `403 PROJECT_OWNER_IMMUTABLE`.

To avoid overwriting a concurrent change, send the `ETag` from your last read in the `If-Match` header. A mismatch returns `412 PRECONDITION_FAILED`. Send an `Idempotency-Key` header so retries are safe. The request needs the `project.members.write` scope.
