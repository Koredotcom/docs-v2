---
title: Create workspace member invitations
openapi: "/agent-platform/api-specs/user-management.yaml post /api/public/v1/workspaces/{workspaceId}/members"
---

Use this endpoint to invite up to 100 people to a workspace in one request. Each person is created at once with the status `pending`. Access starts when the person accepts the invitation and signs in. The API matches people by `externalId` first, then by email address, ignoring case.

The call returns `201` when every item succeeds and `207` when any item fails. Each item in the response carries its own `outcome`. Items not started within the 15-second request deadline return `NOT_PROCESSED`. Retry them with the same `Idempotency-Key`. Set `sendInviteEmail` to `false` to skip the invitation email. The request needs the `workspace.members.write` scope.
