<Badge icon="arrow-left" color="gray">[Back to the Project deployment APIs overview](/agent-platform/api-reference/cicd-overview)</Badge>

Use this endpoint to get a deployment's status, environment, and release. The response includes `_id`, `releaseId`, `environment`, `status`, and `previousDeploymentId`. Poll it after you create or promote a deployment. The status is `building`, `active`, `failed`, or `retired`.

The response includes `previousDeploymentId`, which is the rollback target when one exists. You can promote a deployment only when its status is `active`. A deployment that doesn't exist or that you can't access returns `404`.
