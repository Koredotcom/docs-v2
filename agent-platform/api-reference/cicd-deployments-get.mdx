---
title: Get deployment
openapi: "/agent-platform/api-specs/project-deploy-promote.yaml get /api/cicd/v1/projects/{projectId}/deployments/{deploymentId}"
---

Use this endpoint to get a deployment's status, environment, release, and versions. Poll it after you create or promote a deployment. The status is `building`, `active`, `failed`, or `retired`.

The response includes `previousDeploymentId`, which is the rollback target when one exists. You can promote a deployment only when its status is `active`.
