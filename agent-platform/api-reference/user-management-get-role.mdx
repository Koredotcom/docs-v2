---
title: Get a workspace role
openapi: "/agent-platform/api-specs/user-management.yaml get /api/public/v1/workspaces/{workspaceId}/roles/{roleId}"
---

Use this endpoint to get one built-in workspace role by ID. The response includes the role's permissions, its effective permissions, and `assignableByCaller`. A custom role ID returns `404 ROLE_NOT_FOUND`.

To list all built-in roles, use [List workspace roles](/agent-platform/api-reference/user-management-list-roles). The request needs the `workspace.roles.read` scope.
