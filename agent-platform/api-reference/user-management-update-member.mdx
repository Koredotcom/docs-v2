---
title: Update a workspace member
openapi: "/agent-platform/api-specs/user-management.yaml patch /api/public/v1/workspaces/{workspaceId}/members/{memberId}"
---

Use this endpoint to change a workspace member's role, set or replace their `externalId`, or do both. A member has one workspace role. Send at least one field, or the API returns `400 NO_FIELDS_TO_UPDATE`. If nothing would change, the API returns `409 ROLE_UNCHANGED`.

To avoid overwriting a concurrent change, send the `ETag` from your last read in the `If-Match` header. A mismatch returns `412 PRECONDITION_FAILED`. Send an `Idempotency-Key` header so retries are safe. The request needs the `workspace.members.write` scope.
