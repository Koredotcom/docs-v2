---
title: Get caller identity
openapi: "/agent-platform/api-specs/project-deploy-promote.yaml get /api/cicd/v1/whoami"
---

Use this endpoint to describe the credential that makes the call. It accepts a Bearer token. The response includes the key ID, tenant ID, allowed project IDs, scopes, and client ID. The `via` field shows whether the credential is an API key or a token.

Check the `environments` field before you deploy or promote. It lists the environments (`dev`, `staging`, or `production`) where the caller has deploy and promote authority. This authority gates deployments and promotions independent of `scopes`.
