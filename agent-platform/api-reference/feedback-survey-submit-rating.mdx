---
title: Submit rating for survey
openapi: "/agent-platform/api-specs/public-feedback-survey.yaml post /api/public/feedback/projects/{projectId}"
---

Records one rating for the survey named in the body. The rating is validated against the survey's control range (thumbs 0-1, star 1-5, scale 0-10). The rating is rejected rather than clamped when out of range, so a fabricated value can never reach the score. The response counts toward the survey's headline figure by default, scored by the survey's own method exactly as a runtime-captured response is. It requires the `feedback-survey:write` permission.
