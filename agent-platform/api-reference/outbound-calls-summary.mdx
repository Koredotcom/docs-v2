---
title: Summarize outbound calls
openapi: "/agent-platform/api-specs/outbound-calls.yaml get /api/v1/project/{projectSlug}/{env}/outbound-calls/summary"
---

Rolled-up counts for the given filters and time window: total calls, how many were answered, how many are still in flight, how many hit an answering machine, and a breakdown by terminal outcome. The request needs the `outbound_calls.read` scope.

Filter with `channelConnectionId` and a creation time window with `from` (inclusive) and `to` (exclusive). The `answered` count includes calls that reached `in_progress` at least once. The `inFlight` count includes calls that are not yet `terminal`. The `byOutcome` object counts terminal calls for each outcome.
