---
title: List LLM calls
openapi: "/agent-platform/api-specs/llm-ledger.yaml get /api/public/analytics/projects/{projectId}/llm-ledger"
---

Use this endpoint to retrieve the LLM call ledger for a project. The response contains one record for each individual LLM call, including details such as the model, provider, token usage, latency, and cost. The endpoint does not aggregate calls by conversation turn.

Use the `dataMode` parameter to control the level of detail returned. The default mode returns call-level facts, while `full` additionally includes the exact prompt and response payloads when available.

The available filtering criteria are:

- Date range — required: `fromDate` and `toDate`. `fromDate` is inclusive, while `toDate` is exclusive.
- Source: Filter by the source of the LLM call.
- Source subtype: Further filter calls by source subtype.
- Model: Filter calls by the LLM model.
- Provider: Filter calls by the model provider.
- Other query parameters: The endpoint also supports pagination and sorting, but these control how results are returned rather than which records are included.
