---
title: Get a workspace member
openapi: "/agent-platform/api-specs/user-management.yaml get /api/public/v1/workspaces/{workspaceId}/members/{memberId}"
---

Use this endpoint to get one workspace member and their project memberships. The response includes the member's status, role, `externalId`, and attributes.

The `ETag` response header holds the member's `revision`. Send it in the `If-Match` header when you [update the member](/agent-platform/api-reference/user-management-update-member). The request needs the `workspace.members.read` scope.
