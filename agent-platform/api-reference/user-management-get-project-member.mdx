---
title: Get a project member
openapi: "/agent-platform/api-specs/user-management.yaml get /api/public/v1/projects/{projectId}/members/{memberId}"
---

Use this endpoint to get one project member. The `memberId` in the path is the workspace member ID. The response includes the member's project role and `revision`.

The `ETag` response header holds the `revision`. Send it in the `If-Match` header when you [update the member's role](/agent-platform/api-reference/user-management-update-project-member). The request needs the `project.members.read` scope.
