---
title: List deployments
openapi: "/agent-platform/api-specs/project-deploy-promote.yaml get /api/cicd/v1/projects/{projectId}/deployments"
---

Use this endpoint to list the deployments of a project. Use it to see what runs in each environment or to find the deployments of a release. Each item has the same fields as the response of [Get deployment](/agent-platform/api-reference/cicd-deployments-get).

Filter the list with `environment` (`dev`, `staging`, or `production`), `releaseId`, and `status`. Page through the results with `limit` and `offset`.
