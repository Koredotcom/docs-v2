---
title: Search workspace members
openapi: "/agent-platform/api-specs/user-management.yaml post /api/public/v1/workspaces/{workspaceId}/members/search"
---

To search workspace members, use this API with the filters in the request body. While this request returns the same results as [List workspace members](/agent-platform/api-reference/user-management-list-members), but it keeps email addresses out of URLs and logs. You can filter by status, role, email addresses, `externalId`, and `updatedSince`. You must send either `status` or `statuses`, but not both. This API request needs the `workspace.members.read` scope.

Set `include` to `projects` to return each member's project memberships.

Results are paginated with a cursor. Pass `nextCursor` from the response as `cursor` in the next request.
