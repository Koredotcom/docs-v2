---
title: Terminate outbound calls
openapi: "/agent-platform/api-specs/outbound-calls.yaml post /api/v1/project/{projectSlug}/{env}/outbound-calls/{outboundCallId}/terminate"
---

<Badge icon="arrow-left" color="gray">[Back to the Outbound Dialing API overview](/agent-platform/api-reference/outbound-calls-overview)</Badge>

Hangs up a call that has not yet reached `phase=terminal`. Drives the call to `phase=terminal`, `outcome=canceled`. Don't use this API on a call that's already terminal. It returns the call's existing terminal state, not an error.

The request needs the `outbound_calls.initiate` scope, the same scope as placing a call. The `outbound_calls.read` scope is not enough. The response returns the `outboundCallId`, `phase`, and `outcome`. A call ID that does not exist, or that belongs to a different project, returns `404`.
