title: Apply a workspace member lifecycle action
description: Apply a lifecycle action, such as suspend, reactivate, or reset MFA, to a workspace member.
openapi: "/agent-platform/api-specs/user-management.yaml post /api/public/v1/workspaces/{workspaceId}/members/{memberId}/actions"
---

<Badge icon="arrow-left" color="gray">[Back to the User Management APIs overview](/agent-platform/api-reference/user-management-overview)</Badge>

Using this API, you can apply a lifecycle action on a member. The actions to manage workspace members are `deactivate`, `suspend`, `reactivate`, `reset_mfa`, `revoke_sessions`, and `resend_invite`. This API request updates only a single workspace. The request needs the `workspace.members.write` scope. Send an optional `reason` of up to 500 characters. A successful response returns the updated member and the previous status.

<Note>The platform allows a maximum of 10 actions per hour per member.</Note>

Each action works only on members with specific statuses:

| Action            | Allowed from status                  | Result                                                                                |
|:------------------|:-------------------------------------|:--------------------------------------------------------------------------------------|
| `deactivate`      | `active`, `suspended`, `locked`      | The status becomes `deactivated`. Workspace sessions end.                             |
| `suspend`         | `active`                             | The status becomes `suspended`. Workspace sessions end.                               |
| `reactivate`      | `suspended`, `deactivated`, `locked` | The status becomes `active`. A sign-in lockout returns `409 LOCKED_BY_LOGIN_LOCKOUT`. |
| `reset_mfa`       | `active`, `locked`                   | MFA enrollment is cleared.                                                            |
| `revoke_sessions` | `active`, `suspended`, `locked`      | Workspace sessions end. The status doesn't change.                                    |
| `resend_invite`   | `pending`, `expired`                 | A new invitation is sent and its expiry restarts.                                     |

An inapplicable status combination returns the error `409 INVALID_STATE_TRANSITION`.
