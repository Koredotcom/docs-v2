---
title: Apply a workspace member lifecycle action
openapi: "/agent-platform/api-specs/user-management.yaml post /api/public/v1/workspaces/{workspaceId}/members/{memberId}/actions"
---

Using this API, you can apply a lifecycle action on a member. The actions to manage workspace members are `deactivate`, `suspend`, `reactivate`, `reset_mfa`, `revoke_sessions`, and `resend_invite`. This API request updates only a single workspace. The request needs the `workspace.members.write` scope. A successful response returns the updated member and the previous status.

<Note>The platform allows a maximum of 10 actions per hour per member.</Note>

The applicable actions work only on specific existing statuses.

* `suspend` works only on an `active` member.
* `resend_invite` works only on a `pending` or `expired` member.

An inapplicable status combination returns the error `409 INVALID_STATE_TRANSITION`.
