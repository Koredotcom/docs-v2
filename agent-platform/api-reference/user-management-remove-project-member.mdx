---
title: Remove a project member
openapi: "/agent-platform/api-specs/user-management.yaml delete /api/public/v1/projects/{projectId}/members/{memberId}"
---

Use this endpoint to remove a member from a project. The `memberId` in the path is the workspace member ID. You can't remove the project owner. The API returns `403 PROJECT_OWNER_IMMUTABLE`.

The request needs the `project.members.write` scope.
