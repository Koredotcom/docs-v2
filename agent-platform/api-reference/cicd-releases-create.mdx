---
title: Create release
openapi: "/agent-platform/api-specs/project-deploy-promote.yaml post /api/cicd/v1/projects/{projectId}/releases"
---

Use this endpoint to build an immutable release of a project. The call starts an asynchronous build that produces compiled IR, pinned entity versions, an integrity hash, and an encrypted `.ablenc` bundle. The response returns a `releaseId` and a `statusUrl`. Poll [Get release](/agent-platform/api-reference/cicd-releases-get) until the status is `ready`.

Set `source.kind` to choose the content source. Use `project_snapshot` to capture the project's current content without a Git integration. Use `git`, or omit the field, to build from a branch, tag, or commit. The build is independent of the environment. It needs the `cicd.release.create` scope and project membership, but not environment authority. If an identical versioned release exists, the API reuses it and returns `reused: true`.
