Use this endpoint to get a release and check its build status. Poll it after you [create a release](/agent-platform/api-reference/cicd-releases-create). Wait until the `status` is `ready` before you deploy the release. The `status` is one of `building`, `validated`, `compiled`, `materializing`, `materializing_versions`, `ready`, `materialization_failed`, `failed`, or `superseded`. The `failed` and `materialization_failed` statuses mean the build did not complete.

The response includes the release source, version, and content integrity hash. The hash is set when the release is `ready`. It also includes a summary of the release's deployments for each environment. A release that doesn't exist or that you can't access returns `404`.
