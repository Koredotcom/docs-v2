---
title: Get release
openapi: "/agent-platform/api-specs/project-deploy-promote.yaml get /api/cicd/v1/projects/{projectId}/releases/{releaseId}"
---

Use this endpoint to get a release and check its build status. Poll it after you [create a release](/agent-platform/api-reference/cicd-releases-create). Wait until the `status` is `ready` before you deploy the release. A `failed` status means the build did not complete.

The response includes the release source, version, and content integrity hash. The hash is set when the release is `ready`. It also includes a summary of the release's deployments for each environment.
