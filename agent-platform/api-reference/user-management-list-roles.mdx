---
title: List workspace roles
openapi: "/agent-platform/api-specs/user-management.yaml get /api/public/v1/workspaces/{workspaceId}/roles"
---

Use this endpoint to list the built-in workspace roles, their permissions, and whether a platform key can assign each role. The endpoint does not return custom roles.

Check `assignableByCaller` before you assign a role. It is the source of truth. A key can assign only `builtin.workspace.restricted_member` and `builtin.workspace.workbench_manager`. The request needs the `workspace.roles.read` scope.
