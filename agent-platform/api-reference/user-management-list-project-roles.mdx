---
title: List assignable project roles
openapi: "/agent-platform/api-specs/user-management.yaml get /api/public/v1/projects/{projectId}/roles"
---

Use this endpoint to list the built-in project roles and whether the key can assign each one. Check `assignableByCaller` before you add or update a project member.

A key can assign `builtin.project.developer`, `builtin.project.tester`, `builtin.project.viewer`, and `builtin.project.workbench_manager`. The request needs the `project.members.read` scope.
