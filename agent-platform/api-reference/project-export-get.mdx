<Badge icon="arrow-left" color="gray">[Back to the Project API overview](/agent-platform/api-reference/project-import-export-overview)</Badge>

Use this endpoint to get the status of a project export. Poll it with the `operationId` that [Start project export](/agent-platform/api-reference/project-export-post) returns. The status values include `queued`, `processing`, `packaging`, `completed`, and `failed`. The `progressPercent` field estimates progress from 0 to 100. The request needs the `project_io.read` scope.

When the export is `completed`, the response includes the manifest, the lockfile, and a short-lived `downloadUrl`. Download the archive before `expiresAt`. The lockfile holds content hashes that you can use to verify the archive. A successful request does not mean the export succeeded. Check `data.status` and `data.errors`.
