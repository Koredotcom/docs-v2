---
title: List workspace members
openapi: "/agent-platform/api-specs/user-management.yaml get /api/public/v1/workspaces/{workspaceId}/members"
---

You can list the members of a workspace using this endpoint. The request needs the `workspace.members.read` scope. You can filter the list by `status`, `roleId`, `emails`, `externalId`, and `updatedSince`. To filter by email address, use [Search workspace members](/agent-platform/api-reference/user-management-search-members) so addresses stay out of URLs.

Results are paginated with a cursor. Pass `nextCursor` from the response as `cursor` in the next request. A cursor works only with the filters it was issued for. Set `include` to `projects` to return each member's project memberships. The maximum `limit` is then 50.
