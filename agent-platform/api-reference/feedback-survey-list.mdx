---
title: List survey response
openapi: "/agent-platform/api-specs/public-feedback-survey.yaml get /api/public/feedback/projects/{projectId}"
---

Returns a page of responses with an opaque keyset cursor, with the oldest response first. The cursor is keyset (timestamp, response_id) rather than an offset, so a client polling forward through history never skips a response or sees one twice as new rows arrive. No per-response score is returned: a score is a property of a population, not of one answer. Requires the `feedback-survey:read` permission.
