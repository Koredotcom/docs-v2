---
title: Add project members
openapi: "/agent-platform/api-specs/user-management.yaml post /api/public/v1/projects/{projectId}/members"
---

Use this endpoint to add 1 to 100 active workspace members to a project. Each item names exactly one of `memberId`, `externalId`, or `email`, and a `roleId`. A person must already be an active workspace member. To check which roles a key can assign, call [List assignable project roles](/agent-platform/api-reference/user-management-list-project-roles).

The call returns `201` when every item succeeds and `207` when any item fails. Each item carries its own `outcome`. Send an `Idempotency-Key` header so retries are safe. The request needs the `project.members.write` scope.
