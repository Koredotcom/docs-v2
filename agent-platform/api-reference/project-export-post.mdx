<Badge icon="arrow-left" color="gray">[Back to the API overview](/agent-platform/api-reference/project-import-export-overview)</Badge>


Use this endpoint to start an asynchronous export of a project. The server checks project readiness, discovers agent and tool dependencies, adds the required dependency layers, assembles the archive, and generates its manifest and lockfile. The response returns an `operationId` and a `statusUrl`. Poll [Get project export status](/agent-platform/api-reference/project-export-get) until the export is `completed`. The request needs the `project_io.read` scope.

The request body is optional. Use `format` to choose `zip` (default), `folder`, or `tar.gz`. Use `layers` to select layers. The `core` layer is always included. The export leaves out deployments, version history, and Knowledge Base documents unless you set `includeDeployments`, `includeVersionHistory`, or `includeKnowledgeBaseDocuments` to `true`. Exports never include environment credentials. Send an `Idempotency-Key` header so a retry is safe.
