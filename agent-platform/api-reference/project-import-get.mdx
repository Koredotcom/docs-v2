Use this endpoint to get the status of a project import. Poll it with the `operationId` that [Start project import](/agent-platform/api-reference/project-import-post) returns. The response shows the overall `status`, the `progressPercent`, and the state of each layer: `pending`, `staged`, `activated`, `skipped`, `failed`, or `rolled_back`. The request needs the `project_io.write` scope.

After the import finishes, `applied` shows how many records and tools the import created, updated, and deleted. `dependencyValidation` lists missing and circular dependencies. Warnings are informational and errors are blocking. A `reverted` status means the import's changes were reverted. A successful request does not mean the import succeeded. Check `data.status` and `data.errors`.
