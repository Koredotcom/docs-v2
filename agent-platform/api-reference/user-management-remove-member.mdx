---
title: Remove a workspace member
openapi: "/agent-platform/api-specs/user-management.yaml delete /api/public/v1/workspaces/{workspaceId}/members/{memberId}"
---

Use this endpoint to revoke a pending or expired invitation, or to remove an active member from the workspace and its projects. If the member owns projects or agents, set `transferOwnershipTo` to the `memberId` of an eligible active member. Otherwise the request fails with `409 MEMBER_OWNS_RESOURCES`.

The response reports how many project memberships the API removed, and how many projects and agents it transferred. The request needs the `workspace.members.write` scope.
