---
title: List session summaries
openapi: "/agent-platform/api-specs/sessions.yaml get /api/public/analytics/projects/{projectId}/sessions"
---

Use this endpoint to retrieve session-level analytics for a project. Each result represents one conversation session and includes summary information such as the channel, environment, status, containment outcome, message and trace-event counts, token usage, cost, and session duration. The response does not include the individual messages or trace details; use the conversation-history and traces endpoints to retrieve those details.

It provides the following filters:

- `fromDate` — Inclusive start timestamp.
- `toDate` — Exclusive end timestamp.
- `sessionIds` — Filter by specific session IDs; up to 10,000.
- `containmentType` — Filter by how the session was resolved, such as `contained_resolved`, `contained_partial`, `escalated`, or `abandoned`.
- `environment` — Filter by environment: `dev`, `staging`, `production`, or `working-copy`.
- `channelUId` — Filter by the end-user identity recorded on the channel.
- `callerNumber` — Filter by caller number or caller identity.
- `channel` — Filter by the channel through which the conversation originated.
- `traceDimensions[key]` — Filter by custom session dimensions and their values.
- `status` — Filter by session state, such as `active`, `idle`, `ended`, `completed`, `escalated`, or `abandoned`.

You must provide either `fromDate` and `toDate` together, or `sessionIds`. All other filters are optional. Multiple filters are combined with `AND` logic; multiple values within a filter are combined with `OR` logic.

Use `limit` and `offset` to paginate through the results.
