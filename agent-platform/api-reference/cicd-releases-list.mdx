<Badge icon="arrow-left" color="gray">[Back to the Project deployment APIs overview](/agent-platform/api-reference/cicd-overview)</Badge>

Use this endpoint to list the releases of a project. Use it to find a release ID or to review the build history. Each item has the same fields as the response of [Get release](/agent-platform/api-reference/cicd-releases-get).

Filter the list with the `status`, `branch`, and `version` query parameters. Page through the results with `limit` (minimum 1) and `offset` (minimum 0).
