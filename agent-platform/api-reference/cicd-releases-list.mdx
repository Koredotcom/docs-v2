---
title: List releases
openapi: "/agent-platform/api-specs/project-deploy-promote.yaml get /api/cicd/v1/projects/{projectId}/releases"
---

Use this endpoint to list the releases of a project. Use it to find a release ID or to review the build history. Each item has the same fields as the response of [Get release](/agent-platform/api-reference/cicd-releases-get).

Filter the list with the `status`, `branch`, and `version` query parameters. Page through the results with `limit` and `offset`.
