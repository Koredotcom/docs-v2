`fromDate` and `toDate` are required. `fromDate` is included in the results and `toDate` is not, so a full day is `fromDate=2026-08-04T00:00:00Z&toDate=2026-08-05T00:00:00Z`.

All other filters are optional and match exactly. Filters combine with AND, so adding more narrows the results. `source` and `sourceSubtype` also accept older spellings and translate them for you — see those parameters for the details.
