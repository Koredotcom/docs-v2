<Badge icon="arrow-left" color="gray">[Back to the Outbound Dialing API overview](/agent-platform/api-reference/outbound-calls-overview)</Badge>

Paginated list of outbound calls for the project/environment, most recent first. Destinations are always masked. Combine filters freely; all supplied filters apply together (AND). The request needs the `outbound_calls.read` scope.

Filter by `channelConnectionId`, `phase`, `outcome`, `clientReferenceId`, and a creation time window with `from` (inclusive) and `to` (exclusive). Page with `limit` (1 to 100, default 50) and `cursor`. Pass the `nextCursor` from the response as `cursor` to get the next page. It is null on the last page. To find calls by destination number, use [Search outbound calls](/agent-platform/api-reference/outbound-calls-search).
