The Microsoft OneDrive connector indexes files in OneDrive storage for use in a knowledge base. Configure a platform-managed Microsoft Graph profile, choose the account and synchronization scope, and set folder and permission options before generating a proposal.

## Specifications

| Specifications               | Details                            |
|------------------------------|------------------------------------|
| Supported content            | Files in selected OneDrive folders |
| Permission-aware ACL support | Yes                                |
| Content filtering            | Yes                                |

## Prerequisites

Before you configure the connector, ensure that you meet the following prerequisites:

- Access to the Microsoft OneDrive account or the corresponding M365 tenant that you want to index.
- Create or select a **platform-managed Microsoft profile** for Microsoft Graph.
- An appropriate admin must grants the requisite Microsoft Entra consent before selecting the profile.

## Connector configuration

### Connect Microsoft OneDrive

Select an authorized Microsoft profile from **Microsoft OneDrive connection**. To create one, select **New auth profile** and complete the Microsoft authorization flow. The profile must be authorized for the account or tenant you plan to crawl.

### Choose account and scope

Select the account type and synchronization mode, then choose which drive content to include.

| Setting                   | Description                                                                                                                         |
|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------|
| **OneDrive for Business** | Connects to a business OneDrive account. Choose either **Connected user** or **Business tenant users** as the synchronization mode. |
| **Personal OneDrive**     | Uses the connected user's delegated access. Only that user's My Drive is available.                                                 |
| **Connected user**        | Syncs the authorized user's My Drive.                                                                                               |
| **Business tenant users** | Uses application permissions to crawl the owner My Drives of users in the tenant.                                                   |
| **My Drive**              | Includes folders from the connected user's My Drive.                                                                                |
| **Shared Drive**          | Includes folders added using Microsoft sharing URLs.                                                                                |

The available synchronization modes depend on the account type. For **Personal OneDrive**, only the connected user's delegated My Drive is available.

### Select folders

Browse and select the folder roots to sync. Select **Index subfolders** to recursively include nested folders. Turn it off to index only the selected folders.

### Enforce document permissions

Enable **Enforce document permissions** to apply Microsoft Graph file permissions as document-level retrieval ACLs. It resolves the group membership after it's authorized. The connector doesn't require the `Sites.FullControl.All` permission.

Generate a proposal after configuring the connection, account scope, folders, and permissions. Review the proposal, then activate the connector using the available approval flow.
