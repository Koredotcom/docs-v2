We provide dozens of connectors, including Microsoft SharePoint, Confluence, ServiceNow, Microsoft OneDrive, Google Drive, Slack, Microsoft Teams, Salesforce, Jira, HubSpot, Zendesk, and more. The connectors let you ingest data from a range of third-party repositories out-of-the-box support. If you want to use a repository not listed below, [contact us](https://kore.ai/contact-us/).
