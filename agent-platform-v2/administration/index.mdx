Configure your workspace, team, AI models, and account settings from the Settings console. Only users with the Admin or Owner role can access the Settings console.

**Navigation**

Log in and go to **Profile** > **Admin**. 

The admin panel is organized into four sections: 

## Team Settings

| Page               | Description                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| [Workspace Members](/agent-platform-v2/administration/team/workspace-members)  | Invite new users to your organization. Assign system roles. Revoke member access instantly. |
| [Custom Roles](/agent-platform-v2/administration/team/custom-roles)       | Build granular permission profiles. Define unique access levels for specific teams. |
| [Security & Compliance](/agent-platform-v2/administration/team/security-and-compliance) | Set up Single Sign-On (SSO). Enforce Multi-Factor Authentication (MFA). Establish workspace audit policies. |
| [Workspace Audit Logs](/agent-platform-v2/administration/team/workspace-audit-logs)         | Monitor comprehensive organization-wide activity histories. Track configuration updates. Export logs for compliance. |
| [Key Management](/agent-platform-v2/administration/team/key-management)     | Connect Key Management Service (KMS) platforms. Rotate encryption keys. Secure data at rest. |
| [Environment Variables](/agent-platform-v2/administration/team/environment-variables)      | Define global environment variables. Sync configurations across development and production pipelines. |

## AI Configuration

| Page          | Description                                                                 |
|---------------|-----------------------------------------------------------------------------|
| LLM Providers | Connect external large language model endpoints. Input API credentials. Set default models. |
| Arch          | Define autonomous agent architectures. Configure system prompt orchestration. Set token routing rules. |
| Voice Services| Integrate Speech-to-Text (STT) engines. Connect Text-to-Speech (TTS) providers. Adjust voice characteristics. |
| Guardrails    | Implement real-time content safety filtering. Define data anonymization masks. Block toxic inputs. |
| Auth Profiles | Create reusable authentication profiles. Share credential sets securely across multiple projects. |

## Analytics

| Page             | Description                                                                 |
|------------------|-----------------------------------------------------------------------------|
| Agent Performance| Track key system health metrics. Monitor latency trends. Review token consumption volumes. |
| Session Explorer | Inspect end-to-end user conversation histories. Analyze individual session metadata. Debug context windows. |
| Trace Viewer     | Pinpoint runtime bugs step-by-step. Inspect nested LLM tool calls. View complete execution graphs. |

## Account

| Page              | Description                                                                 |
|-------------------|-----------------------------------------------------------------------------|
| Workspace Settings| Customize your workspace display name. Modify the unique URL slug. Delete the workspace. |
| Secrets           | Store enterprise proxy configurations. Inject global OAuth tokens. Secure the integrations. |
| Billing & Usage   | Track active credit balances. Review usage dashboards. Set automated budget spend alerts. |
| Connectors        | Link external communication channels. Deploy custom SDK integrations. Manage API webhooks. |
