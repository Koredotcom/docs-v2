Workspace Owners and Admins can define custom roles with granular permissions.

These are tenant-scoped and managed through Settings icon from the top navigation > **Team** > **Custom Roles**.

## Create a Role

To define a new role, enter a Role name and optional Description, then select the required permissions. Once configured, click Create to save the role.

**Role Assignment**

- Built-in Roles: Managed on the Members page.
- Project Roles: Governed by the Custom Project Roles flow.
