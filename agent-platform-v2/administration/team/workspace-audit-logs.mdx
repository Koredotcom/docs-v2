Investigate compliance events across access, identity, security, configuration, data protection, and production-impacting changes. Use the filter bar (search, date range, actions, presets, categories) to narrow results quickly.

- Navigation: Settings > Team > Audit Logs
- Required role: Owner or Admin
- Plan requirement: Export available on Professional & Enterprise

The page shows a tenant-scoped, filterable record of all significant workspace actions. Use it to investigate incidents, verify compliance, and review team activity.

- Refresh reloads the log
- Export CSV downloads the current filtered view

## Summary Metrics

| Metric | Description |
| --- | --- |
| Matching events | Total events matching filters |
| Failed on page | Failed events on current page |
| Actors on page | Distinct actors on current page |
| Active filters | Number of filters applied |
| Last event | Timestamp of most recent event |

## Categories

| Category | Examples |
| --- | --- |
| Auth & access | Login, logout, MFA, SSO, API keys |
| Workspace governance | Member invites, role changes, ownership transfers |
| Project, agent & workflow config | Agent creation, updates, deployments, workflow changes |
| Tools, modules & credentials | Tool bindings, module updates, credential changes |
| Data protection | KB updates, uploads, exports, retention events |
| KMS | Key rotations, DEK creation, provider changes |
| Connector configuration | Channel connections, SDK changes |
| Archives, retention & Git | Archiving, retention policy changes, Git events |

## Audit Log Table

| Column | Description |
| --- | --- |
| Timestamp | When action occurred |
| Category | Event category |
| Action | Specific action (e.g., agent.dsl_updated) |
| Actor | User/system ID |
| Target | Resource affected |
| Project | Associated project |
| Source | Origin (studio, runtime-store) |
| IP | Request IP address |
| Trace | Trace ID if available |

## Retention

- Follows workspace retention policy
- Professional & Enterprise: at least 90 days
- Contact support for extended retention
