## 4. Cross-cutting themes (the recurring ABL/platform changes)

1. **Guardrail API overhaul** (ABLP-1103). `not_contains_blocked_words` / `not_matches_pattern` / `toxicity_score(...) < 0.5` → `abl.matches_pattern`, `abl.contains_pii`, `abl.word_count`. **Check polarity inverted:** a guardrail fires when the predicate returns **`true`**. New `llm_check:` (natural-language judgments) and `provider:` (model-backed, e.g. `openai_moderation`). Variables standardized: `response`/`text` → `output`/`input`.
2. **HANDOFF vs ESCALATE split** (ABLP-1251). `HANDOFF:` = machine-to-machine only; human/system routing → dedicated `ESCALATE:` block. `PRIORITY` numeric field removed (ordering is position-based).
3. **Memory grants** (ABLP-1251). `grant_memory:[path,…]` → `memory_grants:[{path,access}]` with `read`/`readwrite`. New **`execution_tree`** memory scope (survives one workflow/handoff chain).
4. **Structured `ON_RETURN` + `RETURN_HANDLERS`** (ABLP-1251). String `ON_RETURN:"handler"` → object `{handler, map}`; new top-level `RETURN_HANDLERS:` block.
5. **History strategies** (ABLP-1251). New `auto` default; `last_N` string → `{ mode: last_n, count: <n> }`.
6. **`WHEN` = deterministic expressions** (ABLP-1251). Natural-language WHEN → boolean expressions (`intent.category == "billing"`).
7. **`ON_ACTION` keyed-map syntax** (ABLP-1251). List-of-objects + `ACTION_ID` → map keyed by action id, with `DO:` ordered action lists; `THEN` → `GOTO`.
8. **LIMITATIONS reframed** (ABLP-1103/1251). "Hard/explicit boundaries" → "prompt-level boundaries" (advisory). `CONSTRAINTS` is the deterministic/runtime-enforced counterpart.
9. **Constraint labels renamed** (ABLP-542/1251). `pre_search`/`pre_booking`/`pre_action`/`pre_change` → `search_rules`/`booking_rules`/`action_rules`/`change_rules`; "phases" → "labels"; plain list strings are **not** runtime constraints.
10. **RBAC overhaul** (ABLP-377/1066). Project roles `Project Admin/Editor/Viewer` → `Admin/Developer/Tester/Viewer`; workspace gains **OPERATOR**; custom roles "tenant-scoped"; permission strings singular + underscore (`agent:update`, `tenant:manage_members`); bulk CSV invite/export removed.
11. **Docs search feature** (ABLP-207) + **design-token centralization** (ABLP-984/1253).
