AI for HR reaches your data through three connections: Workday, ServiceNow, and Search AI. This page lists what each connection carries and which tools use it.

Use it to brief your system owners. Each row tells them which API calls the agents make and which agent depends on them.

## Integrations in the current implementation

The shipped tools call two systems of record and one knowledge service. Everything the agents read or write travels through them.

| Integration | Type | What AI for HR uses it for |
|-------------|------|-----------------------------|
| **Workday** | System of record | Leave, benefits, payroll, the employee master record, timesheets, and termination |
| **ServiceNow** | System of record | The HR service catalog and HR cases |
| **Search AI** | Knowledge service | HR policy and handbook answers through the advanced search API |

## Workday

Six specialists depend on Workday, which makes it the first access request to raise. Each agent calls its own tools.

| Agent | Tools |
|-------|-------|
| **Time Off Assistant** | `fetch_time_off_balance`, `fetch_calendar_events`, `fetch_time_off_requests`, `create_time_off` |
| **Benefit Management** | `fetch_dependents`, `add_dependents`, `submit_benefit`, `search_enrolled_benefits`, `benefits_for_employees`, `get_user` |
| **Compensation** | `search_payslips` |
| **Profile Management** | `search_user`, `get_user`, `update_user` |
| **Offboarding Management** | `resignation_reasons`, `resign_user` |
| **Timesheet Management** | Timesheet retrieval for the employee and their direct reports |

## ServiceNow

Case Management is the only agent that calls ServiceNow. It reads the service catalog and manages cases end to end.

| Tool | What it does |
|------|--------------|
| `get_hr_services` | Retrieves the list of available HR services. |
| `create_ticket` | Creates a new HR support case. |
| `ticket_actions` | Adds and views comments, views a case, and resolves a case. |

## Search AI

Search AI serves every policy answer. It connects to your repository through a connector and to the agentic app through the advanced search API.

| Element | Detail |
|---------|--------|
| **Connector** | Configured in XO11 under **Search AI** > **Connectors**, for example Confluence Cloud |
| **API** | The advanced search API, called by the `data_retrieval` HTTP tool |
| **Authentication** | A JWT signed with your Search AI app's client secret, using HS256 |
| **Filtering** | The `sourceType` value copied from an indexed chunk |
| **Regions** | India and the US |

## Channels

Employees reach AI for HR through AI for Work, so every AI for Work channel works with it.

- AI for Work assistant
- Microsoft Teams
- Copilot
- Web
- Voice
- SDKs for your own applications

## Extend to other systems

Your HR landscape may include systems beyond Workday and ServiceNow. Every agent reaches its data through HTTP tools, so extending the accelerator follows the same pattern as the shipped tools.

1. Create an HTTP tool for each endpoint in the new system.
2. Wrap multi-step logic in a workflow tool and register it as Synchronous.
3. Add config variables for identity and connection values.
4. Attach the tools to the agent that owns the domain.
