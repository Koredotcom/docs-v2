Employees reach AI for HR through a single Autonomous Agent in AI for Work. Create the agent, connect it to your agentic app, pass the metadata your tools need, and publish.

Complete the Agent Platform configuration first. The connection test fails until the agentic app exists in the workspace you select.

## Create the Autonomous Agent

Start in AI for Work and create the agent that fronts your agentic app.

1. Open work.kore.ai.
2. Click your profile and open **Workspaces**.
3. Select your workspace, then open **Autonomous Agents**.
4. Click **Create agent** > **Create from scratch**.
5. Enter the agent name and the purpose of the app, then click **Continue**.

## Connect the agentic app

The agent points at the Agent Platform workspace that holds AI for HR. Test the connection before you go any further.

1. Click **Add agent**.
2. Select the Agent Platform workspace where you created the AI for HR app, then click **Done**.
3. Set the **Mode** to **Async**.
4. Test the connection. The test passes when it displays **Async connection success**.

## Pass custom metadata

The agents need to know who is asking. Pass the employee's email as custom metadata, so the tools resolve the right person at run time.

1. In **Configure agentic app**, open **Meta Data**.
2. Add the custom metadata you want to pass to the connected app, such as the employee's email.

Each context in Agent Platform reads the metadata with its own path:

```text
Agent:         {{_metadata.email}}
Workflow tool: {{vars._session._metadata.email}}
HTTP tool:     {{session._metadata.email}}
```

## Publish

Publishing makes the agent available to employees in your workspace. Publishing stays enabled by default.

1. Click **Continue**.
2. Click **Publish**.

## Confirm the deployment

Run three checks before you invite pilot users. Each one catches a common deployment issue.

| Check | It passes when |
|-------|----------------|
| **Connection** | The agent shows **Async connection success**. |
| **Metadata** | The agentic app receives the employee's email in every context that needs it. |
| **Default model** | **Project Settings** > **General** > **Models** matches the workspace default. |

After these checks pass, test the agent end to end with the scenarios in **Validate and test AI for HR**.
