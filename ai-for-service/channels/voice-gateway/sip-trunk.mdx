The SIP (Session Initiation Protocol) Trunk feature lets you set up and manage phone calls over the internet. When a phone system calls a bot, SIP is establishes the connection. SIP uses numeric error codes (like HTTP status codes for websites) to communicate what went wrong.

## Configure SIP Trunk

You can configure SIP trunk to enable seamless call routing between systems using SIP protocols for efficient voice communication.

### Transfer a Call to Contact Center Using SIP Trunk

You can set up a dedicated number or SIP to transfer calls to a voice agent.


### Failures during agent transfer

When the bot transfers a call to a live agent using SIP INVITE or SIP REFER, the receiving agent system may return a SIP error code if the transfer fails. Voice Gateway captures the error, and the Error Path in the Experience Flow handles the failure.
