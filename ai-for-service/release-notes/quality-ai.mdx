## v11.28.0 August 29, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">AutoQA</p>

<p className="rn-subtitle">Calibration Participant Access and Session Review</p>

Quality AI now includes dedicated Assigned to Me and Closed tabs for users with access to QA functionality. Participants can view their assigned active calibration sessions, track scoring progress, and select Score Now to enter Calibration Mode. Once a session closes, participants can view a read-only Calibration Session Report for any sessions they participated in. Calibration Managers retain their existing management access and can also participate in assigned sessions. [Learn more→](/ai-for-service/quality-ai/analyze/calibration-sessions)

<p className="rn-title">Coaching</p>

<p className="rn-subtitle">Transfer-Leg Level Evaluation</p>

Quality AI now evaluates transferred contacts separately for each agent who handled the call. Each transfer leg is scored using the evaluation form for the relevant queue, with only applicable metrics evaluated. QA teams can review, audit, dispute, and coach each agent based on their own leg. Existing whole-conversation evaluation remains unchanged when this feature is disabled. [Learn more→](/ai-for-service/quality-ai/coaching) 

<p className="rn-title">Analytics</p>

<p className="rn-subtitle">Evaluating Bot Conversations</p>

Quality AI now includes a Minimal license for Automation AI that supports only Automation AI conversations and related features. The license includes AutoQA, Conversation Intelligence, Evaluation Forms, and Taxonomy Builder. Sales App and Builder navigation now show features based on the assigned license. A new Automation/Conversation Insights dashboard provides insights into sentiment, churn, adherence, and intent from Automation AI conversations. If Quality AI or Automation AI isn't enabled, users can enable it from the dashboard, with the required settings and default form configured automatically.

<p className="rn-title">API</p>

<p className="rn-subtitle">Export Auditor Comments support for Raw Data API</p>

The Raw Data API now exposes metric-level auditor and dispute re-evaluation comments as structured data, supporting comprehensive MIS and BI reporting while maintaining full backward compatibility with existing Interaction Evaluations reports and API integrations. [Learn more→](/ai-for-service/apis/quality-ai/raw-data-api)

## v11.27.1 August 08, 2026

<Badge> Patch Release </Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Auto QA</p>

<p className="rn-subtitle">Not Applicable Scoring Treatment</p>

Organizations can now configure how Not Applicable (N/A) metrics affect evaluation scores. Administrators can choose to either exclude them from the score (default) or award full weightage, for a fair and consistent scoring model. The setting is available independently at both the Evaluation Form and Agent Scorecard levels, applies to AutoQA and manual audits across all metric types, and is versioned without changing historical scores. Updated scoring is reflected across audits, dashboards, reports, APIs, and import/export configurations. [Learn more→](/ai-for-service/quality-ai/configure/evaluation-forms#not-applicable-scoring-treatment)

## v11.26.1 July 11, 2026

<Badge>Patch Release</Badge>

<p className="rn-title">AutoQA</p>

Agents now automatically receive email notifications when a coaching session is assigned to them, eliminating the need to check their Assignments dashboard regularly. The By AI Agent metric now supports Artemis project-based integration as an alternative to the existing Agent Platform V1 integration. ## v11.26.0 June 27, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">AutoQA</p>

<p className="rn-subtitle">Scheduled Processing for Agent AI, CCAI, and Automation AI Conversations</p>

Quality AI now supports scheduled processing for Agent AI, CCAI, and Automation AI conversation sources. Administrators can define daily processing windows to optimize LLM usage during off-peak hours.

Conversations are visible before processing and can be filtered by status: Processed, Pending, or Validation Failed. Audit screens, reports, and APIs now include processing-status information, so users can track unprocessed and failed conversations and identify validation issues more effectively. [Learn more→](/ai-for-service/quality-ai/analyze/conversation-mining-interactions)

<p className="rn-subtitle">Automation AI Conversation Source Support</p>

Quality AI now supports Automation AI as a conversation source, enabling AI Agent conversation evaluations through Experience Flow-based form assignments.
This support extends across Conversation Mining, Audit, QA Dashboard, Conversation Intelligence, Reporting, APIs, and Onboarding Journeys, and includes:

- AI Agent and Human Agent segmentation
- Handled By filtering
- Flow-based reporting
- Audit and analytics capabilities for AI Agent conversations

[Learn more→](/ai-for-service/quality-ai/analyze/conversation-mining-interactions)

<p className="rn-title">Configure</p>

<p className="rn-subtitle">By Question Metric V2</p>

The `By Question Metric V2` is a new metric creation experience that evaluates trigger conditions and expected agent behavior using a single, unified rule.

V2 generates clearer AI justifications for Adhered, Not Adhered, and Not Applicable outcomes, improving audit transparency and reducing configuration complexity. It also supports more advanced evaluation scenarios, including multi-condition logic and enhanced compliance checks.

Existing By Question metrics continue to operate without changes. [Learn more→](/ai-for-service/quality-ai/configure/evaluation-criteria/metrics-measurement-types/by-question)

<p className="rn-title">Coaching</p>

<p className="rn-subtitle">Coaching Assignments with Evaluation Metrics</p>

Quality AI now supports creating coaching assignments and marking coaching interactions using evaluation metrics, agent attributes, or both. Supervisors can select coaching areas directly from evaluation forms or scorecards, enabling more targeted and granular coaching. Coaching areas now display their type (Metric or Attribute) across Coaching Assignments and Coaching Monitor, with support for manual metrics and metric-type visibility. Coaching progress tracking has also been enhanced to support supervisor-scored manual metrics and to enable comparison of Kore evaluation scores with supervisor scores. [Learn more→](/ai-for-service/quality-ai/coaching)

<p className="rn-title">API</p>

<p className="rn-subtitle">Conversation Details and Audit Log Enhancements</p>

The Disposition field is now displayed in the Conversation Details for Contact Center AI (CCAI) conversations, providing supervisors with additional context during audits. The disposition value is also available in the Interaction Details Report, Raw Data API, and Score Reporting API.

The ‘By Question’ audit logs now include the list of associated metrics for each LLM call, improving traceability and metric-level analysis. [Learn more→](/ai-for-service/apis/quality-ai/raw-data-api)

Dashboard widgets — including Heatmap and Agent Leaderboard — dynamically update using selected evaluation forms and mapped queues, enabling more accurate analysis of audits, fatal interactions, evaluation trends, and agent performance. Queue filters are displayed in context based on the selected forms to improve operational visibility and reporting precision. [Learn more→](/ai-for-service/quality-ai/analyze/adherence-heatmap)

Conversation Mining now supports filtering by Audit Name, enabling users to view all conversations from a specific audit in one place. ## v11.24.0 April 25, 2026

<Badge>Minor Release</Badge>

<p className="rn-title">Analyze</p>

<p className="rn-subtitle">AI Justification Enhancements</p>

AI justifications are now clearer and more context-aware, helping users better understand evaluation outcomes. For Not Applicable cases, the system explains when no trigger is detected. For Not Adhered cases, timestamps are shown only for violation scenarios where a specific interaction causes the issue (for example, when an agent uses rude language and violates professionalism). [Learn more→](/ai-for-service/quality-ai/analyze/ai-assisted-manual-audit#ai-justification)

<p className="rn-subtitle">Metric-Level Insights in Agent Dashboard</p>

Metric-level insights now include a toggle to switch between Attribute View (default) and Metric View. Attribute View shows top and bottom attributes with drill-down metric details, while Metric View highlights the top five metrics by adherence with associated attributes for context. This improves visibility, analysis, and decision-making in coaching. [Learn more→](/ai-for-service/quality-ai/analyze/supervisor-view-agent-specific-dashboard#coaching-insights)

<p className="rn-title">Configure</p>

<p className="rn-subtitle">Custom Metadata Mapping from AI Agent to Agent Platform</p>

AI Agent metrics now send custom metadata to the Agentic App via Quality AI. Users can configure additional fields, in addition to the default conversation ID, to include in the execute API payload. A new setup option lets users map custom field registry values to API headers, enabling the structured transfer of conversation-specific data for downstream use. [Learn more→](/ai-for-service/quality-ai/configure/evaluation-criteria/metrics-measurement-types/by-ai-agent)

<p className="rn-title">Coach</p>

<p className="rn-subtitle">Group Coaching Assignments</p>

QA Managers can now create group coaching assignments to address common performance gaps across multiple agents in one workflow. Shared coaching details are defined once, and interactions are assigned in bulk, while each agent receives an individual assignment. The Coaching Monitor provides a group-level view to track progress and the impact of coaching across agents. [Learn more→](/ai-for-service/quality-ai/coaching)

## v11.22.1 March 14, 2026

<Badge>Patch Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Role Management</p>

<p className="rn-subtitle">Update of Quality AI Permissions for Default Roles</p>

App Developers and App Testers can now access Quality AI through their default roles, without needing custom roles. This update revises default role permissions to give developers and testers appropriate access while maintaining the right level of control. [Learn more→](/ai-for-service/user-management/users-and-role#parent-and-child-permissions)

<p className="rn-title">Configure</p>

<p className="rn-subtitle">Manual Evaluation Metric</p>

A new Manual Evaluation metric type is now available for QA-only assessment of complex and nuanced scenarios. This metric is supported only in points-based evaluation forms and is excluded from AutoQA, Agent Attributes, and Agent Scorecards. Manual metrics are clearly labeled in reports and APIs, and unaudited conversations show no AutoQA response for these metrics.

<p className="rn-subtitle">Dynamic By Question (Speaker-Based Adherence)</p>

The Dynamic By Question metric now supports speaker-based answer adherence. Admins can configure the answer detection speaker — Agent or Customer — based on trigger rules. When the trigger speaker is an Agent, an optional scoring setting enables sub-weightages and partial scoring for both trigger and answer adherence, and auditors can manually evaluate both in the Audit Screen. Conversation Mining now includes a Not Applicable filter for Dynamic metrics, and reporting and heatmap logic treat trigger absence as Not Adhered when the scoring option is enabled.

## v11.22.0 February 28, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Configure</p>

<p className="rn-subtitle">Configurable Crosstalk Evaluation for By Speech Metrics</p>

The Crosstalk metric now detects simultaneous speech between the agent and customer, including customer interruptions. The Dynamic By Question metric supports speaker selection and sub-weight assignment for agent-triggered adherence, and answer detection can now be extended beyond the agent-enabling use cases such as customer confirmation and verification.

<p className="rn-subtitle">Points-Based Scoring for Complex Evaluation Forms</p>

Evaluation forms can now use points-based scoring, making it easier to build and manage complex forms with more than 20 metrics. QAs can assign weights by points rather than percentages, and all points-based forms include audit tracking for score changes and a full record of updates.

<p className="rn-subtitle">GenAI Logs Enhancement in Audit Screen</p>

The Audit Screen now displays detailed GenAI call logs at the conversation level for easier debugging. Logs are organized by GenAI feature in expandable dropdowns that show only enabled features, and can be filtered by Success or Failure status. Each log entry includes date and time, GenAI feature name, language, model name, integration type, prompt name, token usage, response duration, and full request and response payloads.

## v11.21.0 January 17, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Analytics</p>

<p className="rn-subtitle">Evaluation Form Summary Report Enhancements</p>

The Evaluation Form Summary report now includes a Total Interactions column to show the overall interaction count. The Total Applicable Interactions column excludes inapplicable interactions for dynamic-by-question metrics where the trigger was absent. These enhancements improve calculation accuracy and ensure that totals and percentages align with Heatmap data.

<p className="rn-title">Analyze</p>

<p className="rn-subtitle">Audit Allocation Enhancements</p>

Audit Allocation management uses a dedicated “Allocations” menu and a “My Allocations” tab. QA managers can track auditor progress, create and edit custom allocations, assign interactions to agents by percentage or count, and reassign pending interactions to manage availability while maintaining consistent quality coverage.

<p className="rn-title">Configure</p>

<p className="rn-subtitle">Agent Queue Management in the Quality AI UI</p>

Users can assign agents to Agent AI and Quality AI Express queues directly in the Quality AI UI, eliminating the need for public APIs. This update supports platform-level users, provides visibility into queue IDs for API use, and keeps agent mappings entirely separated from Contact Center AI (CCAI) routing and configuration. 

<p className="rn-subtitle">SFTP Chat Script Timestamp Enhancements</p>

Quality AI Express now supports offset-based timestamps for chat script ingestion via Secure File Transfer Protocol (SFTP). With this update, users can configure the chat script timestamp format at the app level under Conversation Sources. When users select offset-based timestamps, chat script can include message-level offsets relative to the conversation timeline without start or end time validation during ingestion. The system uses start and end dates solely for reporting and filtering. This change applies only to chat conversation ingestion and doesn't affect voice conversation ingestion.
