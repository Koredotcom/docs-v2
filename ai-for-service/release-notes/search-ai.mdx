This document provides information about the latest feature updates and enhancements introduced in **Search AI** of AI for Service (XO) v11.x releases. For previous updates, see release notes of [2025](/ai-for-service/release-notes/search-ai-2025) and [2024](/ai-for-service/release-notes/search-ai-2024).

## v11.28.0 August 29, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Enhanced Crawl Failure Detection and Reporting</p>

Crawl failure detection now surfaces the actual causes of crawl and URL validation failures, such as HTTP 403 responses, sitemap fetch and parsing issues, SSL errors, and filter exclusions, making crawl issues easier to identify and troubleshoot. [Learn more →](/ai-for-service/searchai/content-sources#websites)

<p className="rn-title">Allow Subdomains for Web Crawls</p>

The new Allow Subdomains option in Advanced Crawl Configurations now lets you include subdomains when crawling websites. When enabled, the crawler discovers and indexes content from subdomains of the configured base URL, helping build more complete knowledge bases while still excluding unrelated domains. [Learn more →](/ai-for-service/searchai/content-sources#email-notifications)

<p className="rn-title">Default Prompts for Claude Models</p>

Default prompt support for Anthropic Claude models is now available across GenAI features, letting customers use Claude models without additional prompt configuration. This brings feature parity with OpenAI and Azure OpenAI through built-in model registration, request handling, and default prompts. [Learn more →](/ai-for-service/generative-ai-tools/genai-features-searchai)

<p className="rn-title">Customizable Crawl Failure Email Subject</p>

Email subject lines for crawl failure notifications are now customizable, allowing administrators to include dynamic placeholders such as the application name, source name, and crawl status. This helps users quickly identify failed crawl jobs from their inbox. [Learn more →](/ai-for-service/searchai/content-sources)

<p className="rn-title">Public APIs for Web Source Management</p>

New public APIs let you create, update, and crawl web sources, allowing external applications to programmatically manage web source ingestion and automate crawl operations. [Learn more →](/ai-for-service/apis/searchai/webcrawl)

## v11.27.0 July 25, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Document Engagement Enhancements</p>

[Learn more →](/ai-for-service/apis/searchai/analytics-metadata)

## v11.26.1 July 11, 2026

<Badge>Patch Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Custom Metadata for Search Analytics</p>

The Advanced Search API now supports optional custom analytics metadata, enabling customers to segment and filter search analytics by business-specific dimensions such as channel, customer tier, or A/B test variant. Metadata is persisted alongside analytics records, available as filter dimensions across analytics dashboards, and included in analytics exports.

[Learn more →](/ai-for-service/apis/searchai/advance-search)

<p className="rn-title">Parallel Retrieval</p>

Multiple independent retrievals can now run for the same query, each targeting specific content using conditions and applying its own qualification thresholds, chunk limits, and token budget. Results from all retrievals are combined before answer generation, improving representation across diverse content sources and preventing dominant sources from occupying most top-result positions.

[Learn more →](/ai-for-service/searchai/retrieval-answer-configuration#parallel-retrieval-configuration)

<p className="rn-title">Failure-Only Email Notifications</p>

Administrators can now choose to receive email notifications only when jobs fail completely or partially, reducing noise and enabling teams to focus on actionable failures. This applies to Web Crawl Status, Connectors Status, and Training Status notifications. New applications default to failure-only notifications, while existing applications continue to receive notifications for all events.

[Learn more →](/ai-for-service/searchai/content-sources#email-notifications)

## v11.26.0 June 27, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Support for Search Results</p>

Search Results are now supported, using the same ingestion, indexing, retrieval, and ranking pipeline as answers for improved consistency and relevance. Results are displayed at the chunk level, enabling users to discover relevant content from multiple sections of a document. The feature also introduces configurable search result counts and filters for a more flexible search experience.

[Learn more →](/ai-for-service/searchai/retrieval-answer-configuration#search-results)

<p className="rn-title">Content Insights Dashboard</p>

The new Content Insights dashboard provides visibility into content retrieval and engagement across searches. Analyze retrieval trends by source and file type, track metrics such as documents retrieved, chunks retrieved/cited, and citation rank, and monitor document engagement via retrieval frequency, answer usage, citation clicks, and result clicks. Use filters to evaluate content performance and optimize retrieval quality.

[Learn more →](/ai-for-service/analytics/searchai/content-insights)

<p className="rn-title">GPT-5.x Model Support for Search AI Features</p>

The GPT-5.x model family is now supported across Search AI GenAI features. Users can select GPT-5.4, GPT-5.3 Instant, GPT-5.2, GPT-5.1, GPT-5.4 Mini, GPT-5.4 Nano, and GPT-5-mini (Azure OpenAI only) across all Search AI features except vector generation.

[Learn more →](/ai-for-service/generative-ai-tools/genai-features-searchai)

<p className="rn-title">Connector Enhancements</p>

<p className="rn-subtitle">Shopify Connector: OAuth 2.0 Support</p>

The Shopify connector now supports OAuth 2.0 Client Credentials authentication in addition to existing API access tokens, including token exchange, secure token storage, automatic token lifecycle management, and connection validation — while maintaining full backward compatibility with existing token-based integrations.

[Learn more →](/ai-for-service/searchai/connectors/shopify)

<p className="rn-subtitle">ServiceNow Connector Incremental Sync Support</p>

The ServiceNow connector now supports incremental synchronization. Instead of performing a full sync on every run, the connector fetches only records created or updated since the last successful sync, reducing API calls, sync duration, and processing overhead. Incremental sync is supported for Knowledge Articles, Incidents, Catalog Items, and Attachments.

[Learn more →](/ai-for-service/searchai/connectors/servicenow)

<p className="rn-subtitle">Salesforce Connector: Language Filtering for Knowledge Articles</p>

Added support for language-based filtering of Knowledge Articles via Advanced Filters. Users can now can ingest articles of specific languages while skipping the articles in other locales.

[Learn more →](/ai-for-service/searchai/connectors/salesforce)

## v11.25.1 June 13, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Connector Enhancements</p>

<p className="rn-subtitle">SharePoint Sensitivity Label Support</p>

Microsoft Purview sensitivity labels from SharePoint documents are now extracted and indexed, available as searchable and filterable metadata - improving governance, compliance visibility, and classification-aware enterprise search.

[Learn more →](/ai-for-service/searchai/connectors/sharepoint)

<p className="rn-subtitle">Jira Connector Sync Configuration Update</p>

The Jira connector now uses a single Started On field instead of separate Start Date and End Date fields. When provided, this field defines the earliest date from which Jira content is eligible for sync. Existing configurations are automatically migrated by retaining the configured start date.

[Learn more →](/ai-for-service/searchai/connectors/jira)

<p className="rn-subtitle">Attachment Support in Salesforce Connector</p>

Salesforce connector now supports indexing attachments, including PDFs, documents, spreadsheets, presentations, and images. Indexed attachments are searchable and can be used during response generation, improving knowledge coverage and overall enterprise search experience.

[Learn more →](/ai-for-service/searchai/connectors/salesforce)

<p className="rn-subtitle">Request-Level Retrieval Controls for Advanced Search API</p>

The Advanced Search API now supports optional `vectorWeights` and `retrievalStrategy` request parameters, enabling callers to customize retrieval behavior per request. Use `vectorWeights` to dynamically control the contribution of configured vectors for a specific query, and `retrievalStrategy` to override the application-level retrieval method by selecting either Vector or Hybrid retrieval. These overrides apply only to the current request and don't modify the application's saved configuration. Existing integrations remain fully backward-compatible.

[Learn more →](/ai-for-service/apis/searchai/advance-search)

## v11.23.1 April 11, 2026
<Badge>Patch Release</Badge> 

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-subtitle"> Click Analytics for Answers and Search Results </p>

Search AI now supports click analytics for citations and search result links, enabling tracking of user interactions across answers and search results. The system captures detailed click metadata, including source, document, and timestamp. This feature must be explicitly enabled through advanced configuration.

The Analytics Export API can be used to export all data. For aggregated insights, the Click Analytics API offers metrics such as time-series trends, average click statistics (clicks per search, chunks clicked, total searches with clicks), average click position, click position distribution, and top queries with no clicks.

[Learn more →](/ai-for-service/searchai/advance-config-and-dev-tools#enable-click-tracking)


<p className="rn-title"> Connector Enhancements</p>

Multiple connectors are updated to improve flexibility, content coverage, and access control.

- **Confluence Server**: Now supports multiple authentication profiles, allowing connections to multiple instances.
- **Slack**: Adds support for indexing Canvas (Quip) documents as file-based content using the markdown extractor.
- **GitHub**: Prevents unnecessary ACL sync triggers from webhook events, improving performance.
- **ServiceNow**: Improves runtime access control handling for more accurate permissions and synchronization.
- **All Connectors**: Introduces author-based filtering in search results, allowing users to refine results by content creator.

[Learn more →](/ai-for-service/searchai/content-sources#supported-connectors)

<p className="rn-title"> Configurable Token Encoding Model </p>

Search AI now supports configurable Token encoding models to improve token counting accuracy. New apps default to the GPT-4o (o200k_base) encoding model, while existing apps continue to use their current encoding. The model can be updated via advanced configuration.

[Learn more →](/ai-for-service/searchai/advance-config-and-dev-tools#encoding-model)

## v11.21.1 January 31, 2026

<Badge>Patch Release</Badge> 

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title"> Streaming Support for Search AI Answers </p>

Search AI now streams LLM-generated answers in real-time, displaying responses token-by-token as they're generated. This creates a more interactive experience and reduces wait times for longer answers. To use streaming, use the new default streaming prompt or add streaming options to your custom prompt. Note that streaming isn't available for API-based responses and is currently supported only for OpenAI and Azure OpenAI models. 



<p className="rn-title"> Webhook-Based Content Updates </p>

Search AI now supports webhooks for near real-time content synchronization with Confluence Server and ServiceNow. Webhooks capture create, update, and delete events directly from these systems, ensuring content stays up to date between scheduled syncs and improving indexing efficiency.
Note that this update doesn't support syncing user information for updated content and Confluence spaces.

## v11.21.0 January 17, 2026
<Badge>Minor Release</Badge> 

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title"> Export and Import Search AI Apps via Public APIs </p>

Search AI now supports app configuration export and import via public APIs, enabling easy migration and backup. Users can initiate an app-export job and track its progress using the job-status API, which returns the download URL for the exported JSON file upon completion. For imports, users can upload a config file and then programmatically trigger an app-import request. This capability allows admins to efficiently replicate configurations across apps. Supported configurations include chunk processing stages, advanced configurations, business rules, search results config, answer generation settings, and answer retrieval configuration.


<p className="rn-title"> Github Connector Enhancements: Support for Multiple Auth Profiles </p>

Search AI now supports ingesting and indexing content from multiple GitHub organizations using the same GitHub connector with multiple profiles. 

Key Features

* Add multiple GitHub authentication profiles, each representing a different organization.
* Filters and Manage Content configurations are maintained separately for each organization.
* Permissions, Content Types, and Sync Schedules are shared across all GitHub authentication profiles.
