## v11.28.0 August 29, 2026

<Badge> Minor Release </Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Widget Enhancements</p>

<p className="rn-subtitle">Manual NBA triggering with proactive mode control</p>

Agents can now select Generate NBA on the Assist tab to manually trigger an NBA suggestion when all of the following apply:

* Proactive Mode is off
* A new customer message arrives
* The previous NBA generation finishes

[Learn more→](/ai-for-service/agentai/agent-experience#assist-tab)

<p className="rn-subtitle">Call transfer reason for bot-to-human agent transfers</p>

For bot-to-human call transfers, the Landing Summary now includes a Call Transfer Reason section. [Learn more→](/ai-for-service/agentai/agent-experience#assist-tab)

<p className="rn-subtitle">Transcript visibility control for agents</p>

Admins can now control transcript visibility for transferred agents on the voice channel, using the Control Transcript Visibility between Agents setting in Widget Settings. When admins select Use Agents' Entry and Exit Events, the current agent sees transcripts of their own conversation and summaries of previous bot-user and agent-user conversations. [Learn more→](/ai-for-service/agentai/configuration/widget-settings)

<p className="rn-title">UI Enhancements</p>

<p className="rn-subtitle">Coaching nudge enhancements</p>

Admins can now configure how long a Nudge action stays visible and select the Acknowledge Pressed adherence option. [Learn more→](/ai-for-service/agentai/agent-experience/agent-realtime-coaching#nudge-agent)

<p className="rn-subtitle">Analytics Enhancements</p>

Agent AI Analytics includes the following updates:

* Feedback trend: The Feedback dashboard now shows feedback trends for the Suggestions Feedback and Overall Agent AI Widget Feedback sections. Select the Trend icon to see how agent feedback changes over the selected time period.
* Copilot events in Transcripts: The Transcript tab in the Agent AI Logs dashboard now shows Copilot Paused and Copilot Terminated events, indicating why NBA suggestions stopped during a conversation.
* Overview dashboard export: Admins can now export View All data from the AI Suggestions and Search Results sections to CSV.

[Learn more→](/ai-for-service/analytics/overview#contact-center-analytics)

<p className="rn-subtitle">Model and guardrails support for GenAI features</p>

GenAI features, including GenAI coaching triggers, dynamic playbooks, and summary generation, now support Azure GPT 5.1+ and Claude models (Opus 4.6, Sonnet 4.5, 4.6, and Haiku 4.5). You can configure custom guardrails to validate these features with the supported models. 

<p className="rn-title">Integration Enhancements</p>

<p className="rn-subtitle">WhatsApp chat transfer support for Landing Summary and NBA</p>

Agent AI integration with Salesforce Omni-Channel now supports WhatsApp chat transfers. For transfers to a live agent, Agent AI shows a summary of the pre-transfer conversation, identifies the customer's intent, and automatically provides relevant next-best-action (NBA) suggestions, without requiring an additional message.

<p className="rn-subtitle">Email support for Five9 integration</p>

Agent AI integration with Five9 now supports email interactions. The Agent AI widget automatically loads for agents handling email interactions, providing intent detection, sentiment analysis, suggested replies, playbook guidance, and real-time coaching.

<p className="rn-subtitle">Agent AI integration with Five9 Outgoing Calls</p>

Agent AI integration with Five9 now supports outbound calls. After the call ends, Agent AI generates a post-call summary. Learn more.

Agent AI now integrates with NICE Agent Desktop Chat. Agents can access real-time assistance, intent detection, sentiment analysis, and chat summaries within the NICE Agent Desktop. Agents can also send or copy Agent AI responses into the chat conversation. Learn more.

<p className="rn-title">API Enhancement</p>

<p className="rn-subtitle">Conversation Records API enhancements</p>

The Conversation Records API includes the following updates:

* Supports searching by **conversationIds** and filtering by the **widgetLoaded** flag.
* Returns landing, interim, and final summaries, each with a **generatedAt** timestamp.
* Exposes customer messages, AI suggestions, agent responses, conversation summaries, and feedback data in the response for custom analytics exports.
[Learn more→](/ai-for-service/apis/agent-ai/api-for-duration-based-conversation-records)

## v11.25.0 May 30, 2026

<Badge> Minor Release </Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">UI Enhancements</p>

<p className="rn-subtitle">Enhanced Agent AI Analytics</p>

Agent AI Analytics includes the following enhancements:

* Overview: A new View All button allows users to view, sort, and open conversation usage details.
* Feedback: A new View All button and search field enable filtering conversations by negative feedback keywords.
* Agent AI Logs: A new Widget Loaded column and a side-by-side view of AI suggestions and agent responses are added. 
[Learn more→](/ai-for-service/analytics/overview#contact-center-analytics)

<p className="rn-subtitle">Bulk Playbooks Creation from Knowledge Articles</p>

Admins and supervisors can now create multiple playbooks at once by uploading a Knowledge Article on the **Playbooks** page. Bulk playbooks default to the **Dynamic** type with **GenAI**(LLM-based) as the AI engine, eliminating manual data entry and streamlining the conversion of standard operating procedures into real-time agent guidance. [Learn more→](/ai-for-service/agentai/agent-experience/playbook#create-bulk-playbooks)

<p className="rn-title">Widget Enhancements</p>

<p className="rn-subtitle">Context-Aware NBA Suggestion on Agent Transfer</p>

The Agent AI widget now passes the landing summary as the first request to the Agentic app when an automation bot transfers an interaction to an agent, giving the first Next Best Action (NBA) suggestion full conversation context so agents can send it to the customer without editing. [Learn more→](/ai-for-service/agentai/configuration/linked-services#agentic-configurations)

<p className="rn-subtitle">Send and Copy Actions for All Search Result Types</p>

Agent AI now shows Send and Copy buttons for search results with no inline content — such as webpages, URLs, and files — allowing agents to send results directly to customers or copy them to edit before sharing.

<p className="rn-subtitle">Revisit Adhered Playbook Steps and Dynamic Playbooks</p>

Agents can now hover over an adhered Playbook step or reopen an adhered Dynamic Playbook to revisit the content without affecting adherence metrics. [Learn more→](/ai-for-service/agentai/agent-experience#assist-tab)

<p className="rn-title">Integration Enhancements</p>

<p className="rn-subtitle">Dedicated Salesforce Object for Tracking Metadata</p>

Agent AI now stores tracking metadata in a dedicated Salesforce custom object rather than in the Case object. The custom object stores metadata such as processed email IDs, social post IDs, processing timestamps, web case processing status, and Salesforce Case reference — keeping the integration compliant with Salesforce security policies without disrupting NBA generation or duplicate prevention.

<p className="rn-subtitle">PKCE Support for Genesys Cloud OAuth Authorization</p>

Agent AI integration with Genesys Cloud now supports OAuth Authorization Code Flow with Proof Key for Code Exchange (PKCE), replacing the deprecated Implicit Grant mechanism to meet Genesys Cloud's updated OAuth requirements for browser-based applications, improve security compliance, and prevent integration disruptions.

<p className="rn-subtitle">Five9 Voice Escalation Support</p>

Agent AI Voice integration with Five9 now supports voice call escalation from bot to agent queues. The integration transfers conversation context — including call summary, intent, and routing metadata — to help agents continue the interaction without asking customers to repeat information.

<p className="rn-subtitle">Real-Time Call Transcription Streaming via WebSocket</p>

Agent AI now supports WebSocket-based streaming of real-time call transcription to the Agent AI backend, delivering low-latency transcription data during active calls and enabling real-time assistance and analytics without webhook-related delays.

<p className="rn-title">Widget Enhancement</p>

<p className="rn-subtitle">Conversation Metadata for Troubleshooting and Root-Cause Analysis</p>

Agents can now copy conversation metadata from the Agent AI widget under Settings > Help & Support, helping support teams troubleshoot issues faster and perform root-cause analysis. [Learn more→](/ai-for-service/agentai/agent-experience#settings)

<p className="rn-title">UI Enhancements</p>

<p className="rn-subtitle">Bot-User Conversation Support in End-of-Conversation Summary</p>

Admins can now include bot-user conversations in the ‘End of Conversation’ Summary. Two summary types are available — **Full Summary** (bot-user and agent-user conversations) or **Agent-User Summary Only**. By default, only the agent-user conversation is included. The bot-user conversation isn't supported for Intermittent Summaries. [Learn more→](/ai-for-service/agentai/configuration/summary-settings)

<p className="rn-subtitle">Agent Coaching Analytics on the Dashboard</p>

The Agent AI dashboard now includes an Agent Coaching section with multi-level coaching metrics and rule performance insights to help supervisors monitor adoption and adherence. [Learn more→](/ai-for-service/analytics/contact-center/agentai-dashboard#agent-coaching)

<p className="rn-subtitle">Summary Settings</p>

A new Summary Settings sub-section is now available under Agent AI Configurations, centralizing summary preferences for Chat, Voice, and Email with dedicated settings for Landing Summary, Intermittent Summary, End-of-Conversation Summary, and Summary Generation Mechanism. [Learn more→](/ai-for-service/agentai/configuration/summary-settings)

<p className="rn-subtitle">GenAI Runtime Support for Playbooks</p>

Playbooks now support a GenAI runtime option that uses conversation history to improve trigger detection and step adherence, increasing accuracy for multi-action steps and multilingual conversations. Admins can select Deterministic or GenAI mode when creating a new playbook. [Learn more→](/ai-for-service/agentai/agent-experience/playbook#create-a-playbook)

Admins can also configure a context window under Widget Settings to define how many recent messages the system uses for evaluation (default is five). A warning appears when a stage has more than five steps, as additional steps can increase latency. [Learn more→](/ai-for-service/agentai/configuration/widget-settings#agent-ai-channel-specific-settings)

<p className="rn-subtitle">Custom Model Support for Real-Time Coaching</p>

Real-Time Coaching now supports custom LLM models through the Models Library. Admins can select a custom model for coaching rules and define GenAI prompts to deliver real-time coaching based on business needs. This improves flexibility and coaching accuracy with domain-specific models, aligns outputs with internal standards, and supports security and compliance requirements while reducing dependence on third-party APIs.

## v11.21.0 January 17, 2026

<Badge> Minor Release </Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Widget Enhancements</p>

<p className="rn-subtitle">Improved Copy and Send Behavior for Agentic Copilot Responses</p>

Agentic Copilot responses now use a delimiter **===AGENT_NOTES===**. When the copilot response received from Agent Platform contains this delimiter separating the customer-facing content and agent-specific information, only the customer-facing content above the delimiter is copied or sent when an agent clicks Copy or Send. Agent-specific information remains visible to agents only. This reduces manual edits and helps lower average handling time (AHT).

<p className="rn-subtitle">Agentic Copilot Streams Next Best Responses</p>

Agentic Copilot now streams suggestions incrementally during live conversations, rather than waiting for the full response to be generated. This reduces perceived latency and allows agents to respond faster. Admins can enable this feature by toggling Agentic Response Streaming under **Widget Settings** > **Agent AI Channel Specific Settings**.

<p className="rn-subtitle">Conversation Metadata Support for Agentic App</p>

Agent AI now passes selected conversation metadata—such as landing summaries, agent-customer chat history, intermittent summaries, and custom data—to the Agentic App. This preserves context during conversation transfer from automation to human agents, enabling Agentic Copilot to deliver relevant, context-aware responses. 

<p className="rn-subtitle">Playbook State Persistence on Widget Reloads and Transfers</p>

The system now preserves playbook checklist progress and step adherence during widget reloads and conversation transfers, ensuring agents resume exactly where they left off without losing workflow continuity.

<p className="rn-title">UI Enhancements</p>

<p className="rn-subtitle">Support for Multiple Search Apps Integration</p>

The Search AI integration in UX 11 now supports configuring multiple Search Apps across XO 10 and XO 11. Admins can use the inbuilt XO 11 Search App (AI Agent) or configure up to three Search Apps across XO 10 and XO 11.

<p className="rn-subtitle">Search Result Layout Option in Widget Theming</p>

The **Widget Theming** > **Layout Customization** section now includes the **Search Result Layout** subsection. Admins can select one of the following options: 

* Classic Search: Shows only the current search results.
* Conversational Search: Shows a history of previous questions and answers to reduce repetition and make it more contextual.  

<p className="rn-title">Integration Enhancements </p>

<p className="rn-subtitle">Salesforce Omnichannel Web Chat Pre-handoff Conversation Context in Agent AI</p>

Agent AI now automatically retrieves, stores, and accesses the complete pre-handoff conversation context when a Salesforce Einstein Bot transfers a Web Chat to a live agent. This includes the full bot conversation history and all pre-chat attributes stored in the Agent AI Bot Context (custom data), which are available in the Agent AI widget for use in dialog tasks and workflows. After handoff, Agent AI automatically detects customer intent using the Bot Platform. 

<p className="rn-subtitle">Proactive Cross-Channel Customer Summaries in Salesforce-Agent AI Integration</p>

Agent AI automatically analyzes and summarizes a customer’s recent interactions across all channels, including orders, returns, exchanges, chat, email, SMS, WhatsApp, phone calls, product registrations, and other activities available through Harman’s APIs. This summary helps agents quickly understand the customer context, anticipate call intent, and assist customers efficiently without navigating multiple CRM pages.
