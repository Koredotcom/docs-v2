## v11.28.0 August 29, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Console</p>

<p className="rn-subtitle">Revamped Conversation History With Omnichannel Summary</p>

The Conversation History panel in the Agent Console now presents Chat, Email, and Voice interactions in a unified, chronological view. Each conversation displays acceptance time, duration, channel, participating agents, bot involvement, and status codes. [Learn more→](/ai-for-service/contact-center/agent-console#history-widget)

<p className="rn-subtitle">Conversation Position Preserved When Switching Between Concurrent Chats</p>

Conversations now open directly - at the last-read message when unread messages exist, or at the latest message when fully read - with no visible scrolling. 

<p className="rn-subtitle">Network Instability Warning for One-way Audio</p>

A warning now appears in the Console when audio packets sent or received drop below the threshold indicating one-way audio, alerting agents to check their network or reconnect the call. The warning dismisses when two-way audio is restored, or can be manually closed by the agent. 

<p className="rn-title">Configuration</p>

<p className="rn-subtitle">Separate Permissions for Configuration and Analytics Wallboards</p>

Wallboard access is now controlled by two independent permissions - **Contact Center Wallboards in Configuration** and **Wallboards in Analytics** - letting administrators grant access to each wallboard area separately. The Analytics wallboard permission is enabled by default for all built-in and custom roles.  [Learn more→](/ai-for-service/user-management/users-and-role#agent-and-supervisor-experience-agent-desktop-console)

<p className="rn-subtitle">Manual Reordering of Response Template Groups and Templates</p>

Response Template Groups and the templates within each group can now be reordered using drag-and-drop. The configured order persists across sessions and is reflected in the Agent Console, letting organizations prioritize frequently used groups and templates for faster agent access. [Learn more→](/ai-for-service/contact-center/configurations/operational-configurations#reorder-response-template-groups)

<p className="rn-subtitle">Agent Permissions for Sending Forms and Links</p>

Two new permissions - **Agent Forms** and **Links** - are now available under Agent Capabilities, consistent with the existing Attachments and Emojis controls. When disabled, the respective send options are hidden in the Agent Console and blocked at the backend. [Learn more→](/ai-for-service/user-management/users-and-role#chat-and-voice)

<p className="rn-subtitle">Multilingual Message Localization and Translation Framework</p>

Administrator-configured locale messages now take precedence over machine translation at runtime, with the bot's default language as the universal fallback. Translated messages are cached for 15 days to reduce repeated translation calls, and incomplete multilingual configurations are blocked from saving. Localized message behavior is governed by the account's translation setting in Agent Settings. [Learn more→](/ai-for-service/contact-center/configurations/settings/multilingual-message-localization-and-translation)

<p className="rn-title">API</p>

<p className="rn-subtitle">A New Field Added to Call Details API v2 Response</p>

A new `nonRespondingAgents` object of the Call Details API v2 returns the exact date and time an agent was unlinked from a conversation - whether due to rejection, acceptance timeout, or the caller leaving before the agent responded. The field is populated for historical conversations where the data is available. [Learn more→](/ai-for-service/apis/contact-center/get-all-conversations-data-call-details-v2)

## v11.27.1 August 08, 2026

<Badge> Patch Release </Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Channels</p>

<p className="rn-subtitle">Artemis Channel Support in Interactions Tab and Conversations Dashboard</p>

Artemis sessions now appear as a dedicated channel in the Conversations dashboard and Interactions tab, with inbound and outbound messages routed through the Artemis channel adapter. [Learn more→](/agent-platform/integrations/smartassist#contact-center-app-configuration)

<p className="rn-title">Configuration</p>

<p className="rn-subtitle">Configurable IP Address Masking in Conversation Transcripts</p>

The new **Mask IP Address in Transcripts** option lets you mask IP addresses across conversation transcripts on all channels. The option is added under Agent Settings → System Settings → Obscure Customer Info in Analytics - Interactions. [Learn more→](/ai-for-service/contact-center/configurations/settings/configuration-settings#obscure-customer-info-in-analytics-interactions)

<p className="rn-subtitle">Separate Prompts for Arrival and Closure Summaries</p>

Administrators can now configure independent prompts for Arrival Summary and Closure Summary. Both prompts support runtime resolution of system and custom context variables before the LLM is invoked. On upgrade, existing prompt content is copied into both sections. [Learn more→](/ai-for-service/contact-center/configurations/settings/configuration-settings#enable-llm-based-summarization)

<p className="rn-title">Monitor</p>

<p className="rn-subtitle">Participant-Based Filtering for Workbin Interactions</p>

Supervisors can now filter Workbin interactions by the last handling agent, using the existing Participant filter. The Participant column also identifies the last handling agent for Workbin interactions. [Learn more→](/ai-for-service/contact-center/supervisor#interactions)

<p className="rn-title">API</p>

<p className="rn-subtitle">WFM Contact Volume Skill Breakdown and New Agent Performance API</p>

The Contact Volume API now accepts an `includeSkillBreakdown` parameter that returns per-skill metrics alongside existing queue-level totals for each interval, enabling skill-specific staffing models. A new Agent Performance API returns historical contact handling metrics per agent, per queue, and per interval. [Learn more→](/ai-for-service/apis/contact-center/agent-performance)

## v11.27.0 July 25, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Console</p>

<p className="rn-subtitle">Dark Mode for the Agent Console</p>

Agents can now switch the Agent Console to dark mode from the profile drop-down menu. The preference is persistent across logins. [Learn more→](/ai-for-service/contact-center/agent-console#dark-mode)

<p className="rn-subtitle">Workbin Duration Column in the Agent Workbin</p>

A new Workbin Duration column in the Agent Workbin displays the elapsed time since a conversation was last parked. The timer updates every minute, resets each time a conversation is re-parked, and agents can sort by this column to view the oldest conversations. [Learn more→](/ai-for-service/contact-center/agent-console#personal-workbin-view)

<p className="rn-title">Configuration</p>

<p className="rn-subtitle">Independent Translation Controls for AI Summaries and Automation Transcripts</p>

Administrators can now independently turn translation on or off for Arrival Summary, Disposition Summary, and Automation Transcript. When turned on, content is displayed in its original language. [Learn more→](/ai-for-service/contact-center/configurations/settings/configuration-settings#translation-configurations)

<p className="rn-subtitle">Permission to Override Queue Transfer Restrictions</p>

A new Override Queue Transfer Restrictions permission lets supervisors bypass queue-level transfer restrictions when reassigning conversations from the Monitor tab. [Learn more→](/ai-for-service/user-management/users-and-role#agent-and-supervisor-experience-agent-desktop-console)

<p className="rn-subtitle">Custom Additional Fields for Agent Profile</p>

Administrators and App Owners can now create custom key-value fields in Agent Profile using the UI or existing Agent APIs, and these fields display in all agent profiles. Custom fields propagate through agent context and are included in analytics exports and reports. [Learn more→](/ai-for-service/user-management/users-and-role#manage-profile-fields)

<p className="rn-subtitle">ACW Releases Correctly After a Blind Transfer</p>

After an external (blind) transfer, the After Call Work (ACW) state was not releasing and the interaction remained open in Monitor tab, leaving the agent unable to receive new calls. The conversation now closes correctly once the transferred call ends, and the agent transitions to Available according to the configured Timed Slot Release settings.

## v11.26.1 July 11, 2026

<Badge>Patch Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Configuration</p>

<p className="rn-subtitle">Fallback Messages for No Agent Available and Out-of-Office Flows</p>

Admins can now configure channel-specific fallback messages under Conditional Flows for No Agent Available and Out-of-Office Hours scenarios. These messages are displayed when a conversation encounters either scenario and no conditional flow is configured to handle it, ensuring a consistent response regardless of routing context. <p className="rn-subtitle">Configurable Conversation Timer Metric</p>

Admins can now select which timer metric is displayed in the Agent Console, choosing from Total Chat Handling Time (default), Agent Handling Time, Agent Last Message Time, or Interaction Handling Time. The setting applies to all agents, and existing deployments are unaffected. [Learn more→](/ai-for-service/contact-center/supervisor#conversation-timer-metric)

<p className="rn-title">Analytics</p>

<p className="rn-subtitle">View Last Handling Agent for Workbin Conversations</p>

Supervisors can now see the last agent who handled a conversation before it was moved to the Workbin, visible in both the Queues and Interactions views in the Monitor tab. [Learn more→](/ai-for-service/contact-center/supervisor#queues)

<p className="rn-subtitle">Agent Response Usage Report</p>

A new daily usage report tracks how many times agents used each standard response and secure form over a selected date range of up to 92 days or the last quarter, exported as CSV with a configurable date format. [Learn more→](/ai-for-service/analytics/contact-center/reports/agent-response-usage-report)

<p className="rn-title">API</p>

<p className="rn-subtitle">Translation and Snooze Fields Added to Call Details API v2</p>

Two new fields are now available in every `AgentSegment` object in the Call Details v2 API: 

* `chosenTranslation` indicates whether the agent used translation during their segment. 
* `snoozeinfo` returns an array of snooze periods with start and end timestamps, available when requested using `selectedFields`. [Learn more→](/ai-for-service/apis/contact-center/get-all-conversations-data-call-details-v2)

## v11.26.0 June 27, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Console</p>

<p className="rn-subtitle">Copy Option for AI-generated Conversation Summaries</p>

Agents can now copy the auto-generated end-of-conversation summary to the clipboard with a single click across Chat, Voice, and Email. A notification confirms whether the copy action succeeded or failed. [Learn more→](/ai-for-service/contact-center/agent-console#dispositions)


<p className="rn-subtitle">Template-level Shortcuts for Agent Response Templates</p>

Agents can now invoke individual response templates directly using a nested shortcut format, such as `/billing/refundpolicy`, instead of navigating a group shortcut and manually selecting from a list. [Learn more→](/ai-for-service/contact-center/configurations/operational-configurations#response-templates)


<p className="rn-subtitle">Timeline Events for Chat Transfers in the Console and Transcripts</p>

Chat transfers now appear as system-generated timeline events in the conversation, showing the transferring agent, timestamp, and transfer target-whether a queue or another agent. These events are visible to receiving agents, in supervisor monitoring views, and in conversation transcripts. 

<p className="rn-title">Configuration</p>


<p className="rn-subtitle">Network Disruption Notification Delay</p>

Administrators can now configure a delay of 3 seconds to 1 minute before agents see a `Customer got disconnected` notification, suppressing it if the customer reconnects within that window. This reduces notification noise from short-lived connectivity interruptions, such as SDK reloads. [Learn more→](/ai-for-service/contact-center/supervisor#conversation-status-control)

<p className="rn-subtitle">Video Call Recording Consent Prompt</p>

A new `Display Recording Consent Prompt` setting under Video Call Recording Control lets administrators disable the Web SDK's built-in recording consent prompt, useful when consent is already collected earlier in a customized video call flow. The setting is enabled by default for new and existing configurations. [Learn more→](/ai-for-service/app-settings/advanced-settings/system-settings#video-call-recording-control)


<p className="rn-subtitle">Queue-Based and Combined Skill-Queue Conditions for Waiting Experience</p>

Waiting Experience configurations can now be triggered by queue or by a combination of skill and queue using AND logic, in addition to the existing skill-only condition. Existing skill-only configurations continue to work unchanged. [Learn more→](/ai-for-service/contact-center/flows-and-routing/conditional-and-waiting-flows#waiting-flows)

<p className="rn-title">Analytics</p>

<p className="rn-subtitle">Center Wide Abandoned Wallboard-Manual Scrolling and Updated Top-line Widgets</p>

A new `Allow manual scrolling` option in the Center Wide Abandoned Wallboard configuration disables auto-scroll for the Queue-Skill table, allowing users to scroll and sort manually. [Learn more→](/ai-for-service/contact-center/configurations/operational-configurations#center-wide-abandoned)

The Agents' top-line widget now displays available and system-busy agents relative to the total number of active agents, and the Longest Wait widget has been replaced with Capacity Utilized, which shows active conversations relative to available agent slots. [Learn more→](/ai-for-service/analytics/contact-center/wallboards#top-section-widgets-3)

<p className="rn-subtitle">Download Plain Text Transcript from the Conversations Dashboard</p>

A new `Download Plain Text Transcript` option is now available in the Conversations Dashboard, alongside the existing Download Transcript option. An Export Plain Text Transcripts bulk action is also available, supporting up to 25 conversations at a time. [Learn more→](/ai-for-service/analytics/overview/conversations#export-conversation-data-and-transcripts)

<p className="rn-title">API</p>

<p className="rn-subtitle">New callContactAt API for Scheduling Agentless Campaign Callbacks </p>

A new `callContactAt` API lets one or more contacts be scheduled for a callback at a specified date and time within an Agentless Campaign, supporting scenarios where a contact requests to be called back later. [Learn more→](/ai-for-service/apis/contact-center/create-call-back-schedule-v2)

## v11.25.0 May 30, 2026
    
<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Console</p>

<p className="rn-subtitle">Conversation Tray Notifications and Status Timers</p>

The conversation tray now displays a distinct icon and colored background for each conversation lifecycle status — Ongoing, Idle, ACW, Snoozed, and Overdue — enabling supervisors to identify urgency and state at a glance. Overdue conversations display a dynamic elapsed-time timer based on the customer's last message. A notification on the tray indicates unread customer or system activity and persists until acknowledged. [Learn more→](/ai-for-service/contact-center/agent-console#conversation-statuses)

<p className="rn-subtitle">Personal Workbin View</p>

Agents can now access a dedicated Personal Workbin view from the Console, showing all open conversations parked in their Workbin — without occupying active interaction slots or accumulating handling time. Agents can search and browse the list, open a conversation's detail view, and reassign it to themselves when ready to resume. This feature is controlled by the Enable Personal Workbin View setting. [Learn more→](/ai-for-service/contact-center/agent-console#personal-workbin-view)

<p className="rn-subtitle">Agent AI Widget During Video Calls</p>

The Agent AI widget now stays enabled when a chat conversation escalates to a video call within the same interaction, preserving session context, chat transcript, recommendations, and knowledge suggestions throughout the video session. Returning to chat after the video call doesn't reset the assist state. [Learn more→](/ai-for-service/contact-center/agent-console#agent-ai-widget-during-video-calls)

<p className="rn-title">Configuration</p>

<p className="rn-subtitle">Queue-specific Sound Notifications</p>

Admins can now assign distinct incoming interaction sounds to individual queues for Voice, Chat, and Email channels. Queues without a custom assignment continue to use the default sound. Sounds can be previewed before saving, and mappings can be modified or removed. [Learn more→](/ai-for-service/contact-center/agent-console#notifications)

<p className="rn-subtitle">Standalone Voicemail Trigger in Waiting Experience</p>

Admins can now enable a Trigger Voicemail Immediately option under Forced Voicemail in the Waiting Experience configuration. When enabled, callers are routed directly to voicemail as soon as the waiting experience is triggered — bypassing the voice queue entirely. The voicemail request is created and delivered to agents with no live interaction assigned. [Learn more→](/ai-for-service/contact-center/flows-and-routing/conditional-and-waiting-flows#call-experience-tab)

<p className="rn-subtitle">App-level Language Selection and Conditional Translation</p>

Admins can now configure On-Connect and Waiting messages across all bot languages defined at the app level. Messages are automatically matched and delivered to users based on their language, eliminating the need for manual translation. The translation option is hidden when the customer's language already matches the agent's configured languages. [Learn more→](/ai-for-service/contact-center/configurations/settings/configuration-settings#translation-configurations)

<p className="rn-subtitle">Optional Conversation Status Control Messages for the Email Channel</p>

Admins can now individually enable or disable specific Conversation Status Control messages for the Email channel — including agent inactivity reminders, customer idle notifications, auto-expiry reminders, and on-close messages — under Conversation Status Control → Email Channel. [Learn more→](/ai-for-service/contact-center/supervisor#conversation-status-control)

<p className="rn-subtitle">Callback Number Confirmation in IVR Queue</p>

Admins can now enable a Callback Number Confirmation flag under the Callback option in Waiting Experience. When enabled, callers are prompted via IVR to confirm their callback number — or enter an alternative one — before being placed in the callback queue, with support for both DTMF and voice input. A default Callback Number Confirmation dialog flow is automatically installed in all existing and new apps and is fully editable. [Learn more→](/ai-for-service/contact-center/flows-and-routing/conditional-and-waiting-flows#call-experience-tab)

<p className="rn-title">Analytics</p>

<p className="rn-subtitle">Separate Email Channel Metrics in Queue Performance</p>

The Queue Performance section now displays Email as a dedicated channel alongside Chat and Call, with metrics for Average Response Time, Average Resolution Time, and Average ACW Time. Email interactions are no longer grouped under Chat, ensuring accurate, channel-specific insights for each queue. [Learn more→](/ai-for-service/contact-center/supervisor#queues)

<p className="rn-subtitle">Center Wide Abandoned Wallboard: Queue-skill Accuracy and Blank Skill Visibility</p>

The Queue-Skills table in the Center-Wide Abandoned Wallboard now resolves skill associations at the point a conversation enters each queue, rather than using post-call skill history, ensuring each queue row reflects the correct skill context. Conversations linked to a queue but not associated with any skill are shown as a dedicated row with a blank skill value; rows with no data aren't displayed. [Learn more→](/ai-for-service/analytics/contact-center/wallboards#center-wide-abandoned)

<p className="rn-subtitle">New report: Agent Group Membership</p>

A new Agent Group Membership report tracks when agents were added to or removed from groups over a selected date range of up to 92 days (or the last full quarter). The report is exported as CSV and includes agent name, custom ID, group name, and timestamped added and removed dates, with a configurable date format. [Learn more→](/ai-for-service/analytics/contact-center/reports/agent-group-membership-report)

<p className="rn-subtitle">Interaction Details by Segment Report Enhancements</p>

The Interaction Details by Segment report now supports in-progress conversations via an opt-in configuration checkbox, showing each conversation's current state and SmartStatus in real time. Five new columns have been added — Disposition, First Response Time, Messages Sent, Email Subject, and Session and User Tags — along with a configurable date format. [Learn more→](/ai-for-service/analytics/contact-center/reports/interaction-details-by-segment)

<p className="rn-subtitle">Switch Conversations in the Transcript Slider</p>

Supervisors can now select a different conversation while the transcript slider is open; the slider automatically refreshes with the transcript of the newly selected conversation without requiring a manual close and reopen. [Learn more→](/ai-for-service/contact-center/supervisor#queues)

<p className="rn-title">Campaigns</p>

<p className="rn-subtitle">QuickChat widget for Proactive Web Campaigns</p>

A new QuickChat widget is now available for Proactive Web Campaigns. The chat box opens automatically when campaign rules are met — no visitor click required — and immediately begins the configured flow—dashboard analytics count only conversations where the visitor has sent at least one message. [Learn more→](/ai-for-service/contact-center/campaigns#create-a-proactive-web-campaign)

<p className="rn-subtitle">Campaign-linked Disposition Sets</p>

Disposition sets can now be designated as campaign-linked at creation, restricting them to single-select and ensuring only one such set is associated with each queue. Agents handling campaign calls in ACW see only the campaign-linked disposition set. [Learn more→](/ai-for-service/contact-center/supervisor#add-a-disposition-set)

## v11.24.0 April 25, 2026

<Badge>Minor Release</Badge>

This update includes enhancements and bug fixes. The key enhancements included in this release are summarized below.

<p className="rn-title">Console</p>

<p className="rn-subtitle">Agent Screen Recording for Voice Calls</p>

Agent screen recording for voice calls is now available, with an app-level toggle and a Windows desktop capture application that records full desktop activity and streams it securely. Recording starts on call acceptance, continues through hold, transfer, and ACW, and stops after ACW submission. 
Recordings are stored securely, available on the Interactions page for download with role-based access, and adhere to existing retention policies. Validation, error handling, and compliance controls ensure reliable and secure operation. [Learn more→](/ai-for-service/contact-center/agent-console#screen-recording-for-voice-calls)

<p className="rn-subtitle">Warm Transfer for Live Chat</p>

The new Consult option allows agents to initiate an internal agent-to-agent chat, share context, and collaborate without displaying messages to the customer. Agents can switch between customer and consult chats, merge into a conference chat, and complete a warm transfer with full context. [Learn more→](/ai-for-service/contact-center/agent-console#warm-transfer-chat)

<p className="rn-subtitle">Real-Time Status and ACW Timers</p>

A real-time timer in the Agent Status dropdown shows elapsed time for the current status session and resets on every status change, without affecting cumulative reporting. Each conversation in ACW shows its own timer, starting at ACW entry, running independently, and stopping on closure. [Learn more→](/ai-for-service/contact-center/agent-console#real-time-status-timer)

<p className="rn-subtitle">Anchor Tag in User Info</p>

User Info now supports a predefined anchor tag syntax that renders clickable links in the Console. Clicking a link opens the URL in a new tab or window. [Learn more→](/ai-for-service/contact-center/agent-console#anchor-tags)

<p className="rn-subtitle">Agent-Controlled Skill and Queue Subscription</p>

Agents can now opt in or out of assigned skills and queues from the Profile section when permitted, with deselected items remaining visible but excluded from routing. A Revert to Default option restores original assignments. Supervisors retain full visibility of assignments and agent-level changes, with the ability to override. [Learn more→](/ai-for-service/contact-center/agent-console#agent-profile)

<p className="rn-title">Configuration</p>

<p className="rn-subtitle">Queue and Agent Level Blended Agent Configuration</p>

Blended agent configuration is now supported at the queue and agent levels, in addition to the app-level setting. Agent-level override takes the highest priority, followed by queue-level, then app-level. Routing and system busy logic use the effective blending state, ensuring optimized workload distribution while retaining existing channel selection behavior. [Learn more→](/ai-for-service/contact-center/supervisor#blended-agents)

<p className="rn-subtitle">Dashboard: Queue-Based Access Control for Supervisors</p>

A new Queues option under Dashboard Content permissions now restricts dashboard visibility to a supervisor's assigned queues and the agents serving those queues. This applies across dashboards, wallboards, and interactions, including filters, summaries, and searches. [Learn more→](/ai-for-service/user-management/users-and-role)

<p className="rn-subtitle">Team Leader Permission Modification</p>

A new Edit User Information child permission under User Management controls who can modify user profiles. Users without this permission can view users and perform operational tasks-routing, queues, and monitoring-but can't edit agent or user details, with profile pages rendered in read-only mode. [Learn more→](/ai-for-service/user-management/users-and-role#user-management)

<p className="rn-subtitle">Dedicated Waiting Experience for Email Channel</p>

A separate Email Waiting Experience is now available under Flows, supporting Initial Email, Agent Transfer messages, and configurable periodic messages with hours/minutes and loop/once behavior. [Learn more→](/ai-for-service/contact-center/flows-and-routing/conditional-and-waiting-flows#email-experience-tab)

<p className="rn-title">Analytics</p>

<p className="rn-subtitle">Update Agent Status Label: `Deleted` → `Inactive`</p>

The `Deleted` label is replaced with `Inactive` where Agent Name appears across reports, dashboards (Queues, Agents, Interactions), wallboards, filters, and configuration screens now return `Inactive` instead of `Deleted,` ensuring consistency across UI and data outputs.

<p className="rn-title">Campaigns</p>

<p className="rn-subtitle">Contacts: List View</p>

A new list view is now available for contacts from CSV, Passive API, and Subset-based sources. The view supports pagination, column selection, exact-match search, priority filtering, sorting, and CSV export. Key contact fields are displayed in read-only format. Administrators configure wait times and rerouting rules, while supervisors can manually reassign parked conversations.

<p className="rn-subtitle">Proactive Connection Monitoring and Agent Alerts</p>

<p className="rn-subtitle">CSAT and Feedback Status Visibility in Interactions</p>

The Interactions tab now displays a clear visual indicator for each conversation’s survey status, indicating whether a CSAT or Feedback survey was submitted, triggered but not submitted, or not triggered. <p className="rn-subtitle">Unified Feedback Support (CSAT, NPS, Like/Dislike)</p>

The Interactions page provides a unified Feedback status and consistently tracks survey triggers and submissions across all channels.

Agents can now send outbound emails in any status—Available, Busy, Away, or custom—when they have the required permissions. A system setting controls this capability and is disabled by default. Out-of-hours handling now supports a Route to Queue option that transfers conversations directly to a selected target queue when enabled, bypassing the trigger flow.
