Retrieves the details of a specific coaching rule, including its triggers, actions, configuration, status, and metadata.


| **METHOD**           | **GET**                                                                                                                              |
|:--------------|:----------------------------------------------------------------------------------------------------------------------------------|
| Endpoint      | `https://{{host}}/agentai/api/v1/public/{{streamid}}/acrules/{{ruleId}}`                                                                     |
| Content Type  | `application/json`                                                                                                                |
| Authorization | `auth: {{JWT}}` — See [How to generate the JWT Token](/ai-for-service/apis/automation/api-introduction#generating-the-jwt-token). |
                                                                                            

## Header Parameters

| Header | Type | Required | Description |
|----------|----------|----------|----------|
| `auth` | String | Yes | JWT token used for authentication. |
| `accountid` | String | Yes | Unique account identifier. |


## Path Parameters

| Parameter | Description | Type |
|:-----------|:-------------|:------|
| `host` | Environment URL. For example, `https://platform.kore.ai/` | String, required |
| `streamId` | `botId` or `streamId`. Retrieve this from the App Settings page. | string, required |
| `ruleId` | Unique identifier of the coaching rule to retrieve. | String, required |

## Sample Request

```bash 
curl --location --max-time 15 'https://{{host}}/agentai/api/v1/public/{{streamid}}/acrules/{{ruleId}}' \
--header 'auth: {{JWT_TOKEN}}' \
--header 'accountid: {{accountId}}' \
--header 'Content-Type: application/json' \
--data ''
```

## Response Parameters

| Parameter     | Type | Description |
|---------------|------|-------------|
| `_id`          | String | Unique identifier of the coaching rule. |
| `name`        | String | Name of the coaching rule. |
| `description` | String | Description of the coaching rule. |
| `tags`        | Array | Tags associated with the coaching rule. |
| `channels`    | Array | Channels where the coaching rule applies. |
| `isActive`    | Boolean | Indicates whether the coaching rule is active. |
| `botId`       | String | Unique identifier of the Agent AI stream. |
| `accountId`   | String | Unique account identifier. |
| `createdOn`   | String | Date and time when the coaching rule was created in ISO 8601 format. |
| `triggers`    | Array | Configured trigger definitions. |
| `actions`     | Array | Configured action definitions. |
| `assignees`   | Array | Users assigned to the coaching rule. |
| `status`      | String | Current status of the coaching rule. |
| `state`       | String | Current configuration state of the coaching rule. |
| `default`     | Boolean | Indicates whether the coaching rule is a system-defined rule. |
| `deletable`   | Boolean | Indicates whether the coaching rule can be deleted. |
| `refId`       | String | Reference identifier of the coaching rule. |
| `lModOn`      | String | Date and time when the coaching rule was last modified. |
| `__v`      | Number | Internal version number of the coaching rule. |
| `parentId` | String | Identifier of the parent coaching rule from which the rule was derived. |
| `actions.id`  | String | Unique identifier of the action. |
|  `_id` | String | Unique identifier of the trigger. |
|`type` | String | Trigger type. Supported values include `utterance` and `genai`. |
| `by` | String | Participant whose interaction is evaluated by the trigger. |
| `when` | Object | Additional trigger conditions. |
| `frequency` | Object | Frequency settings for trigger evaluation. |
| `operator` | String | Logical operator used to evaluate conditions. |
| `conditions` | Object | Conditions associated with the trigger. |
| `default` | Boolean | Indicates whether the trigger is system-defined. |
| `triggerDesc` | String | Natural language description of the GenAI trigger. Available only for `genai` triggers. |
|  `utteranceCount` | Number | Number of utterances after which the trigger is evaluated. |
| `nOccurrences` | Number | Number of occurrences required to activate the trigger. |
| `duration` | String | Time period during which occurrences are evaluated. |
| `_id` | String | Unique identifier of the action. |
| `type` | String | Action type. Examples include `nudge` and `email_manager`. |
| `expression` | String | Visual presentation style of the action. Available for nudge actions. |
| `message` | Object | Message configuration associated with the action. |
| `emails` | Array[String] | Email recipients configured for the action. |
| `adherence` | Object | Adherence settings for nudge actions. |
| `when` | String | Specifies when the action is executed. Available for email actions. |
| `default` | Boolean | Indicates whether the action is system-defined. |
| `title` | String | Title displayed for the action. |
| `titleDesc` | String | Description associated with the title. |
| `useGenAIForTitle` | Boolean | Indicates whether GenAI generates the title dynamically. |
| `body` | String | Email body content. Available for email actions. |
| `adType` | String | Adherence evaluation type. |
| `session` | String | Session scope used for adherence evaluation. |
