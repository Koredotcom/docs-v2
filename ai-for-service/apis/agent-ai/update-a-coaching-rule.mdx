Updates an existing coaching rule for a specific bot. Use this API to modify the coaching rule name, description, and trigger conditions used to identify customer interactions that require coaching actions.


| **METHOD**           | **PUT**                                                                                                                              |
|:--------------|:----------------------------------------------------------------------------------------------------------------------------------|
| Endpoint      | `https://{{host}}/agentassist/api/v1/public/{{streamid}}/acrules/{{ruleId}}`                                                                     |
| Content Type  | `application/json`                                                                                                                |
| Authorization | `auth: {{JWT}}` — See [How to generate the JWT Token](/ai-for-service/apis/automation/api-introduction#generating-the-jwt-token). |
                                                                                            

## Header Parameters

| Header | Type | Required | Description |
|----------|----------|----------|----------|
| `auth` | String | Yes | JWT token used for authentication. |
| `accountid` | String | Yes | Unique account identifier. |



## Path Parameters

| Parameter | Description | Type |
|:-----------|:-------------|:------|
| `host` | Environment URL. For example, `https://platform.kore.ai/` | String, required |
| `streamId` | `botId` or `streamId`. Retrieve this from the App Settings page. | string, required |
| `ruleId` | Unique identifier of the coaching rule to retrieve. | String, required |

## Request Body

| Parameter | Type | Required | Description |
|------------|--------|----------|-------------|
| `name` | String | Yes | Name of the coaching rule. |
| `description` | String | No | Description of the coaching rule. |
| `triggers` | Array | Yes | List of trigger conditions that activate the coaching rule. |
| `_id` | String | No | Unique identifier of the trigger. |
| `type` | String | Yes | Trigger type. Supported values: `utterance`, `genai`. |
| `by` | String | Yes | Participant whose utterances are evaluated. For example, `customer` or `agent`. |
| `operator` | String | No | Logical operator used to combine trigger conditions. Supported values: `and`, `or`. |
| `triggerDesc` | String | Conditional | Natural language description used by GenAI triggers. Required when `type` is `genai`. |
| `when` | Object | Conditional | Utterance matching configuration. Required when `type` is `utterance`. |
| `frequency` | Object | No | Defines how often the trigger must occur before activation. |
| `addUtterances` | Array | Yes | List of utterances to match. |
| `utteranceCount` | Integer | No | Minimum number of utterances that must match. |
| `nOccurrences` | Integer | No | Number of times the condition must occur. |
| `duration` | String | No | Time window in which occurrences are evaluated. |

## Sample Request

```bash expandable=true
curl --location --max-time 15 --request PUT 'https://{{host}}/agentassist/api/v1/public/{{streamid}}/acrules/{{ruleId}}' \
--header 'auth: {{JWT_TOKEN}}' \
--header 'accountid: {{accountid}}' \
--header 'Content-Type: application/json' \
--data '{
    "name": "",
    "description": "",
    "triggers": [
      {
         "_id": "aat-c6ce49c2-536************9-51b6-9134ed683cc7fd0f",
        "type": "utterance",
        "by": "customer",
        "operator": "or",
        "when": {
          "addUtterances": [
            { "utterance": "" },
            { "utterance": "" }
          ],
          "utteranceCount": 1

          "nOccurrences": 1,
          "duration": "anyTime"
        }
      },
      {
          "_id": "aat-1fc7977f--************-ffe4eabe8bad",
        "type": "genai",
        "by": "customer",
        "operator": "or",
        "triggerDesc": "",
        "frequency": {
          "nOccurrences": 1,
          "duration": "anyTime"
        }
      }
    ]
}
```

## Response Body Parameters

| Parameter | Type | Description |
|------------|--------|-------------|
| `id` | String | Unique identifier of the coaching rule. |
| `name` | String | Name of the coaching rule. |
| `description` | String | Description of the coaching rule. |
| `tags` | Array | Tags associated with the coaching rule. |
| `channels` | Array | Channels where the coaching rule is applicable. |
| `isActive` | Boolean | Indicates whether the coaching rule is currently active. |
| `botId` | String | Unique identifier of the associated bot. |
| `accountId` | String | Unique identifier of the account. |
| `createdOn` | String (DateTime) | Date and time when the coaching rule was created. |
| `triggers` | Array | List of configured trigger conditions. |
| `actions` | Array | List of coaching actions executed when rule conditions are met. |
| `assignees` | Array | Users assigned to the coaching rule. |
| `status` | String | Current status of the coaching rule. |
| `state` | String | Configuration state of the coaching rule. |
| `default` | Boolean | Indicates whether the coaching rule is a system-defined default rule. |
| `deletable` | Boolean | Indicates whether the coaching rule can be deleted. |
| `refId` | String | Reference identifier of the coaching rule. |
| `lModOn` | String (DateTime) | Date and time when the coaching rule was last modified. |
| `parentId` | String | Parent coaching rule identifier. |
| `triggers._id` | String | Unique identifier of the trigger. |
| `triggers.type` | String | Type of trigger configured for the coaching rule. |
| `triggers.by` | String | Participant evaluated by the trigger. |
| `triggers.operator` | String | Logical operator used for trigger evaluation. |
| `triggers.triggerDesc` | String | Natural language description used by GenAI trigger evaluation. |
| `actions._id` | String | Unique identifier of the action. |
| `actions.type` | String | Coaching action type. |
| `actions.expression` | String | Severity or expression level associated with the action. |
