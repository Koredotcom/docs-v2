Provides programmatic access to interaction-level Quality AI and Conversation Intelligence data, including evaluation metrics, sentiment, emotions, duration status, intents (L1–L3 hierarchy, confidence, sentiment, resolution), custom fields, disposition, audit data, voice-specific metrics, and complete interaction context.

Audit data includes audit status, audit date, auditor, and audit responses by metric, enabling teams to analyze AutoQA and ManualQA results, track audits, generate reports, and perform advanced analytics. Additional fields such as contact direction, audit workflow details, and recording links enhance reporting, compliance monitoring, and operational insights.

| **METHOD** | **POST** |
|:------------|:----------|
| Endpoint | `https://{{host}}/qualityai/api/v1/public/qualitymanagement/app/{{streamId}}/rawdata` |
| Content Type | `application/json` |
| Authorization | `auth: {{JWT}}` — See [How to generate the JWT Token](/ai-for-service/apis/automation/api-introduction#generating-the-jwt-token). |
| API Scope | Quality Management Analytics. |

## Header Parameters

| Parameter | Description | Type |
|:-----------|:-------------|:------|
| `Content-Type` | `application/json` | String, required |
| `accountId` | Unique account identifier. For example, `67a9ca06cf0e510a8632xxxx` | String, required |
| `orgId` | Unique identifier of the organization. | String, required |

## Path Parameters

| Parameter | Description | Type |
|:-----------|:-------------|:------|
| `host` | Environment URL. For example, `https://platform.kore.ai/` | String, required |
| `streamId` | Bot identifier or Stream identifier. Access it from the [General Settings](/ai-for-service/app-settings) page of the bot. | String, required |

## Sample Request

```bash
curl --location 'https://{{host}}/qualityai/api/v1/public/qualitymanagement/app/{{streamId}}/rawdata' \
  --header 'accountId: {{accountId}}' \
  --header 'auth: {{JWT_TOKEN}}' \
  --header 'Content-Type: application/json' \
  --header 'orgId: o-da5be4e0-8fbb-5229-ac20-9b1384ebxxxx' \
  --data '{
    "offset": 0,
    "startDate": "2026-03-23 10:17:54",
    "endDate": "2026-03-23 23:00:35",
    "limit": 5,
    "page": 1
    "contact_direction": "inbound"
  }'
```

## Body Parameters

| Parameter | Description | Type |
|:-----------|:-------------|:------|
| `offset` | Number of records to skip for pagination.  | Integer, required |
| `startDate` | The start date to include records in ISO 8601 format. | String, required |
| `endDate` | The end date to include records in ISO 8601 format. | String, required |
| `limit` | The number of conversation records to return. The default is `10`. | Integer, optional |
| `page` | The page number for pagination. The default value is `1`. | Integer, optional |
|`include_below_threshold`|	Includes `below-threshold` contacts. By default, the API excludes contacts below the configured minimum duration. To include them, set `include_below_threshold=true`.|	Boolean, optional|
| `custom_fields` |	Business-specific metadata filters.	| Object, optional |
| `contact_direction` |	Resolved direction: `inbound` or `outbound`.	| String, optional|

<Note> This API excludes contacts below the threshold by default. For ad hoc analysis, allow the `include_below_threshold` parameter to `true`.</Note>

## Response Body Parameters

| Field | Type | Description |
|-------|------|-------------|
| `src` | String | Source of the conversation. |
| `customConversationId` | String | Custom conversation identifier. |
| `contactDirection` | String | Direction of the conversation, such as `inbound` or `outbound`. |
| `Conversation ID` | String | Unique conversation identifier. |
| `Disposition` | Array | List of disposition sets associated with the conversation. |
| `Disposition.setId` | String | Unique disposition set identifier. |
| `Disposition.setName` | String | Name of the disposition set. |
| `Disposition.code` | Array| List of disposition codes selected for the set. |
| `Disposition.code.id` | String | Unique disposition code identifier. |
| `Disposition.code.name` | String | Name of the disposition code. |
| `Disposition.code.colour` | String | Hex color associated with the disposition code. |
| `Conversation Start Time` | String | Date and time when the conversation started in ISO 8601 format. |
| `Conversation End Time` | String | Date and time when the conversation ended in ISO 8601 format. |
| `Language` | String | Language used in the conversation. |
| `Duration` | String | Total conversation duration. |
| `Sentiment Score` | Number | Overall sentiment score of the conversation. |
| `Queues` | Array | Queue details associated with the conversation. |
| `Queues.Queue ID` | String | Unique queue identifier. |
| `Queues.Queue Name` | String | Queue name. |
| `Agents` | Array | Agent details associated with the conversation. |
| `Agents.agentId` | String | Unique agent identifier. |
| `Agents.Agent Name` | String | Agent name. |
| `Agents.Agent Start Time` | String | Date and time when the agent joined the conversation in ISO 8601 format. |
| `Agents.Empathy Score` | Number | Empathy score assigned to the agent. |
| `Agents.Agent Email` | String | Agent email address. |
| `Kore Evaluation Score` | Number | Overall evaluation score generated by the system. |
| `IsChurnRiskObserved` | Boolean | Indicates whether churn risk was detected. |
| `IsEscalationObserved` | Boolean | Indicates whether escalation was detected. |
| `Fatal Errors` | Number | Number of fatal errors identified. |
| `Emotions` | Array | Emotions detected during the conversation. |
| `Taxonomy Resolution` | String | Indicates whether the conversation was resolved according to taxonomy criteria. |
| `Audit Status` | String | Current audit status. |
| `Audit Date` | String | Date when the audit was completed. |
| `Auditor Name` | String| Name of the auditor. |
| `duration_status` | String | Evaluation status based on duration threshold. |
| `Sentiment Pattern` | Object | Sentiment trend throughout the conversation. |
| `Sentiment Pattern.start` | String | Sentiment at the beginning of the conversation. |
| `Sentiment Pattern.end` | String | Sentiment at the end of the conversation. |

| `Agent emotions.emotion` | String | Detected agent emotion. |
| `Agent emotions.duration` | Number | Duration for which the emotion was detected. |
| `Agent emotions.proportion` | Number | Percentage of conversation associated with the emotion. |
| `Sentiment Ratio` | Object | Distribution of sentiment across the conversation. |
| `Sentiment Ratio.positive` | Number | Percentage of positive sentiment. |
| `Sentiment Ratio.neutral` | Number | Percentage of neutral sentiment. |
| `Sentiment Ratio.negative` | Number | Percentage of negative sentiment. |
| `Metrics` | Array | Evaluation metrics associated with the conversation. |
| `Metrics.Metric ID` | String | Unique metric identifier. |
| `Metrics.Metric Name` | String | Metric name. |
| `Metrics.auditorResponse` | String | Auditor's response for the metric. |
| `Metrics.effectiveComment` | String | Final comment applied to the metric after review. |
| `Metrics.comments` | Array | Audit and dispute review comments. |
| `Metrics.comments.stage` | String | Review stage where the comment was added. |
| `Metrics.comments.round` | Number | Review round number. |
| `Metrics.comments.authorRole` | String | Role of the comment author. |
| `Metrics.comments.authorId` | String | Identifier of the comment author. |
| `Metrics.comments.text` | String | Comment text. |
| `Metrics.comments.createdAt` | String | Date and time when the comment was created in ISO 8601 format. |
| `Metrics.Qualification` | String | Qualification result for the metric. |
| `Metrics.isFatalError` | Boolean | Indicates whether the metric is marked as a fatal error. |
| `Metrics.triggerJustification` | Array | Trigger-based justification details. |
| `Metrics.justification` | Array | Supporting justification details. |
| `Metrics.justification.message_id` | Array | Referenced message identifiers. |
| `Metrics.justification.timestamp` | Array | Timestamps of referenced messages. |
| `Metrics.justification.justification` | String | Justification text. |

| `Generated Intents.keywords` | Array | Keywords associated with the intent. |
| `Generated Intents.Sentiment` | String | Sentiment associated with the intent. |

| `Configured_Intents.topics.L2_topics.L3_topics.sentiment` | Number | Sentiment score for the third-level topic. |
| `Configured_Intents.topics.L2_topics.L3_topics.resolution` | Number | Resolution score for the third-level topic. |
| `Configured_Intents.total_topics_identified` | Number | Total number of topics identified. |
| `custom_fields` | Object | Custom fields configured for the conversation. |
| `custom_fields.Duration_minutes` | String | Conversation duration in minutes. |
| `custom_fields.CallType` | String | Type of call. |
| `custom_fields.Region` | String | Region associated with the conversation. |
| `totalResults` | Number | Total number of records available. |
| `hasMore` | Boolean | Indicates whether additional records are available. |
| `totalPages` | Number | Total number of result pages. |
