The following table lists the APIs available for Quality AI.

| API | Description | App Scope |
|-----|-------------|-----------|
| [Raw Data API](/ai-for-service/apis/quality-ai/raw-data-api) | Provides detailed Quality AI and Conversation Intelligence data, including quality metrics and analytics for each interaction | Configuration |
| [Auto QA Reporting API](/ai-for-service/apis/quality-ai/auto-qa-reporting-api) | Provides interaction-level Auto QA scoring and metric qualification based on the associated Quality AI form | Configuration |
| [Create Queue Map](/ai-for-service/apis/quality-ai/create-queue-map-api) |Creates a queue mapping for Quality AI evaluation. | Configuration |
| [Assign Agent](/ai-for-service/apis/quality-ai/assign-agent-api) |Assigns an agent to a queue for Quality AI evaluation. | Configuration |
| [Create Queue](/ai-for-service/apis/quality-ai/create-queue-api) |Creates a queue for Quality AI evaluation. | Configuration |
| [Fetch Agents using Queues](/ai-for-service/apis/quality-ai/fetch-agents-using-queues-api) |Fetches a list of agents associated with one or more Quality AI queues. | Configuration |
| [Get Job Status](/ai-for-service/apis/quality-ai/get-job-status-api) |Retrieves the status of a Quality AI job. | Configuration |
| [Replace Agent](/ai-for-service/apis/quality-ai/replace-agent-api) |Replaces an existing agent in a queue for Quality AI evaluation. | Configuration |
| [Unassign Agent](/ai-for-service/apis/quality-ai/unassign-agent-api) |Removes an agent from a queue for Quality AI evaluation. | Configuration |
