Retrieves the status and results of a previously submitted asynchronous queue management job.

| **Method**        | GET |
|-------------------|------|
| **Endpoint**      | `https://{{host}}/qualityai/api/v1/public/{{streamId}}/qm/queues/jobs/{{jobId}}` |
| **Content-Type**  | `application/json` |
| **Authorization** | `auth: {{JWT_TOKEN}}` See [How to generate the JWT Token](/ai-for-service/apis/automation/api-introduction#generating-the-jwt-token). |
| **API Scope**     | SmartAssist Analytics |

## Path Parameters

| Parameter| Description                                                      | Type             |
|---------------|-------------------------------------------------------------|------------------|
| `host`        | Environment URL. For example, `https://platform.kore.ai`    | String, required |
| `streamId`   | Unique identifier of the stream.                             | String, required |
| `jobId`      | Unique identifier of the job for which to retrieve status.     | String, required |

## Header Parameters

| Parameter| Description                                               | Type              |
|---------------|--------------------------------------------------------------|-------------------|
| `auth`       | Authentication token used to authorize the request. | String, required  |


## Sample Request

```bash expandable=true
curl --location --request GET 'https://{{host}}/qualityai/api/v1/public/{{streamId}}/qm/queues/jobs/{{jobId}}' \
--header 'auth: {{JWT_TOKEN}}' \
--header 'Content-Type: application/json' \
```

## Response Body Parameters

| Field | Type | Description |
|---------|------|-------------|
| `jobId` | string | Unique identifier of the agent mapping job. |
| `type` | string | Type of job being processed. For this API, the value is `AGENT_MAPPING`. |
| `action` | string | Operation performed by the job. Possible values include `assign` or `unassign`. |
| `mode` | string | Processing mode used for the operation. Possible values include `append` or `replace`. |
| `status` | string | Current status of the job. Possible values include `queued`, `in_progress`, `completed`, or `failed`. |
| `createdAt` | string | Timestamp when the job was created in ISO 8601 format. |
| `progress` | object | Summary of the overall job execution progress. |
| `progress.total` | integer | Total number of items submitted for processing. |
| `progress.done` | integer | Number of items processed successfully. |
| `progress.failed` | integer | Number of items that failed during processing. |
| `progress.pending` | integer | Number of items still awaiting processing. |
| `results` | array | List of processing results for each queue included in the request. |
| `index` | integer | Zero-based index of the processed queue from the request payload. |
| `queue` | string | Name of the queue that was processed. |
| `customQueueId` | string | Custom identifier of the queue. |
| `queueId` | string | System-generated unique identifier of the queue. |
| `status` | string | Processing status of the queue operation. |
| `counts` | object | Summary of agent processing results for the queue. |
| `counts.agents` | integer | Total number of agents included in the operation. |
| `counts.assigned` | integer | Number of agents successfully assigned to the queue. |
| `counts.unassigned` | integer | Number of agents successfully unassigned from the queue. |
| `counts.unchanged` | integer | Number of agents whose queue mapping remained unchanged. |
| `counts.failed` | integer | Number of agent operations that failed. |
| `processedAt` | string | Timestamp when processing of the queue completed in ISO 8601 format. |
| `errors` | array | List of errors encountered during processing. Empty if no errors occurred. |
