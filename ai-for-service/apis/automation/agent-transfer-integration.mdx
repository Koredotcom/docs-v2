Use the Agent Transfer Integration API to enable, update, and reset Agent Integrations for an app. The API supports Custom (Botkit), Kore, Genesys Web Messaging, ServiceNow, and Salesforce MIAW integrations.

| Field | Value |
|---|---|
| **Method** | `POST` – Enables a new Agent Integration.<br />`PUT` – Updates an existing Agent Integration.<br />`DELETE` – Resets an existing Agent Integration configuration. |
| **Endpoint** | `https://{{host}}/api/public/bot/{{botId}}/agentintegrations/chat/{{integration}}` |
| **Content Type** | `application/json` |
| **Authorization** | `auth: {{JWT}}` See [How to generate the JWT Token](/ai-for-service/apis/automation/api-introduction#generating-the-jwt-token). |
| **API Scope** | `agent_integrations:read` and `agent_integrations:write` |

All supported Agent Integrations are chat integrations. Use `chat` as the integration type in the endpoint.

### Path Parameters

| Parameter | Required | Description |
|---|---|---|
| `botId` | Required | ID of the app. Access it through **App Settings** → **App Profile**. |
| `integration` | Required | Identifier of the Agent Integration to configure. Supported integrations are `custom`, `genesys`, `kore`, `servicenow`, and `salesforce`. |

### Query Parameters

| Parameter | Required | Type | Description |
|---|---|---|---|
| `setAsDefault` | Optional | Boolean | Sets the Agent Integration as the default when set to `true`. Only one Agent Integration can be the default at a time. |

<Note>Do not use `isDefault` in the request body.</Note>
    

### Body Parameters

For `POST` and `PUT`, provide the configuration fields required for the selected Agent Integration.

| Parameter | Required | Type | Description |
|---|---|---|---|
| `<integration-specific-fields>` | Conditional | Object | Configuration fields required for the selected Agent Integration. |

### Sample Request for POST

Use `POST` to enable an Agent Integration.

```bash
curl --location --request POST 'https://{{host}}/api/public/bot/{{botId}}/agentintegrations/chat/{{integration}}' \
--header 'auth: {{jwt-token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
  <integration-specific-fields>
}'
```

To enable the integration and set it as the default:

```bash
curl --location --request POST 'https://{{host}}/api/public/bot/{{botId}}/agentintegrations/chat/{{integration}}?setAsDefault=true' \
--header 'auth: {{jwt-token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
  <integration-specific-fields>
}'
```

### Sample Request for PUT

Use `PUT` to update an existing Agent Integration. Provide the complete configuration.

```bash
curl --location --request PUT 'https://{{host}}/api/public/bot/{{botId}}/agentintegrations/chat/{{integration}}' \
--header 'auth: {{jwt-token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
  <complete-integration-configuration>
}'
```

### Sample Request for DELETE

Use `DELETE` to reset an Agent Integration.

```bash
curl --location --request DELETE 'https://{{host}}/api/public/bot/{{botId}}/agentintegrations/chat/{{integration}}' \
--header 'auth: {{jwt-token}}' \
```

Use this API to reset all the configured Agent Integration.

```bash
curl --location --request DELETE 'https://{{host}}/api/public/bot/{{botId}}/agentintegrations' \
--header 'auth: {{jwt-token}}' \
```

## Channel Mappings

Use these APIs to read and update which Agent Integration handles each channel of an app.

| Field | Value |
| - | - |
| **Method** | `GET` – Retrieve the current channel mappings.<br />`PUT` – Replace the entire channel mapping. |
| **Endpoint** | `https://{{host}}/api/public/bot/{{botId}}/agentintegrations/channelmappings` |
| **API Scope** | `agent_integrations:read` (GET)<br />`agent_integrations:write` (PUT) |

### Body Parameters for PUT

The `channelMappings` object has one key per channel enabled for the app, plus `default`. The set of keys is specific to each app. It is not a fixed list, and voice channels are not included.

| Parameter | Required | Description |
| - | - | - |
| `channelMappings` | Required | Object that maps each channel to an Agent Integration. |
| `channelMappings.default` | Required | The app's default Agent Integration. |
| `channelMappings.<channel>` | Required | One key per enabled chat channel of the app, for example `rtm`, `agentassist`, `smartassist`, or `widgetsdk`. The value is the Agent Integration used for that channel. |

<Note>
`PUT` replaces the whole map, so a body that omits a channel would delete it. The API therefore rejects a partial map with `400` and names what is missing, for example: `channelMappings must map every channel enabled for this app. Missing: rtm, agentassist.` It also returns `400` if a channel is mapped to an integration that is not configured for the app.
</Note>

### Sample Request for GET

```bash
curl --location 'https://{{host}}/api/public/bot/{{botId}}/agentintegrations/channelmappings' \
--header 'auth: {{jwt-token}}'
```

### Sample Response for GET

The channel keys depend on the channels enabled for your app.

```json
{
  "channelMappings": {
    "default": "salesforce",
    "rtm": "genesys",
    "agentassist": "genesys",
    "smartassist": "genesys"
  },
  "state": "configured",
  "requiresPublish": true
}
```

### Sample Request for PUT

The channel keys depend on which channels the app has enabled, so copying this body verbatim fails on an app with a different set. Start from the `GET` response, which you can send back as the `PUT` body unchanged. `state` and `requiresPublish` are accepted and ignored.

```bash
curl --location --request PUT 'https://{{host}}/api/public/bot/{{botId}}/agentintegrations/channelmappings' \
--header 'auth: {{jwt-token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
  "channelMappings": {
    "default": "salesforce",
    "rtm": "genesys",
    "agentassist": "genesys",
    "smartassist": "genesys"
  },
  "state": "configured",
  "requiresPublish": true
}'
```





## Channel Mappings API

| Field             | Value                                                                                                                            |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Method**        | `GET` – Retrieves the channel mappings configured for the app.<br />`PUT` – Updates the channel mappings configured for the app. |
| **Endpoint**      | `https://{{host}}/api/public/bot/{{botId}}/agentintegrations/channelmappings`                                                    |
| **Content Type** | `application/json` |
| **Authorization** | `auth: {{JWT}}` See [How to generate the JWT Token](/ai-for-service/apis/automation/api-introduction#generating-the-jwt-token). |
| **API Scope**     | `agent_integrations:read` and `agent_integrations:write`                                                                         |

The channel mapping configuration contains the app's default Agent Integration and a mapping for each enabled chat channel. Voice channels are not included.

### Path Parameters

| Parameter | Required | Description                                                          |
| --------- | -------- | -------------------------------------------------------------------- |
| `botId`   | Required | ID of the app. Access it through **App Settings** → **App Profile**. |

### Sample GET Request

Retrieves the channel mappings configured for the app.

```bash
curl -s "https://{{host}}/api/public/bot/{{botId}}/agentintegrations/channelmappings" \
--header 'auth: {{jwt-token}}' \
```

### Sample PUT Request

Updates the channel mappings configured for the app.

The request must include the `default` mapping and a mapping for every enabled chat channel. The API replaces the entire channel mapping configuration. If a channel is omitted, the API returns a `400` error.

```bash
curl -s -X PUT "https://{{host}}/api/public/bot/{{botId}}/agentintegrations/channelmappings" \
--header 'auth: {{jwt-token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
    "channelMappings": {
      "default": "salesforce",
      "rtm": "genesys",
      "agentassist": "genesys",
      "smartassist": "genesys"
    }
  }'
```

### Body Parameters

| Parameter                   | Required | Type    | Description                                                                                                       |
| --------------------------- | -------- | ------- | ----------------------------------------------------------------------------------------------------------------- |
| `channelMappings`           | Required | Object  | Contains the default Agent Integration and a mapping for each enabled chat channel.                               |
| `channelMappings.default`   | Required | String  | The app's default Agent Integration.                                                                              |
| `channelMappings.<channel>` | Required | String  | Agent Integration mapped to an enabled chat channel. The channel keys depend on the channels enabled for the app. |
| `state`                     | Optional | String  | Configuration state. The API accepts and ignores this field.                                                      |
| `requiresPublish`           | Optional | Boolean | Indicates whether the configuration requires publishing. The API accepts and ignores this field.                  |

<Note>The `PUT` request replaces the entire channel mapping configuration. To update a single mapping, retrieve the current configuration using `GET`, modify the required mapping, and send the complete configuration using `PUT`.</Note>
