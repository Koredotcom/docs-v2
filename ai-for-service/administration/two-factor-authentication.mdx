The Kore.ai Platform provides Two-Factor Authentication (2FA) as an additional security measure for enterprise user accounts. 2FA adds an extra layer of security by requiring a one-time password (OTP) sent to the user's registered email address. In addition to standard authentication methods, users must complete email-based OTP verification to access the platform.

## Enable 2FA

Only administrators can enable 2FA for enterprise users.

1. Sign in to the Admin Console.
2. Navigate to **Security & Control** > **2FA**.
3. Click **Enable 2FA**.
4. Click **Save**.

<Note>Enterprise SSO and 2FA are mutually exclusive. Enabling one automatically disables the other.</Note>

## OTP Verification

- OTPs are valid for a single use and expire after **10 minutes**.
- Authentication fails if the OTP is reused, entered incorrectly, or submitted after expiration.


## Grant 2FA Permissions

The master administrator grants 2FA permissions to system administrators.

1. Go to **User Management** > **Role Management**.
2. Edit the required administrator role.
3. Open the Permissions tab.
4. Set **Two-Factor Authentication** to **Yes**.
5. Click **Save**.


## Admin User Sign-In with 2FA

1. Enter your email address and **Click Continue**.
2. Enter your password and click **Log in**.
3. Enter the OTP received by email.
4. After successful verification, the system signs you in and redirects you to the dashboard.


## End User Sign-In with 2FA

1. Sign in to App Builder using your email address and password.
2. Select the required AI Agent account.
3. If 2FA has not already been completed during the current session, enter the OTP received by email.
4. If required, click **Resend Code** to generate a new OTP.
5. After successful verification, the system redirects you to the dashboard.

<Note>If you have already completed 2FA for another account during the same session, the system does not prompt for additional verification.</Note>

## Switch Accounts During 2FA

Users with multiple accounts can switch accounts after initiating 2FA without entering the current verification code.

1. On the verification screen, click **Switch to Different Account**.
2. Select the same or a different account from the account list.
3. Complete verification using the email passcode sent for the selected account.

### Important Considerations

- Email passcodes expire after 2 minutes.
- Switching to an unauthenticated account generates a new passcode, regardless of whether the previous passcode has expired.
- If the previously selected account has already been verified during the current session, no additional verification is required.
- If you enter an incorrect passcode, access is denied. Enter a valid passcode within 2 minutes or click **Resend Code** to generate a new one.
