Enterprise Key Management enables organizations to protect enterprise data through encryption and manage encryption keys used to secure data stored on Kore.ai servers, including user information, enterprise data, and application content.

The platform supports the following key management options:

* **Default Encryption**: Uses platform-managed encryption keys.
* **Bring Your Own Key (BYOK)**: Uses customer-managed encryption keys.


## Default Encryption

By default, the platform encrypts all enterprise data using a platform-managed encryption key. This includes user profiles, application configurations, conversations, and enterprise settings.

### Key Rotation

To maintain security, the platform supports:

- **Automatic rotation** every 60 days.
- **Manual rotation** from the Admin Console.

### Generate a New Encryption Key

1. Navigate to **Security & Control** > **Enterprise Key**.

![Enterprise key](/ai-for-service/administration/nac-images/bac-enterprise-key.png)

2. Select **Refresh**. The platform immediately generates and applies a new encryption key.

## Bring Your Own Key (BYOK)

BYOK lets organizations to use customer-managed encryption keys to protect application data while retaining full control of key ownership and lifecycle management.

Kore.ai integrates with external key management services such as [AWS Key Management Service (KMS)](/ai-for-service/administration/byok-aws-integration) and [Azure Key Vault](/ai-for-service/administration/byok-azure-integration). Organizations can use their own Customer Master Keys (CMKs) while benefiting from Kore.ai's secure, scalable cloud infrastructure and HSM-backed key protection.
