The Administration module provides tools to manage your platform account, users, security, and billing. Use the sections below to find configuration guides and reference documentation.



## Accessing the Admin Console

You can access the [Admin Console](https://platform.kore.ai/adminconsole/) from the AI for Service using the **Go To Admin Console** option, under your user account menu.


## Administration Dashboard

The dashboard gives administrators a real-time snapshot of platform activity, app usage, and user engagement metrics. For details, see [Dashboard overview](/ai-for-service/administration/dashboard).
