 Use the Groups page in User Management to create, import, and manage user groups, including groups from Active Directory. Create groups to organize developers and assign apps based on business needs, such as department, business unit, or geographic location. The system automatically creates groups when you import organizational units from Active Directory. The following illustration shows the Groups page in the User Management module. 

![User Management - Groups](/ai-for-service/administration/images/manage-group.png)


## Details

The following table describes the columns in the Groups listing.

| Column | Description |
|--------|-------------|
| Group Name | Displays the group name. |
| Description | Displays the group description. This field is optional.|
| Source | Displays the group source: **Local** (created manually in User Management), **AD** (imported or synchronized from Active Directory), or System (created as a default group).|
| Users | Displays the number of users in the group. Select the link to manage group members.|
| Groups | Displays the number of child groups. Select the link to manage child groups.|

## Search Field

If the list of users or groups is large, use the **Search** field to find specific entries. Enter at least three characters to start the search. To display all entries, clear the search field and press **Enter**.

<Note>You can use any number of search terms, but the system considers only the first 20 characters of each term when returning results.</Note>

## Create a Group

Create groups to organize users by department, location, interest, or other criteria. 

<Note>Groups are for administrative use only and are not visible to end users.</Note>

1. In **User Management**, select **Groups**.
2. Click **Add New**.
3. In **Group Name**, enter a name for the group.
4. (Optional) In Description, enter a description.
5. Select the users and groups to add to the group.
6. Click **Save**. The system creates the group and returns you to the Groups page.

    ![Create Groups](/ai-for-service/administration/images/create-new-group-new-admin-console.png)

## Edit or Delete a Group

To edit or delete a group, select the ellipsis (...) next to the group on the **Groups** page. To delete multiple groups, select the groups and then select **Delete Selected**.

![Delete Groups](/ai-for-service/administration/images/delete-group.png)
