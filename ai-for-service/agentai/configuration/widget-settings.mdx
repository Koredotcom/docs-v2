Widget Settings lets you configure the appearance and behavior of the Agent AI widget. Settings are organized into two sections:

- **Agent AI Channel Specific Settings** — channel-specific preferences for Chat, Voice, and Email.
- **Agent AI General Settings** — widget-wide behavior and display options.

---

## Agent AI Channel-Specific Settings

Configure widget features per channel. The following options are available:

| Setting | Description |
|---------|-------------|
| **Proactive Mode** | Automates intent identification, entity extraction, and transcript generation. Also supports **Automatic Dialog Task Entity Extraction**. By default, this toggle is on for all channels. |
| **Agent Coaching** | Provides real-time coaching based on agent utterances and speech analysis. By default, this toggle is off and is available for Chat and Voice channels. |
| **Agent Playbook** | Provides structured guidance for agents. When off, the Playbook tab remains hidden. When on, welcome messages become part of the Playbook step. By default, this toggle is off. |
| **Agentic Copilot** | Turns on autonomous, end-to-end conversation handling. Agents can cancel, override, or edit messages. Configure language, app selection, auto-send, and timer. |
| **Agentic Response Streaming** | Streams Agentic Copilot responses incrementally, reducing perceived latency during live conversations. |
| **Auto-Scroll Widget Content** | Automatically scrolls to the latest content in the **Assist**, **My AI Agent (Bot)**, and **Transcript** tabs. Agents can override this setting in the widget's Settings tab. |
| **Control Transcript Visibility between Agents** (Voice only) | Controls transcript visibility for agents on the voice channel during conversation transfers. Select **Use Agent's Entry and Exit Events** to restrict the current agent to their own conversation transcripts. The agent can still view summaries of previous bot-user and agent-user conversations, but not the previous agent's transcripts. |
| **Send Button** | Controls the **Send** button for Agent AI responses. Available for Chat and Email; on for Chat by default. |
| **Copy Button** | Controls the **Copy** button for Agent AI responses. Available for Chat and Email; on for both by default. |
| **Widget Search Bar Configuration** | Configures search sources. If the toggle is on, select from Platform, Search AI, and Agentic App. if the toggle is off, results from all sources load simultaneously. |
| **Conversation Transfer** | Defines behavior when a conversation transfers between agents. Applies to third-party configurations with appropriate transfer events. |

**When the Proactive Mode is off**:
- The **Assist** tab **Run** button is off; only **Run with agent's input** is available.
- Dynamic playbook identification and adherence are inactive; tick-off and step progression still work.
- Primary playbook automatic adherence or tick-off doesn't occur.
- If the Playbook widget is also off, the default landing page is **My AI Agent (Bot)**.

**Conversation Transfer options:**

| Transfer Type | Description |
|---------------|-------------|
| **Cold Transfer** | Handover between two agents. Applies to Voice, Chat, and Email. The system generates a new summary for the receiving agent. |
| **Warm Transfer** | Conference call between two agents. Applies to Voice and Chat. Agent-2 can modify Summary Feedback, but Run, Override, Send, Copy, Terminate, Restart, and List View buttons remain off until Agent-1 disconnects. |

Both transfer types support:
- **Scroll up to the First Message** — opens chat history at the top.
- **Continue from the Last Message** — opens chat history at the bottom.
- **Configure Dialog Task** — runs a selected dialog task automatically when the conversation transfers.

### Steps to Set Channel-Specific Preferences

1. Sign in to Platform.
2. Go to **Agent AI** > **Configuration** > **Widget Settings** > **Agent AI Settings** > **Agent AI Channel Specific Settings**.
3. Expand **Agent AI Channel Specific Settings**.
4. Select a channel from the **Select channel** list.
5. Turn on the **Agent AI Channel Specific Settings** toggle if it's off.
6. Turn **Proactive Mode** on or off.
   - Select or clear **Automatic Dialog Task Entity Extraction**.
7. Turn the toggles on or off for **Agent Coaching**, **Agent Playbook**, **Agentic Response Streaming**, **Auto-scroll widget content**, **Send Button**, and **Copy Button**.
   * For Agent Playbook, select the number of messages to pass to a step for adherence and trigger evaluation. The following note displays if you select five messages:  
      <Note> Increasing the number of messages might cause higher latency. </Note>

8. For **Agentic Copilot**:
   - Select a language.
   - Turn on or off the **Agentic Copilot** toggle.
   - Select an assignment option:
     - **Enable for all Agents** — the selected app applies to all queues.
       1. Select an app from **Select Agentic App**.
       2. Select **Allow auto send Message** to turn on auto-send.
       3. Use the slider to set the delay (up to 60 seconds).

       ![Agentic Copilot All Agents](/ai-for-service/agentai/configuration/widget-settings-images/agentic-copilot-all-agents.png)

     - **Enable for Specific Queues** — assigns apps to specific queues via Agent AI Mapping.
       1. Select **Open AI Feature Mapping** to navigate to Agent AI Mapping.
       2. Select **learn more** for queue configuration details.

       ![Agentic Copilot Specific Agents](/ai-for-service/agentai/configuration/widget-settings-images/agentic-copilot-specific-agents.png)

9. Turn on or off **Control Transcript Visibility between Agents** (Voice channel only) and select one of the following options:
   | Option | Description |
|---|---|
| **Use Public APIs to Control Transcription** | Controls transcript visibility using public APIs. |
| **Use Agent's Entry and Exit Events** | The current agent views only their own conversation transcripts and summaries of previous bot-user and agent-user conversations. |

10. Turn on **Widget Search Bar Configuration**.
    1. Select one or more options — **Platform**, **Search AI**, **Agentic App**.
    2. If you select **Agentic App**, choose an app from the dropdown list.

    <Note>**Search AI** and **Agentic App** fields are unavailable until you configure them, and a warning prompts you to configure them first.</Note>

11. Select an option under **Conversation Transfer**.
12. Select **Save**.

    ![Agent AI Channel Specific Settings](/ai-for-service/agentai/configuration/widget-settings-images/agentassist-channel-specific-settings-page-1.png)

## Agent AI General Settings

Configure global widget behavior including URL handling, data format, and language preferences.

| Setting | Description |
|---------|-------------|
| **URL Opening Behavior** | **Default System Behavior** — links open in a new window. **Post Event** — triggers the `AgentAI.UrlClickedMessage` event so the desktop app controls the link's behavior. |
| **Data Format Preference** | **Plain String** — sends messages in plain text. **Original Format** — sends messages with HTML tags as received. Applies to Playbooks and Dialog Tasks. |
| **Help & Support** | Show or hide Help & Support in the widget. Configure which components appear (Documentation, FAQ, Kore Academy) and their URLs. |
| **Honor Bot Event - Intent not found** | Triggers the configured intent-not-found event if Agent AI can't identify the user's intent. |
| **Third Party Configuration** | Loads the Agent AI widget in third-party agent desktops based on the queue mappings in [Third Party Configuration](/ai-for-service/agentai/configuration/third-party-configuration). Turned off this toggle to stop the widget from loading in those desktops. | 
| **Default Language for Agent AI Widget** | Sets the widget display language. Optionally, allow agents to change the language at run time. |
| **Dialog Task Display Name Configurations** | **Default System Behavior** — standard display. **Advanced Mode** — use custom script logic for trait-based dialog task display. |
| **Secure Real-Time Messaging** | Turns on end-to-end encryption for agent and customer messages during live conversations. |

**Post Event URL behavior:**

When an agent selects a link in the widget, the `AgentAI.UrlClickedMessage` event triggers and a log appears on the right showing the URL. Desktop applications use this URL to control how the link opens.

![Post Event URL Opening Behavior](/ai-for-service/agentai/configuration/widget-settings-images/post-event-url-opening-behavior-3.png)

### Steps to Set Agent AI General Settings

1. Go to **Agent AI** > **Configuration** > **Widget Settings** > **Agent AI Settings** > **Agent AI General Settings**.
2. Expand **Agent AI General Settings**.
3. Select **Default System Behavior** or **Post Event** under **URL opening behavior**.
4. Select **Plain String** or **Original Format** under **Data Format Preference**.
5. Turn on or off the **Help & Support** toggle.

   <Note> Turning on this toggle makes **Conversation Metadata** available to copy by default. </Note>

   1. Select the components to display — **Documentation**, **FAQ**, **Kore Academy**.
   2. Customize the URLs for **Documentation** and **FAQ** as needed.
6. Turn on or off the **Honor Bot Event - Intent not found** and **Third Party Configuration** toggles. 
7. Select a language from the **Default Language for Agent AI Widget** list, or select **Interactive Language** to use the app's language. To allow agents to switch languages, select **Allow agents to switch between multiple available languages**.
8. Select **Default System Behavior** or **Advanced Mode** under **Dialog Task Display Name Configurations**. For **Advanced Mode**, enter a custom script in the pop-up and select **Save**.

   ![Custom Script](/ai-for-service/agentai/configuration/widget-settings-images/custom-script.png)

9. Turn on the **Secure Real-Time Messaging** toggle to encrypt agent and customer messages during live conversations. 
10. Select **Save**.

   ![Agent AI General Settings](/ai-for-service/agentai/configuration/widget-settings-images/agent-ai-general-settings.png)

### Auto-Correct for the Search Tab

The Auto Correct feature highlights misspelled words in the Search tab and suggests corrections. Admins configure it in Widget Settings; agents can override the setting in the widget's **Settings** tab.

**Admin steps:**

1. Sign in to **Agent AI**.
2. Go to **Widget Settings** > **Agent AI General Settings**.
3. Turn the **Auto Correct** toggle on or off.
4. Select or clear **Use Custom Dictionary**.
5. Upload a customized word list.

   <Note>You can download the current word list if one has already been uploaded.</Note>

6. Select **Save**.

**Agent steps**:

1. Sign in to the **Agent AI** widget.
2. Go to the **Settings** tab.
3. Turn on or off the **Auto Correct** toggle.
