Permit traffic on the ports below in your firewall, based on the Session Border Controller (SBC) your account connects to.

## Common Ports and Protocols

These apply in every region.

| Component | Protocol | Destination Port |
| :--- | :--- | :--- |
| Agent SBC | TCP/UDP | 5060 |
| Agent SBC | TLS | 5061 |
| Agent SBC | TCP/WSS | 8443 |
| Agent SBC (RTP media) | UDP | 6000-65535 |
| Kore.ai domain (`*.kore.ai`) | TCP | 443, 8443 |
| Twilio domain (`*.twilio.com`) | TCP | 443, 8443 |
| STUN media edge (destination `168.86.128.0/18`) | UDP | 10000-65535 |

<Note>Customers on an AudioCodes gateway in the **US** region need an additional SBC block: TCP/UDP 5060, TLS 5061, TCP 10081, and UDP 6000-65535 to `54.161.251.110` (Automation/HA SBC) and `52.4.142.107` (Agent SBC).</Note>
