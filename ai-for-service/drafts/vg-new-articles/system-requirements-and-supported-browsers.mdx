## Minimum System Requirements

* x64-based processor with four CPU cores (quad-core).
* 64-bit operating system: Windows 11 or later, macOS Monterey or later.
* 8 GB RAM minimum (16 GB recommended).
* 50 GB free hard disk space.
* Network Interface Card (NIC) with 1 Gbps throughput.

The software also runs on any desktop operating system that meets these requirements and supports a listed browser, such as Linux or Chrome OS. Kore.ai doesn't test or certify these combinations.

## Additional Requirements

* Network bandwidth: 5 Mbps for voice, video, and co-browse sessions.
* Minimum screen resolution: 1024 x 768 at 20 FPS.
* Antimalware protection on each agent computer.

<Note>Some antivirus software inspects HTTPS and audio packets in real time, which can lower WebRTC audio quality.</Note>

## Web Browser Requirements

The Agent Console supports Chrome, Microsoft Edge, and Safari — each with full support for core features, video chat, screen sharing, and WebRTC calling.

| Browser | Supported version |
| :--- | :--- |
| Chrome | Current major release, or one version behind. |
| Microsoft Edge (Chromium) | Current release. |
| Safari | Latest version. |

Version recommendations come from internal testing. Older browser versions may still work; if an issue traces back to browser version, the customer must update to a supported version.

<Note>
Before using the Contact Center Agent Console, confirm the following:

* JavaScript and cookies are enabled.
* The browser grants camera and microphone access when prompted.
* The pop-up blocker is off, so the separate WebRTC window can open.
* The browser grants screen-share access (specific window or entire desktop) when prompted.
* TLS 1.2 is allowed. TLS 1.0, 1.1, and 1.3 aren't supported.
* The active call tab or window stays open. Minimizing it can delay or block answering calls; restoring the window resolves this.
* Chrome updates automatically, unless the customer's IT department restricts automatic updates.
* Microsoft Edge doesn't run in IE compatibility mode.
</Note>

### Disable Your Browser's Sleep Mode Setting

When multiple tabs are open in the Contact Center AI console, connection issues can occur while the console isn't the active tab. Disable sleep mode for the relevant site to prevent this.

**Microsoft Edge**

1. Start Microsoft Edge.
2. Select **Settings and more**.
3. Select **Settings**.
4. Select **System and performance**.
5. Under **Never put these sites to sleep**, select **Add**.
6. Enter your region domain in the **Site** box, in the format `[*.]domain` (for example, `[*.]example.com`).
7. Select **Add**.

**Google Chrome**

1. Start Google Chrome.
2. Select **Customize and control Google Chrome**.
3. Select **Settings**.
4. Select **Performance**.
5. Under **Memory** > **Always keep these sites active**, select **Add**.
6. Select **Add sites manually**.
7. Enter your region domain in the **Site** box (for example, `example.com`).
8. Select **Add**.
