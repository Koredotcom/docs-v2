The Agent Login Logout Summary Report is a detailed report of an agent's login and logout events.

---

## Report Fields

| Field | Description | Example |
|-------|-------------|---------|
| `Login` | Date and time at which the agent logged in, starting a new session. | `01/06/23 15:57:17` |
| `Logout` | Date and time at which the agent logged out, ending a session. | `01/06/23 15:57:17` |
| `Duration` | Duration of the session (Logout - Login). | `64:39:22` |
