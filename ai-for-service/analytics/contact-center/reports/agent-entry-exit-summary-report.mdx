## Report Fields

| Field | Description | Example |
|:-------|:-------------|:---------|
| `App Entry` | Date and time at which the agent entered the system, starting a new session. | `01/06/23 15:57:17` |
| `App Exit` | Date and time at which the agent exited the system, ending a session. | `01/06/23 15:57:17` |
| `Duration` | Duration of the session (Entry - Exit). | `01:39:22` |
| `Client IP` | The IP address of the client device. | `192.168.1.100` |
