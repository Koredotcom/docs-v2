The Agent Group Membership Report tracks when agents were added to or removed from agent groups within a selected date range. Use this report to audit changes to group membership for specific agents or groups.

## Report Fields

| Field           | Description                                                                                      | Example                 |
| :-------------- | :----------------------------------------------------------------------------------------------- | :---------------------- |
| `Group Name`      | Name of the agent group.                                                                         | `Support - Tier 1`        |
| `Agent Custom ID` | Custom identifier configured in the agent's profile.                                             | `AGT-00245`               |
| `Agent Name`      | Full display name of the agent.                                                                  | `John Doe`                |
| `Agent First Name` | Agent's first name.                                                                             | `John`                    |
| `Agent Last Name` | Agent's last name.                                                                               | `Doe`                     |
| `Added`           | Date and time when the agent was added to the group.                                             | `01/15/2024 09:30:00`   |
| `Removed`         | Date and time when the agent was removed from the group. Blank if the agent hasn't been removed. | `03/22/2024 14:45:00`   |
| `Last Action By`  | Email address of the user who performed the most recent membership action for this agent in the group (adding, removing, or unlinking). If the action was performed using API, the value is in the `API:<clientid>` format. | `john.doe@example.com`, `API:client_abc123`   |

<Note>`Group Name`, `Agent Custom ID`, and `Agent Name` are key fields that uniquely identify each membership record in the report.</Note>
