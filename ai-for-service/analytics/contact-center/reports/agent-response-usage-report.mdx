The Agent Response Usage Report provides a day-by-day count of how frequently agents use standard responses and secure forms across the selected date range.

---

## Generate and Manage the Report

Refer to [Creating a New Report](/ai-for-service/analytics/contact-center/reports/introduction-to-reports#creating-a-new-report) for instructions on generating this report.

Refer to [Manage Reports](/ai-for-service/analytics/contact-center/reports/introduction-to-reports#manage-reports) for instructions on managing this report.

The report is available for download.

---

## Report Fields

Each row represents one standard response or secure form for one date within the selected range.

| Field | Description                                                                                                                                               | Example                                 |
| :---- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------- |
| Name  | Name of the standard response or secure form.                                                                                                             | Refund Policy, Payment Capture Form     |
| Type  | Category of the entity.                                                                                                                                   | std response, secure form               |
| Date  | The date for this row, formatted per the selected Date Format option.                                                                                     | 01/15/2024                              |
| Usage | Number of times agents used this entity on this date — includes direct use and instances where the agent copied and edited the response before sending.    | 12                                      |
