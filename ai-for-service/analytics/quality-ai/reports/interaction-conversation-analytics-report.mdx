The Interaction Evaluation & Conversation Analytics Report provides interaction-level insights for quality evaluation and business analysis across customer conversations. It exports interaction metadata together with evaluation outcomes, sentiment analysis, detected topics, audit information, AI-generated justifications (when available), conversation intelligence insights, business metadata, evaluation metric details, and any selected optional or custom fields.

The report includes evaluation outcomes, sentiment analysis, detected topics (including topic hierarchy where available), metric-level evaluation details, manual audit results, AI-generated justifications, business metadata, and conversation intelligence insights.

Use filters such as channel, queue, flow, language, agents, agent groups, contact direction, and duration status to generate targeted reports. By default, exports include only processed conversations, with optional inclusion of pending and validation-failed conversations. Optional and custom fields are added as CSV columns based on the selected evaluation forms, report configuration, and available data.

## Generate the Report

1. **Create the New Report**

    1. On the **Reports** tab, select **+ New Report**.

    1. From the **Create New Report** list, select the **Interaction Evaluations and Conversation Analytics Report**.

        ![Report Selection](/ai-for-service/analytics/quality-ai/reports/images/interaction-report.png)

    1. Select **Next**.

1. Complete the **General** settings.

    1. Enter a unique **Name** for the report.

    1. Enter a **Description**.

    1. Select **Next**.

        ![General Settings](/ai-for-service/analytics/quality-ai/reports/images/interactions-eva-report.png)

1. Complete the **Configuration** — **Filters and Options**.

    1. Select an evaluation **Form** (at least one form is required).

    1. Select a **Date** or date range.

    1. Select a **Timezone**.

    1. Select **+ Add Filter** to apply one or more filters:
    
        1. Select the required Standard filters.
        
            1. Select the Predefined system attributes filter options such as **Channel** (**Voice** or **Chat**) with **Contact Direction** (**Inbound** or **Outbound** or **All Directions**), **Queue**, **Language**, **Agents**, **Agent Groups**, and **Duration Status** to consistently segment and analyze interactions across reports.
            
            1. Configure the selected filter values. The **Flow** filter displays only Experience Flows associated with the selected flow-based evaluation form and filters report results accordingly.

        1. Select **Custom Filters** to filter using organization-specific fields. 

            1. Dropdown selection for fields with up to 10 distinct values. 
            
            1. Text search for fields with more than 10 distinct values (supports partial and exact matches).
                
    1. Add **Optional Fields** to include additional metrics or attributes in the report that provide an extended interaction performance and customer context.

        1. **Standard Optional Fields**: Predefined system-defined (evaluation scores, sentiment, duration, topics, and conversation intelligence metrics) and ready-to-use for consistent reporting.
        1. **Predefined System Attributes** (such as channel, direction, queue, agent, and duration status) are used to consistently segment and analyze interactions across reports. 
        1. **Custom Optional Fields**: Organization-defined (from CRM integrations, APIs, AI Agent metadata) and adds business-specific context, such as Account ID, Status ID.
        1. **Flow Name** for flow-based evaluation forms, where applicable.

    1. Enter one or more addresses in the **Send Email to** field to send the automated reports (minimum one required). 

    1. Select **Next**.

        ![Configure Filters](/ai-for-service/analytics/quality-ai/reports/images/interactions-config.png)

    <Note>AI Justifications, available only for Gen AI by Question metrics, provide AI-generated explanations for each evaluation score. They appear in Interaction Evaluations and Conversation Analytics reports, and are accessible via APIs.</Note>

1. Complete the **Schedule** to generate a report with the current configuration.

    1. Choose **Run on Demand** or **Schedule**.

        - **Run on Demand**: Generates the report immediately.
        - **Schedule**: Generates the report automatically.

    1. If you select **Schedule**:

        1. Choose a **Frequency or Repeat** (Hourly, Daily, Weekly, Monthly, Quarterly, or Yearly).

        1. Select a **Start Date** and **Timezone**.

        1. Select **Save**.

            ![Schedule](/ai-for-service/analytics/quality-ai/reports/images/interaction-run-on-demand.png)


            
            <Note>The report returns all interactions matching the selected filters. Use the **Duration Status** filter to narrow results by evaluation eligibility. Interactions ingested before duration threshold support may display a `null duration_status` value.</Note>

### Processing Status Options in Reports

The following options determine whether pending or validation-failed conversations are included when exporting reports.

| Option                                                         | What Is Exported                                                                                                                                                |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Include pending conversations** *(Off by default)*           | Exports conversation metadata for pending conversations. Evaluation scores and Conversation Intelligence fields remain empty because processing isn't complete. |
| **Include validation-failed conversations** *(Off by default)* | Exports conversation metadata for validation-failed conversations, along with the validation failure reason.                                                    |


<Note>Exported reports include a **Processing Status** column with one of the following values: **Processed**, **Pending**, or **Validation Failed**. For **Validation Failed** entries, the report also includes the corresponding validation failure reason.</Note>

### Important behavior

- AI Justifications are available only for Gen AI by Question metrics.
- Custom fields vary depending on the selected date range and available data.
- Only selected optional and custom fields are included in the generated CSV.
- By default, the report includes all interactions matching the selected filters.
- Use **Duration Status** to filter interactions by **Evaluated**, **Below Threshold**, or **Duration Unavailable**.
- For interactions ingested before duration threshold support was introduced, the `duration_status` field may return `null`.
- When available, **Contact Direction** displays **Inbound**, **Outbound**, or **All Directions**.
- For flow-based evaluation forms, the report includes Experience Flow conversations and exports flow-specific evaluation details.


## Report Fields

### Generated CSV Fields

The generated CSV exports one row for each interaction and includes interaction metadata, evaluation outcomes, sentiment analysis, detected topics, audit information, AI-generated justifications (when available), conversation intelligence insights, business metadata, evaluation metric details, and any selected optional or custom fields.

| Field                         | Description                                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------------------------ |
| **Account ID**                | Account identifier associated with the interaction.                                              |
| **Contact ID**                | Unique identifier for the customer contact.                                                      |
| **Conversation ID**           | Unique identifier for the interaction.                                                           |
| **Entry Date**                | Date and time when the interaction started.                                                      |
| **Channel**                   | Interaction channel, such as Voice or Chat.                                                      |
| **Contact Direction**         | Indicates whether the interaction is Inbound, Outbound, or All Directions.                       |
| **Queue**                     | Queue associated with the interaction.                                                           |
| **Flow Name**                 | Experience Flow associated with the interaction. Available only for flow-based evaluation forms. |
| **Processing Status**         | Indicates whether the interaction is Processed, Pending, or Validation Failed.                   |
| **Duration Status**           | Indicates whether the interaction is Evaluated, Below Threshold, or Duration Unavailable.        |
| **Evaluation Scores**         | AutoQA and manual evaluation scores for the interaction.                                         |
| **Sentiment**                 | Conversation sentiment identified during analysis.                                               |
| **Topics**                    | L1, L2, and L3 topics identified for the interaction.                                            |
| **AI Justifications**         | AI-generated explanations for Gen AI by Question metric scores, where available.                 |
| **Conversation Intelligence** | Conversation intelligence insights included in the report.                                       |
| **Optional Fields**           | Additional columns selected during report configuration.                                         |
| **Custom Fields**             | Organization-specific fields included in the export.                                             |

<Note>The exported CSV dynamically includes columns based on the selected evaluation forms, applied filters, optional fields, custom fields, and report configuration. For flow-based evaluation forms, the export also includes the **Flow Name** column where applicable.</Note>

### Metric Evaluation Fields

When metric-level evaluation details are included in the export, the report contains one row for each evaluated metric associated with an interaction.

| Field | Description |
|------|-------------|
| Metric Name | Name of the evaluation metric. |
| Is Fatal | Indicates whether the metric is configured as a fatal metric (1 = Yes, 0 = No). |
| Total Interactions | Total interactions included for the metric. |
| Total Applicable Interactions | Number of interactions where the metric was applicable. |
| Total Adhered Interactions | Number of applicable interactions that met the evaluation criteria. |
| Metric Adherence % | Percentage of applicable interactions that adhered to the metric. |

<Note>Metric evaluation fields are repeated for each evaluated metric associated with an interaction. Consequently, a single interaction may appear in multiple rows of the exported CSV—one row for each evaluated metric.</Note>

### View and Download the Report

1. On the **Reports** tab, locate the report in the **Actions** column.

1. Select More options (⋮), then select **History**.

1. Select **Download** to save the report as a CSV file.

### Report Format

#### Field Representation in the Generated CSV

The generated CSV exports one row for each interaction and includes interaction details, evaluation outcomes, conversation intelligence insights, and any selected optional or custom fields.

- **Format**: CSV
- **File Name**: `[ReportName]-YYYY-MM-DD-HH-MM-SS.csv`

**Typical exported information includes**: Interaction identifiers and timestamps, Channel and contact direction, Queue and Flow Name (for flow-based evaluation forms), Processing status and duration status, Evaluation outcomes, including evaluation scores, pass or fail status, and fatal interaction indicators, Metric-level evaluation details, Sentiment analysis and detected topics, AI-generated justifications (when applicable), Evaluation Metric Details (if configured), Conversation intelligence insights, Selected optional fields, and Custom business fields.

<Note> Additional evaluation metric columns are included when supported by the selected evaluation form.</Note>

The exported CSV includes interaction-level details followed by metric-level evaluation details for each applicable evaluation criterion.
