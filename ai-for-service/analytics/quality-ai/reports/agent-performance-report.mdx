The Agent Performance Report provides a consolidated view of agent performance across the selected scorecards and evaluated interactions. It summarizes evaluation scores, pass/fail statistics, coaching assignments, metric adherence, and attribute-level performance to help supervisors assess agent quality and identify coaching opportunities.

Only evaluated interactions are included in the report. Interactions below the configured duration threshold or marked as Duration Unavailable are excluded from aggregated scores unless they have been manually evaluated.

## Generate the Report

1. **Create the New Report**

    1. On the **Reports** tab, select **+ New Report**.

    1. From the **Create New Report** list, select the **Agent Performance Report**.
    
        ![Report Selection](/ai-for-service/analytics/quality-ai/reports/images/general-report-selection.png)

    1. Select **Next**.

1. Complete the **General** settings.

    1. Enter a unique **Name** for the report.

    1. Enter a **Description** for the report.

    1. Select **Next**.

        ![General Settings](/ai-for-service/analytics/quality-ai/reports/images/agent-general.png)

1. Complete the **Configuration** — **Filters and Options**.

    1. Select one or more Agent Scorecards to define the report scope. The selected scorecards determine the evaluated interactions, available agents, and evaluation metrics included in the report.
    
    1. Select a **Date** range from the dropdown, such as Today, Yesterday, Last 7 days, Last Week, Week to Date.

    1. Select a **Timezone** (defaults to device local timezone) from the dropdown.

    1. Configure the required Filter.
        
        1. Select the required filter options such as **Channel** (**Voice** or **Chat**) with **Contact Direction** (**Inbound** or **Outbound** or **All Directions**), **Queue**, **Language**, **Agents**, **Agent Groups**, and **Duration Status** (evaluated, below threshold, and duration unavailable). 
        
        1. Set the corresponding values for the selected/added filters. 

    1. Select **Optional Fields** to include additional supported columns in the generated CSV export. The available optional fields depend on the selected scorecard and evaluation form. Selected optional fields are appended as additional columns in the generated CSV.

    1. Enter one or more addresses in the **Send Email to** field to send the automated reports (minimum one required). 

    1. Select **Next**.

        ![Configure Filters](/ai-for-service/analytics/quality-ai/reports/images/agent-configuration.png)

1. Complete the **Schedule** to generate a report with the current configuration.

    1. Choose **Run on Demand** or **Schedule**.

        - **Run on Demand**: Generates the report immediately.
        - **Schedule**: Generates the report automatically.

    1. If you select **Schedule**:

        1. Choose a **Frequency or Repeat** (Hourly, Daily, Weekly, Monthly, Quarterly, or Yearly).

        1. Select a **Start Date** and **Timezone**.

        1. Select **Save** to confirm and activate the schedule.

           <Note>This report includes only evaluated interactions in aggregated metrics. Interactions below the configured duration threshold or marked as Duration Unavailable are excluded unless they're manually evaluated.</Note>

## Report Fields

### Generated CSV Fields

The generated CSV summarizes agent performance across the selected scorecards and evaluated interactions.

Depending on the selected scorecards, filters, evaluation form, and optional fields, the report can include the following information.

| Field                         | Description                                                                                |
| ----------------------------- | ------------------------------------------------------------------------------------------ |
| **Agent Name**                | Name of the evaluated agent.                                                               |
| **Total Interactions**        | Number of evaluated interactions included for the agent.                                   |
| **Kore Evaluation Score**     | Overall evaluation score calculated across the selected interactions.                      |
| **Failed Interactions**       | Number of interactions that failed one or more evaluation metrics.                         |
| **Fatal Interactions**        | Number of interactions containing fatal violations.                                        |
| **Coaching Assignments**      | Number of coaching assignments associated with the evaluated interactions.                 |
| **Scorecard Score**           | Overall score calculated for the selected scorecard.                                       |
| **Attributes**     | Attribute groups and evaluation attributes included in the selected scorecard.             |
| **Metric Values / Adherence** | Metric scores, adherence percentages, or calculated values for the evaluation attributes included in the selected scorecard.   |
| **Duration Status**           | Indicates whether the interaction was evaluated, below threshold, or duration unavailable. |
| **Optional Fields**           | Additional report columns selected during report configuration.                            |

<Note> Attribute and metric columns in the generated CSV depend on the selected scorecard and evaluation form. Reports generated using different scorecards may contain different attribute and metric columns.</Note>

### View and Download the Report

1. On the **Reports** tab, locate the report in the **Actions** column.

1. Select More options (⋮), then select **History**.

1. Select **Download** to save the report as a CSV file.

### Report Format

- **Format**: CSV file
- **File Name**: `[ReportName]-YYYY-MM-DD-HH-MM-SS.csv`

#### Field Representation in the Generated CSV

The generated CSV includes columns based on the selected scorecards, evaluation form, applied filters, and optional fields.

Typical exported fields include: Agent information, Interaction counts, Kore Evaluation Score, Failed interaction statistics, Fatal interaction statistics, Coaching assignments, Scorecard scores, Evaluation attributes, Metric values and adherence percentages, Duration status, and Selected optional fields.

The exact columns included in the export may vary depending on the selected scorecards, evaluation form, and optional fields.
