The Evaluation Form Summary Report provides interaction-level evaluation results across selected evaluation forms. It combines conversation details, evaluation outcomes, sentiment analysis, audit information, and quality metrics to help supervisors analyze evaluated interactions across channels, queues, agents, and contact directions.

The report exports interaction metadata together with evaluation results, including conversation identifiers, queue information, language, scored agent, sentiment score, detected topics, escalation status, evaluation score, pass/fail status, audit score, contact direction, and duration status.

## Generate Evaluation Form Summary Report

1. **Create the New Report**

    1. On the **Reports** tab, select **+ New Report**.

    1. From the **Create New Report** list, select the **Evaluation Form Summary Report**.
        
        ![Report Selection](/ai-for-service/analytics/quality-ai/reports/images/evaluation-form-report.png)

    1. Select **Next**.

1. Complete the **General** settings.

    1. Enter a unique **Name** for the report.

    1. Enter a **Description**.

    1. Select **Next**.

        ![General Settings](/ai-for-service/analytics/quality-ai/reports/images/create-new-report-general.png)

1. Complete the **Configuration** — **Filters and Options**.

    1. Select an **Evaluation Form** to define the data scope (at least one form is required).

    1. Select a **Date** or date range.

    1. Select a **Timezone**.

    1. Configure the required Filter.
    
        1. Select one or more filters to refine the report, including **Channel** (**Voice** or **Chat**) with **Contact Direction** (**Inbound** or **Outbound** or **All Directions**), **Queue**, **Language**, **Agents**, **Agent Groups**, and **Duration Status** (evaluated, below threshold, and duration unavailable). 
    
        1. Set the corresponding values for the selected/added filters. 

    1. Select **Optional Fields** to add additional columns to the report export. 

    1. Enter one or more addresses in the **Send Email to** field to send the automated reports (minimum one required). 

    1. Select **Next**.
    
        ![Configure Filters](/ai-for-service/analytics/quality-ai/reports/images/create-new-report-config.png)

1. Complete the **Schedule** to generate a report with the current configuration.

    1. Choose **Run on Demand** or **Schedule**.

        - **Run on Demand**: Generates the report immediately.
        - **Schedule**: Generates the report automatically.

    1. If you select **Schedule**:

        1. Choose a **Frequency or Repeat** (Hourly, Daily, Weekly, Monthly, Quarterly, or Yearly).

        1. Select a **Start Date** and **Timezone**.

        1. Select **Save**.

## Report Fields

### Interaction Evaluation Summary Report

The report exports one row for each evaluated interaction and includes conversation details, evaluation results, sentiment analysis, audit information, interaction status, and any optional fields selected during report configuration.

<Note>The report includes only interactions with **Duration Status = Evaluated**. When the **Contact Direction** filter is applied, the report includes only interactions matching the selected direction.</Note>


| Field                     | Description                                                                               |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| **Conversation ID**       | Unique identifier for the interaction.                                                    |
| **Channel**               | Interaction channel (Voice or Chat).                                                      |
| **Queue**                 | Queue associated with the interaction.                                                    |
| **Last Queue**            | Final queue that handled the interaction.                                                 |
| **Language**              | Language detected for the interaction.                                                    |
| **Agent**                 | Agent who handled the interaction.                                                        |
| **Scored Agent**          | Agent whose performance was evaluated.                                                    |
| **Start Time**            | Date and time when the interaction started.                                               |
| **Sentiment Score**       | Overall sentiment score calculated for the interaction.                                   |
| **Topics**                | Topics identified during conversation analysis.                                           |
| **Escalation**            | Indicates whether the interaction was escalated.                                          |
| **Kore Evaluation Score** | Overall evaluation score assigned to the interaction.                                     |
| **Is Passed**             | Indicates whether the interaction passed the evaluation criteria.                         |
| **Is Fatal Interaction**  | Indicates whether the interaction contains one or more fatal evaluation failures.         |
| **Audit Score**           | Manual audit score, when available. Displays **N/A** if no manual audit exists.           |
| **Contact Direction**     | Indicates whether the interaction is Inbound or Outbound.                                 |
| **Duration Status**       | Indicates the interaction duration status. The exported report includes only interactions with a value of **Evaluated**. |

<Note> The exported report contains only evaluated interactions. Interactions below the configured duration threshold are excluded from the report.</Note>

### View and Download the Report

1. On the **Reports** tab, locate the report in the **Actions** column.

1. Select More options (⋮), then select **History**.

1. Select **Download** to save the report as a CSV file.
