Scheduled Reporting enables supervisors to create, schedule, and manage reports for agent performance, interaction evaluation and conversation analytics, and evaluation form summary reports. Reports can be generated on demand or on a recurring schedule, filtered by evaluation forms, channels, queues, agents, contact direction, processing status, duration status, and other supported filters, then delivered by email or downloaded as CSV files. Depending on the report type, exports include interaction details, evaluation outcomes, quality metrics, conversation intelligence insights, metric-level evaluation results, optional fields, and custom business fields.

## Reports Overview

The Reports page provides a centralized view of all scheduled reports. Supervisors can create, run, schedule, edit, clone, publish, favorite, download, and delete reports for the following report types:

## Available Report Types
| Report                                                     | Purpose                                                                                                                                                                                                         |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Agent Performance Report**                               | Summarizes agent-level evaluation results, quality scores, failed interactions, fatal interactions, scorer details, and evaluation metric columns.                                                              |
| **Interaction Evaluation & Conversation Analytics Report** | Exports interaction-level evaluation results together with conversation intelligence insights, sentiment, detected topics, AI justifications, evaluation outcomes, optional fields, and custom business fields. |
| **Evaluation Form Summary Report**                         | Exports interaction-level evaluation results together with evaluation form details and metric-level evaluation columns for each applicable evaluation criterion.                                            |

## Report Configuration 

With Quality AI, you can create, filter, and schedule reports for automated or on-demand delivery with customizable formats, bulk actions, and secure, role-based access.

### Create a Report

To create a new report, follow these steps:

1. Navigate to **Quality AI** > **Analytics** > **Reports** > **+ New Report**.

1. Select **+ New Report**.

1. Select a report type (for example, Agent Performance Report). 

1. Select **Next** to proceed.

---

### Create and Configure a Report

The following steps demonstrate the three-step configuration process.

#### General Configuration

Captures the basic report metadata and identification information.

1. Enter a unique **Name** for the report.

1. Enter a meaningful **Description** explaining the report's purpose and intended audience.

1. Select **Next** to proceed.

#### Configure Report Scope

Select the required **Evaluation Form** or **Agent Scorecard**, depending on the selected report type.

- Select one or more evaluation forms or agent scorecards (depending on the report type) to define the report scope.
- Includes only conversations associated with the selected evaluation forms or agent scorecards. Depending on the selected report type, the exported report includes evaluation results, interaction metadata, metric-level evaluation columns, optional fields, and custom business fields.

<Note>You must select at least one evaluation form or scorecard (mandatory). Only agents with assigned scorecards appear in the report.</Note>

1. Select a **Date** or date range:

    - **Standard Ranges**: Current day, Previous day, Last 7 days, Last 30 days, Last 90 days.
    - **Custom Range**: Select specific start and end dates.

1. Select a **Timezone** to match the reporting accuracy.

1. Choose the necessary **Filters** such as Channel, Queue, Language, and Agents, then set their corresponding values.

##### Filters Configuration

This allows you to add filters to refine report data.

1. Select **+Add Filter** to add filters and set their corresponding values. Available filters include: 

- **Queues**: Select one or more queues to evaluate workload distribution and queue-specific agent metrics.
- **Channel**: Select **Chat** or **Voice**.
- **Agents**: Select specific agents for agent-level performance tracking.
- **Agent Groups**: Select the group or team of agents to include in the report.
- **Language**: Select a language configured for Quality AI. Defaults to the application's default language.
- **Duration Status**: Filter interactions by Evaluated, Below Threshold, or Duration Unavailable.
- **Contact Direction**: Filter by Inbound or Outbound to segment report data by contact direction. When applied, the report output includes only interactions matching the selected direction, and the exported file reflects the active direction filter.
- **Processing Status**: Filter conversations by processing state (Processed, Pending, or Validation Failed). Pending and Validation Failed conversations are included only when selected and contain only the available metadata because evaluation processing hasn't completed.

Reports exclude **Below Threshold** interactions by default. To include them, select **Below Threshold** in the **Duration Status** filter. Manually evaluated interactions are always included, and you can select **Delete** to remove a filter row.

##### Configure Optional Fields 

1. Select **Optional Fields** to add additional columns to the report export. 

1. Enter recipient email addresses in the **Send Email to** (minimum one required to receive automated reports).

1. Select **Next** to proceed.

    <Note>Available optional and custom fields vary by report type, selected evaluation forms or agent scorecards, configured business metadata, and report configuration.</Note>

#### Configure Schedule 

Choose one execution method: **Run on Demand** (manual) or **Schedule** (automated).

- **Run on Demand** (manual): Generates the report immediately using the current configuration. The **Instant Run** is available and the scheduling toggle is disabled.
- **Schedule** (automated): Generates the report automatically at the configured frequency. The scheduling toggle remains enabled, and you can enable or disable the schedule at any time.

##### Configure Schedule Frequencies 

For scheduled reports, specify the frequency:

- **Hourly**: Specify the minute of each hour (0-59). The system generates the report every hour at the specified minute.
- **Daily**: Select a specific time in 24-hour format.
- **Weekly**: Choose a specific day (Monday to Sunday) and time. The system generates the report every seven days.
- **Monthly**: Select a day of the month (1-28) and time.
- **Quarterly**: Select a day of the quarter (1-28/29/30/31) and time. The system generates the report every three months.
- **Yearly**: Select a month, day, and time. The system generates the report once per year.

##### Additional Settings

- **Start Date**: Select when the schedule begins.
- **Timezone**: Sets the time zone for report execution (defaults to your device’s local time zone).
- **Instant Run**: Runs the report immediately (available only in Run on Demand mode). To generate the report immediately, select **Instant Run**.

   <Note>When you configure a recurring schedule (such as Daily or Weekly), the **Instant Run** option is disabled. The report runs automatically according to the schedule. In Schedule mode, you can toggle the schedule on or off at any time.</Note>

1. Select **Save** to confirm and activate the schedule. The saved report appears in the **Reports** > **My Reports** dashboard.

    - Enable scheduling by switching on the Schedule toggle.
    - From the **Actions** column, select **Run** to generate the report immediately.

      <Note>When you proceed to disable a report, the system displays a pop-up confirmation before updating the report status.</Note>

## Report Behavior

Reports include conversations based on the selected **Processing Status** and **Duration Status** filters. The available report fields depend on the conversation processing state.

Pending and Validation Failed conversations include only the metadata available when the report is generated because conversation processing hasn't completed.

| Conversation State | Behavior                                                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| Processed          | Included in report metrics and calculations.                                                                                           |
| Pending            | Included only when selected through the **Processing Status** filter. Metric fields remain empty because processing has not completed. |
| Validation Failed  | Included only when selected through the **Processing Status** filter. Metric fields remain empty because processing did not complete.  |
| Below Threshold    | Excluded by default. Include using the **Duration Status** filter.                                                                     |
| Manually Evaluated | Always included as evaluated interactions.                                                                                             |

<Note> When Pending or Validation Failed processing statuses are selected, reports include only the metadata available for those conversations. Evaluation scores, sentiment, topics, metric-level evaluation data, and other processed fields remain empty until processing completes.</Note>

## Manage Reports

### Edit Reports

Modify the report's settings including name, description, data scope, filters, recipients, and schedule, then save to activate automated generation.

1. Select **Edit** from the **Actions** column.

1. Modify the required fields across General, Configuration, and Schedule steps.

1. Select **Save** to activate the changes or reschedule the configuration.

---

### View and Download Report History

1. Navigate to the **Reports** and select the three-dot (⋮) menu in the **Actions** column.

1. Select **History** to view the last five report runs.

    ![History](/ai-for-service/analytics/quality-ai/reports/images/download-report-action.png)

1. Select **Download** to save a report run as a CSV file.

    ![History Report](/ai-for-service/analytics/quality-ai/reports/images/history.png)

1. The generated reports show their status: run success (green) or run failed (red).

    Reports are downloaded as CSV files. Exported columns vary depending on the selected report type, evaluation form, optional fields, custom fields, processing status, and report configuration.

   <Note>Reports are available for download in CSV format only, with headers translated to the selected language.</Note>


### Clone a Report

1. Navigate to the **Reports** > select the three-dot (⋮) menu in the **Actions** column.

1. Select **Clone** to create a copy of the report configuration. 

1. A confirmation message appears when cloning is complete.

### Favorite or Unfavorite a Report

1. Navigate to the **Reports** > select the three-dot (⋮) menu in the **Actions** column.

1. Select **Favorite** or **Unfavorite**. 

1. All tagged favorite reports appear in the **Favorites** tab.

### Change Report Visibility

Reports are **Public** by default. Switching to **Private** restricts access to the report creator or specific users.

- **Public**: Accessible to all users.
- **Private**: Accessible only to specific groups, individuals, or the report creator.

To revise access:

1. Navigate to the **Reports** > select the three-dot (⋮) menu in the **Actions** column.

1. Select **Switch to Public** or **Switch to Private**. 

1. A confirmation message appears when the change is applied.

### Delete Report

Deleting a report permanently removes its configuration, associated schedule, and all history.

1. Navigate to the **Reports** > select the three-dot (⋮) menu in the **Actions** column.

1. Select **Delete** to remove the report.

1. Select **Confirm**. The system displays a success message after deleting the selected reports.

## Sample Report Format

Reports are generated only in CSV format:

- **File Format Output**: CSV file
- **File Name**: `[ReportName]-YYYY-MM-DD-HH-MM-SS.csv`
- **Headers**: Translated to the selected language with filtered data

Depending on the selected report type, the exported CSV contains: Standard Interaction or Agent Information, Evaluation Results, Contact Direction, Processing Status, Duration Status, Evaluation Form or Scorecard Information, Metric-Level Evaluation Columns, Conversation Intelligence Insights, Optional Fields, and Custom Business Fields.


  ![Sample Report](/ai-for-service/analytics/quality-ai/reports/images/sample-agent-performance-report.png)

  <Note>The same three-step process (General > Configuration > Schedule) applies to all report types, with variations in the Configuration step based on the specific report requirements.</Note>

## Data Availability Behavior

- **Partial Data**: Reports include all available conversation metadata. Pending and Validation Failed conversations contain only the metadata available when the report is generated because evaluation processing hasn't completed.
- **No Matching Data**: An empty CSV with header rows is generated, and the email indicates that no data matches the criteria with suggestions for alternative filter configurations.

## Access Control

### Role-Based Permissions

The following table describes report-related permissions based on user roles:


| Role                                        | Create Report | Edit Own Reports | Edit Public Reports | Delete Own Reports | Delete Public Reports | Schedule Reports | View Report History    |
|---------------------------------------------|---------------|------------------|---------------------|--------------------|-----------------------|------------------|------------------------|
| App Owner                                   | Yes           | Yes              | Yes                 | Yes                | Yes                   | Yes              | Yes                    |
| Supervisor                                  | Yes           | Yes              | Yes                 | Yes                | Yes                   | Yes              | Yes                    |
| User with `Quality AI Reporting` Permission | Yes           | Yes              | Yes                 | Yes                | No                    | Yes              | Yes (own reports only) |
| User without Permission                     | No            | No               | No                  | No                 | No                    | No               | No                     |


<Note>Report data is based on the selected filters. Users with the Quality AI Reporting permission can access reports, create reports, receive report emails, and download report history.</Note>

For more information on role-based access control, see [Other Modules](/ai-for-service/user-management/users-and-role#other-modules) under the **Roles and Permissions**.

---

### Permission Restrictions

Users without the Quality AI Reporting permission can't:

- Access the Reports section
- View any reports (public or private)
- Create new reports
- Receive scheduled report emails
- Download historical reports
